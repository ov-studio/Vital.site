---
title: self:get_distance_fade_length
description: Retrieves the length of the fade transition on the directional light
badge: client
---

### Syntax

```lua
local distance = self:get_distance_fade_length()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | distance | Fade transition length in world units |

---

### Examples

```lua lineNumbers title="Get distance fade length of a directional light"
local entity = light.directional.create()

core.engine.print("info", entity:get_distance_fade_length())
```
