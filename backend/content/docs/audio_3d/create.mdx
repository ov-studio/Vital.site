---
title: core.audio_3d.create
description: Creates a new audio-3d instance from a file path
badge: client
---

### Syntax

```lua
local instance = core.audio_3d.create(
    path,
    autoplay = false
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | path | File path to the audio asset<br/>Refer [**Formats**](#formats) section |
| `bool` | autoplay | Determines whether the audio starts playing immediately:<br/>• When `true` - playback begins as soon as the instance is created<br/>• When `false` - playback must be started manually via [`self:play()`](/docs/audio_3d/method/play) |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `audio_3d` | instance | Created audio-3d instance |

---

### Examples

```lua lineNumbers title="Create a basic audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:set_global_position({0, 1, -5})
entity:play()
```

```lua lineNumbers title="Create an instance that starts playing immediately"
local entity = core.audio_3d.create("sounds/ambient.ogg", true)

entity:set_global_position({10, 0, 0})
entity:set_volume(1.0)
```
