---
title: self:get_volume
description: Retrieves the current linear volume of the audio-3d instance
badge: client
---

### Syntax

```lua
local result = self:get_volume()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | volume | Current linear volume |

---

### Examples

```lua lineNumbers title="Get the volume of an audio_3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Volume:", entity:get_volume())
```
