---
title: self:set_shadow_mode
description: Sets the shadow rendering mode of the point light
badge: client
---

### Syntax

```lua
local status = self:set_shadow_mode(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | mode | Shadow mode enum value — refer to [`light.point.shadow_mode`](/docs/point_light/enum/shadow_mode) |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the shadow mode of a point light to cube map"
local entity = light.point.create()

entity:set_shadow_mode(light.point.shadow_mode.CUBE)
```
