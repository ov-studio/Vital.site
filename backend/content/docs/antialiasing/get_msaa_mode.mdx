---
title: gfx.antialiasing.get_msaa_mode

badge: client

### Syntax

```lua
local result = gfx.antialiasing.get_msaa_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`gfx.antialiasing.msaa_mode`](/docs/antialiasing/enum/msaa_mode) | result | Currently active MSAA mode |

---

### Examples

```lua lineNumbers title="Print current MSAA mode"
core.engine.print("info", "MSAA mode:", gfx.antialiasing.get_msaa_mode())
```
