---
title: gfx.antialiasing.set_mode
description: Sets the active antialiasing mode
badge: client
---

### Syntax

```lua
local status = gfx.antialiasing.set_mode(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`gfx.antialiasing.mode`](/docs/antialiasing/enum/mode) | mode | Antialiasing mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set antialiasing mode to TAA"
gfx.antialiasing.set_mode(gfx.antialiasing.mode.TAA)
```
