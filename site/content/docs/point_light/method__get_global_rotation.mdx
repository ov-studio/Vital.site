---
title: self:get_global_rotation
description: Retrieves the global world-space rotation of the point light
badge: client
---

### Syntax

```lua
local rotation = self:get_global_rotation()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Current global world-space rotation in degrees as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global world-space rotation of a point light"
local entity = light.point.create()
local rotation = entity:get_global_rotation()

core.engine.print("info", "Rotation:", util.table.unpack(rotation))
```
