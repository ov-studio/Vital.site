---
title: self:get_attenuation_filter_db
description: Retrieves the attenuation filter gain of the audio-3d instance
badge: client
---

### Syntax

```lua
local result = self:get_attenuation_filter_db()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current attenuation filter gain in decibels |

---

### Examples

```lua lineNumbers title="Get the attenuation filter gain of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Attenuation filter gain:", entity:get_attenuation_filter_db())
```
