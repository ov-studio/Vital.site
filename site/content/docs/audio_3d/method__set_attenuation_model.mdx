---
title: self:set_attenuation_model
description: Sets the attenuation model of the audio-3d instance
badge: client
---

### Syntax

```lua
local status = self:set_attenuation_model(
    model
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`core.audio_3d.attenuation_model`](/docs/audio_3d/enum/attenuation_model) | model | Attenuation model to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Use logarithmic attenuation on an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:set_attenuation_model(core.audio_3d.attenuation_model.LOGARITHMIC)
```
