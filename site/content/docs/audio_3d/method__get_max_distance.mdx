---
title: self:get_max_distance
description: Retrieves the maximum distance at which the audio-3d instance can be heard
badge: client
---

### Syntax

```lua
local result = self:get_max_distance()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current maximum audible distance in meters |

---

### Examples

```lua lineNumbers title="Get the max distance of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Max distance:", entity:get_max_distance())
```
