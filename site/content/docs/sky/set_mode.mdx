---
title: gfx.sky.set_mode
description: Sets the material type of the sky
badge: client
---

### Syntax

```lua
local status = gfx.sky.set_mode(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`gfx.sky.mode`](/docs/sky/enum/mode) | mode | Sky material type to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set sky material type to procedural"
gfx.sky.set_mode(gfx.sky.mode.PROCEDURAL)
```
