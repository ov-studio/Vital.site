---
title: self:set_emission_angle_filter_attenuation_db
description: Sets the attenuation applied outside the emission cone of the audio-3d instance
badge: client
---

### Syntax

```lua
local status = self:set_emission_angle_filter_attenuation_db(
    value
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | value | Attenuation in decibels applied to audio outside the emission cone<br/>More negative values produce a sharper drop-off beyond the cone edge |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply strong attenuation outside the emission cone"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:set_emission_angle_enabled(true)
entity:set_emission_angle(45.0)
entity:set_emission_angle_filter_attenuation_db(-24.0)
```
