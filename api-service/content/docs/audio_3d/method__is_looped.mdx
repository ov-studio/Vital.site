---
title: self:is_looped
description: Checks whether the audio-3d instance is set to loop playback
badge: client
---

### Syntax

```lua
local result = self:is_looped()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if playback loops once it reaches the end, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check if an audio-3d instance is looping"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Loop:", entity:is_looped())
```
