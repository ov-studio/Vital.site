---
title: self:is_area_normalizing_energy
description: Checks whether energy normalization is enabled on the area light, which keeps perceived brightness constant regardless of the area size
badge: client
---

### Syntax

```lua
local result = self:is_area_normalizing_energy()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if energy normalization is enabled, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check energy normalization on an area light"
local entity = light.area.create()

core.engine.print("info", entity:is_area_normalizing_energy())
```
