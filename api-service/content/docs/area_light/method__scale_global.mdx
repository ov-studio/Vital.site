---
title: self:scale_global
description: Scales the area light in world space by the given factor
badge: client
---

### Syntax

```lua
local status = self:scale_global(
    scale
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Scale factor to apply in world space as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Scale a area light uniformly in world space"
local entity = light.area.create()

entity:scale_global({2, 2, 2})
```
