---
title: gfx.antialiasing.get_mode
description: Retrieves the currently active antialiasing mode
badge: client
---

### Syntax

```lua
local result = gfx.antialiasing.get_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`gfx.antialiasing.mode`](/docs/antialiasing/enum/mode) | result | Currently active antialiasing mode |

---

### Examples

```lua lineNumbers title="Print current antialiasing mode"
core.engine.print("info", "Antialiasing mode:", gfx.antialiasing.get_mode())
```
