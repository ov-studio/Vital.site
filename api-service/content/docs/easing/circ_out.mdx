---
title: util.easing.circ_out
description: Applies a circular ease-out — follows the arc of a quarter circle, fast start settling smoothly
badge: shared
---

### Syntax

```lua
local result = util.easing.circ_out(
    progress
)
```

<Callout type="info">
  **Circ easing follows the geometry of a circle — organic and smooth without any overshoot.**

  - **No overshoot or oscillation** — the curve stays strictly within [0, 1] at all times.
  - **Best for** — natural camera pans, soft object placements, and physics-inspired motion without bounce.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | progress | Interpolation factor, typically in the range [0, 1] |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Eased progress value |

---

### Examples

```lua lineNumbers title="Sample output at key progress values"
core.engine.print("info", util.easing.circ_out(0.0))  -- 0.0
core.engine.print("info", util.easing.circ_out(0.25)) -- near start
core.engine.print("info", util.easing.circ_out(0.5))  -- midpoint
core.engine.print("info", util.easing.circ_out(0.75)) -- near end
core.engine.print("info", util.easing.circ_out(1.0))  -- 1.0
```

```lua lineNumbers title="Pair with lerp to animate a value"
local result = util.easing.lerp(0, 100, util.easing.circ_out(0.5))

core.engine.print("info", result)
```

```lua lineNumbers title="Animate a circle across the screen"
local resolution = core.engine.get_resolution()
local duration = 1.5
local start_tick = core.engine.get_tick()

util.event.on("sandbox:draw", function()
    local elapsed = (core.engine.get_tick() - start_tick) / 1000.0
    local t = math.min(elapsed / duration, 1.0)
    local x = util.easing.lerp(0, resolution[1], util.easing.circ_out(t))

    core.engine.draw_circle({x, resolution[2]*0.5}, 16, {1, 1, 1, 1})
end)
```
