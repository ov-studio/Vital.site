---
title: self:get_intensity
description: Retrieves the physical intensity of the spot light in lumens or lux when physical light units are enabled
badge: client
---

### Syntax

```lua
local intensity = self:get_intensity()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | intensity | Current physical intensity value |

---

### Examples

```lua lineNumbers title="Get intensity of a spot light"
local entity = light.spot.create()

core.engine.print("info", entity:get_intensity())
```
