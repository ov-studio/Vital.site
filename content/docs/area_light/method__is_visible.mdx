---
title: self:is_visible
description: Checks whether the area light is set as visible
badge: client
---

### Syntax

```lua
local result = self:is_visible()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the area light is visible, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check visibility of a area light"
local entity = light.area_light.create()

core.engine.print("info", entity:is_visible())
```
