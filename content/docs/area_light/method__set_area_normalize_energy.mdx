---
title: self:set_area_normalize_energy
description: Sets whether energy normalization is enabled on the area light, keeping perceived brightness constant regardless of area size
badge: client
---

### Syntax

```lua
local status = self:set_area_normalize_energy(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to enable energy normalization, `false` to disable |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable energy normalization on an area light"
local entity = light.area.create()

entity:set_area_normalize_energy(true)
```
