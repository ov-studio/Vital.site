---
title: self:set_distance_fade_length
description: Sets the length of the fade transition on the area light
badge: client
---

### Syntax

```lua
local status = self:set_distance_fade_length(
    distance
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | distance | Fade transition length in world units |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply distance fade length on a area light"
local entity = light.area_light.create()

entity:set_distance_fade_length(1.0)
```
