---
title: self:reset_projector
description: Removes the currently active projector texture from the area light
badge: client
---

### Syntax

```lua
local status = self:reset_projector()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Remove the projector texture from a area light"
local entity = light.area_light.create()

entity:reset_projector()
```
