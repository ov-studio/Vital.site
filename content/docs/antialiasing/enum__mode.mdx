### Values

<Callout type="info">
This is independent of MSAA — refer [`gfx.antialiasing.msaa_mode`](/docs/antialiasing/enum/msaa_mode), which can be combined with any of the below.
</Callout>

| Constant | Description |
|----------|-------------|
| `gfx.antialiasing.mode.DISABLED` | No screen-space or temporal antialiasing is applied |
| `gfx.antialiasing.mode.FXAA` | Fast approximate antialiasing — cheap post-process, softens the image |
| `gfx.antialiasing.mode.TAA` | Temporal antialiasing — accumulates prior frames for sharper edges, can ghost on fast motion |
