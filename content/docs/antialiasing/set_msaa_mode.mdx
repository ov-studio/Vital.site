---
title: gfx.antialiasing.set_msaa_mode
description: Sets the active MSAA mode
badge: client
---

### Syntax

```lua
local status = gfx.antialiasing.set_msaa_mode(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`gfx.antialiasing.msaa_mode`](/docs/antialiasing/enum/msaa_mode) | mode | MSAA mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set MSAA to 4x"
gfx.antialiasing.set_msaa_mode(gfx.antialiasing.msaa_mode.X4)
```
