---
title: self:set_emission_angle
description: Sets the emission angle of the audio-3d instance
badge: client
---

### Syntax

```lua
local status = self:set_emission_angle(
    value
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | value | Half-angle of the emission cone in degrees<br/>Audio is only emitted within this cone when emission angle is enabled via [`self:set_emission_angle_enabled`](/docs/audio_3d/method/set_emission_angle_enabled) |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Configure a narrow directional speaker"
local entity = core.audio_3d.create("sounds/speaker.ogg")

entity:set_emission_angle_enabled(true)
entity:set_emission_angle(30.0)
```
