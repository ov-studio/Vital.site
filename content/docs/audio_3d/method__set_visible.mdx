---
title: self:set_visible
description: Sets the visibility of the audio-3d instance
badge: Client
---

### Syntax

```lua
local status = self:set_visible(
    visible
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | visible | Determines the visibility state:<br/>• When `true` - the instance is visible<br/>• When `false` - the instance is hidden |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Toggle visibility of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:set_visible(false)
entity:set_visible(true)
```
