---
title: self:get_unit_size
description: Retrieves the unit size of the audio-3d instance
badge: Client
---

### Syntax

```lua
local result = self:get_unit_size()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current unit size |

---

### Examples

```lua lineNumbers title="Get the unit size of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Unit size:", entity:get_unit_size())
```
