---
title: self:get_emission_angle
description: Retrieves the emission angle of the audio-3d instance
badge: Client
---

### Syntax

```lua
local result = self:get_emission_angle()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current emission cone half-angle in degrees |

---

### Examples

```lua lineNumbers title="Get the emission angle of an audio-3d instance"
local entity = core.audio_3d.create("sounds/speaker.ogg")

core.engine.print("info", "Emission angle:", entity:get_emission_angle())
```
