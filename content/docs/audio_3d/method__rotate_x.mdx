---
title: self:rotate_x
description: Rotates the audio-3d instance around the X axis by the given angle in radians
badge: Client
---

### Syntax

```lua
local status = self:rotate_x(
    angle
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | angle | Angle in radians to rotate around the X axis |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Rotate an audio-3d instance around the X axis"
local entity = core.audio_3d.create("sounds/speaker.ogg")

entity:rotate_x(math.pi / 4)
```
