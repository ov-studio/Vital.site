---
title: self:get_rotation_degrees
description: Retrieves the rotation of the audio-3d instance in degrees
badge: Client
---

### Syntax

```lua
local result = self:get_rotation_degrees()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `{float, float, float}` | result | Current Euler rotation in degrees as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the rotation of an audio-3d instance in degrees"
local entity = core.audio_3d.create("sounds/ambient.ogg")

local rot = entity:get_rotation_degrees()
core.engine.print("info", rot[1], rot[2], rot[3])
```
