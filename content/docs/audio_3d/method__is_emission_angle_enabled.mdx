---
title: self:is_emission_angle_enabled
description: Checks whether the emission angle cone is enabled on the audio-3d instance
badge: client
---

### Syntax

```lua
local result = self:is_emission_angle_enabled()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if emission angle is enabled, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check emission angle state"
local entity = core.audio_3d.create("sounds/speaker.ogg")

core.engine.print("info", "Emission angle enabled:", entity:is_emission_angle_enabled())
```
