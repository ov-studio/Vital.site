---
title: self:is_visible
description: Checks whether the audio-3d instance is visible
badge: Client
---

### Syntax

```lua
local result = self:is_visible()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the instance is visible, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check visibility of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Visible:", entity:is_visible())
```
