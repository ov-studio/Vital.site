---
title: self:get_attenuation_model
description: Retrieves the attenuation model of the audio-3d instance
badge: client
---

### Syntax

```lua
local result = self:get_attenuation_model()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `core.audio_3d.attenuation_model` | result | Current attenuation model<br/>Refer [**core.audio_3d.attenuation_model**](/docs/audio_3d/enum/attenuation_model) |

---

### Examples

```lua lineNumbers title="Get the attenuation model of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Attenuation model:", entity:get_attenuation_model())
```
