---
title: self:hide
description: Hides the audio-3d instance
badge: client
---

### Syntax

```lua
local status = self:hide()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Hide an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:hide()
```
