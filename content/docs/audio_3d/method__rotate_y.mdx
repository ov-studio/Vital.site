---
title: self:rotate_y
description: Rotates the audio-3d instance around the Y axis by the given angle in radians
badge: Client
---

### Syntax

```lua
local status = self:rotate_y(
    angle
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | angle | Angle in radians to rotate around the Y axis |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Rotate an audio-3d instance around the Y axis"
local entity = core.audio_3d.create("sounds/speaker.ogg")

entity:rotate_y(math.pi / 2)
```
