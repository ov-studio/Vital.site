---
title: self:get_position
description: Retrieves the position of the audio-3d instance relative to its parent
badge: client
---

### Syntax

```lua
local result = self:get_position()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | result | Current position relative to the parent as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the position of an audio-3d instance relative to its parent"
local entity = core.audio_3d.create("sounds/ambient.ogg")
local position = entity:get_position()

core.engine.print("info", "Audio position:", util.table.unpack(position))
```
