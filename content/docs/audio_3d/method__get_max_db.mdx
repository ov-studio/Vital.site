---
title: self:get_max_db
description: Retrieves the maximum decibel level of the audio-3d instance
badge: Client
---

### Syntax

```lua
local result = self:get_max_db()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current maximum output level in decibels |

---

### Examples

```lua lineNumbers title="Get the max dB of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Max dB:", entity:get_max_db())
```
