---
title: self:set_global_position
description: Sets the global world position of the audio-3d instance
badge: client
---

### Syntax

```lua
local status = self:set_global_position(
    position
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Global world position as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Place an audio-3d instance at an absolute world position"
local entity = core.audio_3d.create("sounds/explosion.ogg")

entity:set_global_position({100, 0, -50})
entity:play()
```
