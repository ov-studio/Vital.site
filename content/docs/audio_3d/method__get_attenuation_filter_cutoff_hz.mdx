---
title: self:get_attenuation_filter_cutoff_hz
description: Retrieves the attenuation filter cutoff frequency of the audio-3d instance
badge: client
---

### Syntax

```lua
local result = self:get_attenuation_filter_cutoff_hz()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current filter cutoff frequency in Hz |

---

### Examples

```lua lineNumbers title="Get the attenuation filter cutoff of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Filter cutoff:", entity:get_attenuation_filter_cutoff_hz())
```
