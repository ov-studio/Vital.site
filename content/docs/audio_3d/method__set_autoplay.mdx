---
title: self:set_autoplay
description: Sets whether the audio-3d instance starts playing automatically
badge: client
---

### Syntax

```lua
local status = self:set_autoplay(
    enable
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | enable | Determines the autoplay state:<br/>• When `true` - playback begins automatically when the instance enters the scene<br/>• When `false` - playback must be started manually via [`self:play()`](/docs/audio_3d/method/play) |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable autoplay on an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:set_autoplay(true)
```
