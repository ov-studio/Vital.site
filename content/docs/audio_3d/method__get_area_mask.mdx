---
title: self:get_area_mask
description: Retrieves the area mask of the audio-3d instance
badge: Client
---

### Syntax

```lua
local result = self:get_area_mask()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | result | Current area mask as a bitmask integer |

---

### Examples

```lua lineNumbers title="Get the area mask of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Area mask:", entity:get_area_mask())
```
