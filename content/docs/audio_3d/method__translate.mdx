---
title: self:translate
description: Translates the audio-3d instance by an offset in world space
badge: Client
---

### Syntax

```lua
local status = self:translate(
    offset
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `{float, float, float}` | offset | World-space offset to move by as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Move an audio-3d instance forward in world space"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:translate({0, 0, -5})
```
