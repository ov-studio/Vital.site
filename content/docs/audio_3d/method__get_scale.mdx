---
title: self:get_scale
description: Retrieves the scale of the audio-3d instance
badge: Client
---

### Syntax

```lua
local result = self:get_scale()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `{float, float, float}` | result | Current scale as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the scale of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

local s = entity:get_scale()
core.engine.print("info", s[1], s[2], s[3])
```
