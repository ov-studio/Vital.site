---
title: self:set_position
description: Sets the local position of the audio-3d instance
badge: client
---

### Syntax

```lua
local status = self:set_position(
    position
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Local position as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Position an audio-3d instance in local space"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:set_position({0, 2, -10})
entity:play()
```
