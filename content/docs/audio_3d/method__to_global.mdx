---
title: self:to_global
description: Converts a local-space position to world space relative to the audio-3d instance
badge: client
---

### Syntax

```lua
local result = self:to_global(
    local_point
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `{float, float, float}` | local_point | Local-space position to convert as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `{float, float, float}` | result | Converted world-space position as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Convert a local offset to a world position"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:set_global_position({10, 0, 0})

local world_pos = entity:to_global({0, 0, -5})
core.engine.print("info", world_pos[1], world_pos[2], world_pos[3])
```
