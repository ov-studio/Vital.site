---
title: self:is_type
description: Checks whether the instance belongs to the specified type
badge: client
---

### Syntax

```lua
local result = self:is_type(
    name
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Type to check against |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the instance matches the given type, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check the type of an audio-2d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", entity:is_type("audio_3d")) -- true
core.engine.print("info", entity:is_type("audio_3d")) -- false
```
