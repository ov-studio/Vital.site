---
title: self:get_emission_angle_filter_attenuation_db
description: Retrieves the attenuation applied outside the emission cone of the audio-3d instance
badge: Client
---

### Syntax

```lua
local result = self:get_emission_angle_filter_attenuation_db()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current out-of-cone attenuation in decibels |

---

### Examples

```lua lineNumbers title="Get emission cone attenuation"
local entity = core.audio_3d.create("sounds/speaker.ogg")

core.engine.print("info", "Cone attenuation:", entity:get_emission_angle_filter_attenuation_db())
```
