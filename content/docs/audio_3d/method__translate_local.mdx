---
title: self:translate_local
description: Translates the audio-3d instance by an offset relative to its own local axes
badge: client
---

### Syntax

```lua
local status = self:translate_local(
    offset
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | offset | Local-space offset to move by as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Move an audio-3d instance forward along its own local Z axis"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:translate_local({0, 0, -5})
```
