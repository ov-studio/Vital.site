---
title: self:set_max_db
description: Sets the maximum decibel level of the audio-3d instance
badge: client
---

### Syntax

```lua
local status = self:set_max_db(
    max_db
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | max_db | Maximum output level in decibels<br/>Clamps the volume so it never exceeds this level regardless of distance |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Cap the output level of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:set_max_db(3.0)
```
