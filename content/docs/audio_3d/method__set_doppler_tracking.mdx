---
title: self:set_doppler_tracking
description: Sets the doppler tracking mode of the audio-3d instance
badge: client
---

### Syntax

```lua
local status = self:set_doppler_tracking(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`core.audio_3d.doppler_tracking`](/docs/audio_3d/enum/doppler_tracking) | mode | Doppler tracking mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable idle-step Doppler tracking"
local entity = core.audio_3d.create("sounds/vehicle.ogg")

entity:set_doppler_tracking(core.audio_3d.doppler_tracking.IDLE_STEP)
entity:play()
```
