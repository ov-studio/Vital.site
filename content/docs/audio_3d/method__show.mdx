---
title: self:show
description: Makes the audio-3d instance visible
badge: client
---

### Syntax

```lua
local status = self:show()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Show an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:hide()
entity:show()
```
