---
title: self:set_distance_fade_begin
description: Sets the distance at which the spot light begins to fade out
badge: client
---

### Syntax

```lua
local status = self:set_distance_fade_begin(
    distance
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | distance | Fade begin distance in world units |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply distance fade begin on a spot light"
local entity = light.spot_light.create()

entity:set_distance_fade_begin(1.0)
```
