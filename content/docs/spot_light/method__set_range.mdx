---
title: self:set_range
description: Sets the maximum range of the spot light
badge: client
---

### Syntax

```lua
local status = self:set_range(
    range
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | range | Light range in world units |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the range of a spot light"
local entity = light.spot_light.create()

entity:set_range(15.0)
```
