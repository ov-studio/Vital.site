---
title: self:get_shadow_blur
description: Retrieves the shadow blur amount of the spot light
badge: client
---

### Syntax

```lua
local blur = self:get_shadow_blur()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | blur | Current shadow blur amount |

---

### Examples

```lua lineNumbers title="Get shadow blur of a spot light"
local entity = light.spot_light.create()

core.engine.print("info", entity:get_shadow_blur())
```
