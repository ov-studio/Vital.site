---
title: self:set_intensity
description: Sets the physical intensity of the spot light in lumens or lux when physical light units are enabled
badge: client
---

### Syntax

```lua
local status = self:set_intensity(
    intensity
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | intensity | Physical intensity value to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply intensity on a spot light"
local entity = light.spot_light.create()

entity:set_intensity(1.0)
```
