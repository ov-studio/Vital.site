---
title: self:set_global_position
description: Sets the global world-space position of the spot light
badge: client
---

### Syntax

```lua
local status = self:set_global_position(
    position
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Position to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the global world-space position of a spot light"
local entity = light.spot_light.create()

entity:set_global_position({0, 5, 0})
```
