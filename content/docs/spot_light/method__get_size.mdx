---
title: self:get_size
description: Retrieves the soft shadow size of the spot light, which controls the apparent source radius for soft shadows
badge: client
---

### Syntax

```lua
local size = self:get_size()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | size | Current soft shadow size |

---

### Examples

```lua lineNumbers title="Get the soft shadow size of a spot light"
local entity = light.spot_light.create()

core.engine.print("info", entity:get_size())
```
