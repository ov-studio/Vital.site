---
title: self:get_range
description: Retrieves the maximum range of the spot light
badge: client
---

### Syntax

```lua
local range = self:get_range()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | range | Current light range in world units |

---

### Examples

```lua lineNumbers title="Get the range of a spot light"
local entity = light.spot_light.create()

core.engine.print("info", entity:get_range())
```
