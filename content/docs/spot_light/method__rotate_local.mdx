---
title: self:rotate_local
description: Rotates the spot light around the given local axis by the specified angle
badge: client
---

### Syntax

```lua
local status = self:rotate_local(
    axis,
    angle
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | axis | Local-space axis to rotate around as `{x, y, z}` |
| `float` | angle | Angle in radians |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Rotate a spot light around its local Y axis"
local entity = light.spot_light.create()

entity:rotate_local({0, 1, 0}, math.pi / 4)
```
