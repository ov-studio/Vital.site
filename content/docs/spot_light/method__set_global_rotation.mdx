---
title: self:set_global_rotation
description: Sets the global world-space rotation of the spot light
badge: client
---

### Syntax

```lua
local status = self:set_global_rotation(
    rotation
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Rotation to apply in degrees as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Rotate a spot light 45 degrees on the Y axis"
local entity = light.spot_light.create()

entity:set_global_rotation({0, 45, 0})
```
