---
title: self:set_visible
description: Sets the visibility of the point light
badge: client
---

### Syntax

```lua
local status = self:set_visible(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to show the point light, `false` to hide it |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Hide a point light"
local entity = light.point_light.create()

entity:set_visible(false)
```
