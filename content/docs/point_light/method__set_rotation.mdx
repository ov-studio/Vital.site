---
title: self:set_rotation
description: Sets the local rotation of the point light
badge: client
---

### Syntax

```lua
local status = self:set_rotation(
    rotation
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Rotation to apply in degrees as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Rotate a point light 45 degrees on the Y axis"
local entity = light.point_light.create()

entity:set_rotation({0, 45, 0})
```
