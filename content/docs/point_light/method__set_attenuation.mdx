---
title: self:set_attenuation
description: Sets the attenuation curve exponent of the point light, which controls how light intensity falls off with distance
badge: client
---

### Syntax

```lua
local status = self:set_attenuation(
    attenuation
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | attenuation | Attenuation exponent to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the attenuation of a point light"
local entity = light.point_light.create()

entity:set_attenuation(1.0)
```
