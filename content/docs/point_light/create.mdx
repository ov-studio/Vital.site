---
title: light.point_light.create
description: Creates a new point light instance and adds it to the scene
badge: client
---

### Syntax

```lua
local instance = light.point_light.create()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `point_light` | instance | Created point light instance |

---

### Examples

```lua lineNumbers title="Create a point light instance"
local entity = light.point_light.create()

entity:set_color({1, 1, 1})
entity:set_energy(1.0)
entity:set_position({0, 5, 0})
```
