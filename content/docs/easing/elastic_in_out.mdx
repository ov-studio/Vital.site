---
title: util.easing.elastic_in_out
description: Applies an elastic ease-in-out — oscillation at both ends with a fast transition in the middle
badge: shared
---

### Syntax

```lua
local result = util.easing.elastic_in_out(
    progress,
    amplitude,
    period
)
```

<Callout type="info">
  **Elastic easing simulates a spring or rubber-band effect.**

  - **`amplitude`** — controls the oscillation scale. **`period`** — controls the oscillation frequency.
  - **Best for** — springy UI reveals, bouncy object placements, and effects that should feel alive or physical.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | progress | Interpolation factor, typically in the range [0, 1] |
| `float` | amplitude | Oscillation scale. Values below `1.0` are clamped to `1.0`. Defaults to `1.0` |
| `float` | period | Oscillation frequency. Smaller = faster oscillation. Defaults to `0.45` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Eased progress value |

---

### Examples

```lua lineNumbers title="Sample output at key progress values"
core.engine.print("info", util.easing.elastic_in_out(0.0))  -- 0.0
core.engine.print("info", util.easing.elastic_in_out(0.25)) -- near start
core.engine.print("info", util.easing.elastic_in_out(0.5))  -- midpoint
core.engine.print("info", util.easing.elastic_in_out(0.75)) -- near end
core.engine.print("info", util.easing.elastic_in_out(1.0))  -- 1.0
```

```lua lineNumbers title="Pair with lerp to animate a value"
local result = util.easing.lerp(0, 100, util.easing.elastic_in_out(0.5))

core.engine.print("info", result)
```

```lua lineNumbers title="Animate a circle across the screen"
local resolution = core.engine.get_resolution()
local duration = 1.5
local start_tick = core.engine.get_tick()

util.event.on("sandbox:draw", function()
    local elapsed = (core.engine.get_tick() - start_tick) / 1000.0
    local t = math.min(elapsed / duration, 1.0)
    local x = util.easing.lerp(0, resolution[1], util.easing.elastic_in_out(t))

    core.engine.draw_circle({x, resolution[2]*0.5}, 16, {1, 1, 1, 1})
end)
```
