---
title: util.easing.lerp
description: Linearly interpolates between two values by a progress factor
badge: shared
---

### Syntax

```lua
local result = util.easing.lerp(
    from,
    to,
    progress
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | from | Start value |
| `float` | to | End value |
| `float` | progress | Interpolation factor, typically in the range [0, 1] |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Interpolated value between `from` and `to` |

---

### Examples

```lua lineNumbers title="Interpolate between 0 and 100 at 50%"
local result = util.easing.lerp(0, 100, 0.5)

core.engine.print("info", result) -- 50.0
```

```lua lineNumbers title="Interpolate between two positions"
local start_x = 10
local end_x = 90
local result = util.easing.lerp(start_x, end_x, 0.25)

core.engine.print("info", result) -- 30.0
```

```lua lineNumbers title="Combine with an easing curve"
local progress = util.easing.cubic_in_out(0.5)
local result = util.easing.lerp(0, 200, progress)

core.engine.print("info", result) -- 100.0
```

```lua lineNumbers title="Animate a value over time"
local elapsed = 0.0
local duration = 2.0

-- called each frame
elapsed = elapsed + delta
local t = math.min(elapsed / duration, 1.0)
local x = util.easing.lerp(0, 500, util.easing.sine_in_out(t))

core.engine.print("info", x)
```
