---
title: util.easing.elastic_in
description: Applies an elastic ease-in — oscillates with increasing intensity before the motion begins
badge: shared
---

### Syntax

```lua
local result = util.easing.elastic_in(
    progress,
    amplitude,
    period
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | progress | Interpolation factor, typically in the range [0, 1] |
| `float` | amplitude | Oscillation scale. Defaults to `1.0` |
| `float` | period | Oscillation frequency. Defaults to `0.3` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Eased progress value |

<Callout type="info">
    The `amplitude` controls the oscillation scale and `period` controls the oscillation frequency.
</Callout>

---

### Examples

```lua lineNumbers title="Sample output at key progress values"
core.engine.print("info", util.easing.elastic_in(0.0)) -- 0.0 — at rest
core.engine.print("info", util.easing.elastic_in(0.25)) -- near start
core.engine.print("info", util.easing.elastic_in(0.5)) -- midpoint
core.engine.print("info", util.easing.elastic_in(1.0)) -- 1.0 — complete
```

```lua lineNumbers title="Animate a value from 0 to 100"
local result = util.easing.lerp(0, 100, util.easing.elastic_in(0.5))

core.engine.print("info", result)
```

```lua lineNumbers title="Drive with elapsed time"
local elapsed = 0.0
local duration = 1.5

-- called each frame
elapsed = elapsed + delta
local t = math.min(elapsed / duration, 1.0)
local value = util.easing.lerp(0, 500, util.easing.elastic_in(t))

core.engine.print("info", value)
```
