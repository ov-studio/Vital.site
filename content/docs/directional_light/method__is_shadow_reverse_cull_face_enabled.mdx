---
title: self:is_shadow_reverse_cull_face_enabled
description: Checks whether shadow reverse cull face is enabled on the directional light
badge: client
---

### Syntax

```lua
local result = self:is_shadow_reverse_cull_face_enabled()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if shadow reverse cull face is enabled, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check is shadow reverse cull face enabled on a directional light"
local entity = light.directional_light.create()

core.engine.print("info", entity:is_shadow_reverse_cull_face_enabled())
```
