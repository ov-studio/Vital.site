---
title: self:set_angular_distance
description: Sets the angular distance of the directional light in degrees, controlling shadow softness by simulating a light source with angular size
badge: client
---

### Syntax

```lua
local status = self:set_angular_distance(
    degrees
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | degrees | Angular distance in degrees to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the angular distance to simulate a soft sun"
local entity = light.directional_light.create()

entity:set_angular_distance(0.5)
```
