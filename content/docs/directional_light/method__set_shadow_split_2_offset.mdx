---
title: self:set_shadow_split_2_offset
description: Sets the split 2 offset of the directional light's cascade shadow map, as a proportion of the shadow max distance
badge: client
---

### Syntax

```lua
local status = self:set_shadow_split_2_offset(
    offset
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | offset | Split 2 offset to apply, from `0.0` to `1.0` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set split 2 offset on a directional light"
local entity = light.directional_light.create()

entity:set_shadow_split_2_offset(0.2)
```
