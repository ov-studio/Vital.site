---
title: self:set_negative
description: Sets whether the directional light operates in negative mode, subtracting light from the scene
badge: client
---

### Syntax

```lua
local status = self:set_negative(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to enable negative mode, `false` to disable |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply negative on a directional light"
local entity = light.directional_light.create()

entity:set_negative(true)
```
