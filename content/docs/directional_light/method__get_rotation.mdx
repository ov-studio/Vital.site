---
title: self:get_rotation
description: Retrieves the local rotation of the directional light
badge: client
---

### Syntax

```lua
local rotation = self:get_rotation()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Current local rotation in degrees as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the local rotation of a directional light"
local entity = light.directional_light.create()
local rotation = entity:get_rotation()

core.engine.print("info", "Rotation:", util.table.unpack(rotation))
```
