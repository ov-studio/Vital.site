---
title: self:set_bake_mode
description: Sets the bake mode of the directional light
badge: client
---

### Syntax

```lua
local status = self:set_bake_mode(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | mode | Bake mode enum value to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply bake mode on a directional light"
local entity = light.directional_light.create()

entity:set_bake_mode(1)
```
