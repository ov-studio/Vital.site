---
title: light.directional_light.sky_mode
description: Enumeration of sky interaction modes for the directional light
badge: client
---

### Values

| Constant | Description |
|----------|-------------|
| `light.directional_light.sky_mode.LIGHT_AND_SKY` | The directional light affects both scene geometry and the sky shader. This is the default mode |
| `light.directional_light.sky_mode.LIGHT_ONLY` | The directional light affects scene geometry only and has no influence on the sky shader |
| `light.directional_light.sky_mode.SKY_ONLY` | The directional light affects the sky shader only and has no influence on scene geometry |

---

### Examples

```lua lineNumbers title="Set a directional light to affect geometry only"
local entity = light.directional_light.create()

entity:set_sky_mode(light.directional_light.sky_mode.LIGHT_ONLY)
```
