---
title: light.directional_light.create
description: Creates a new directional light instance and adds it to the scene
badge: client
---

### Syntax

```lua
local instance = light.directional_light.create()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `directional_light` | instance | Created directional light instance |

---

### Examples

```lua lineNumbers title="Create a directional light instance"
local entity = light.directional_light.create()

entity:set_color({1, 1, 1})
entity:set_energy(1.0)
entity:set_position({0, 5, 0})
```
