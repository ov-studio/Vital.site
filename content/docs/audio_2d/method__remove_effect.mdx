---
title: self:remove_effect
description: Removes an audio effect from the audio-2d instance's effect chain
badge: Client
---

### Syntax

```lua
local status = self:remove_effect(
    id
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | id | Index of the effect to remove, as returned by [`self:add_effect()`](/docs/audio_2d/method/add_effect) |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Remove an effect from an audio-2d instance"
local entity = core.audio_2d.create("sounds/ambient.ogg")

local id = entity:add_effect("reverb", { wet = 0.5 })

entity:remove_effect(id)
```
