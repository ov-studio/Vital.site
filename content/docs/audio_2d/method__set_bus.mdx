---
title: self:set_bus
description: Sets the audio bus the audio_2d instance is routed through
badge: Client
---

### Syntax

```lua
local status = self:set_bus(
    bus
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | bus | Name of the audio bus to route playback through |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Route an audio_2d instance to a custom bus"
local entity = core.audio_2d.create("sounds/ambient.ogg")

entity:set_bus("Ambient")
```
