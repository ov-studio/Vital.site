---
title: self:set_volume
description: Sets the volume of the audio-2d instance
badge: Client
---

### Syntax

```lua
local status = self:set_volume(
    volume
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | volume | Linear volume. `1.0` is full volume, `0.0` is silent |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Reduce the volume of an audio-2d instance"
local entity = core.audio_2d.create("sounds/ambient.ogg")

entity:set_volume(0.5)
```
