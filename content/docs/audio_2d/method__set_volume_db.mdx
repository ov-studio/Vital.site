---
title: self:set_volume_db
description: Sets the volume of the audio_2d instance in decibels
badge: Client
---

### Syntax

```lua
local status = self:set_volume_db(
    volume_db
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | volume_db | Volume in decibels. `0.0` is full volume, negative values reduce it |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Reduce the volume of an audio_2d instance"
local entity = core.audio_2d.create("sounds/ambient.ogg")

entity:set_volume_db(-10.0)
```
