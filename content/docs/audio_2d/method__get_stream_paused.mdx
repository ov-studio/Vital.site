---
title: self:get_stream_paused
description: Checks whether the audio_2d stream is currently paused
badge: Client
---

### Syntax

```lua
local result = self:get_stream_paused()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the stream is paused, `false` otherwise |

---

### Examples

```lua lineNumbers title="Resume a paused audio_2d stream"
local entity = core.audio_2d.create("sounds/ambient.ogg")
entity:play()
entity:set_stream_paused(true)

if entity:get_stream_paused() then
    entity:set_stream_paused(false)
end
```
