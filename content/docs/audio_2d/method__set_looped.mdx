---
title: self:set_looped
description: Sets whether the audio-2d instance loops playback
badge: client
---

### Syntax

```lua
local status = self:set_looped(
    loop
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | loop | Determines the looping behavior of playback:<br/>• When `true` - the stream restarts automatically once it reaches the end<br/>• When `false` - the stream stops once it reaches the end |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Loop an ambient audio-2d instance"
local entity = core.audio_2d.create("sounds/ambient.ogg")

entity:set_looped(true)
entity:play()
```
