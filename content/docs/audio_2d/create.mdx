---
title: core.audio_2d.create
description: Creates a new audio_2d instance from a file path
badge: Client
---

### Syntax

```lua
local instance = core.audio_2d.create(
    path
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | path | File path to the audio asset. Supported formats: `.ogg`, `.wav`, `.mp3` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `audio_2d` | instance | Created audio_2d instance |

---

### Examples

```lua lineNumbers title="Create a basic audio_2d instance"
local entity = core.audio_2d.create("sounds/ambient.ogg")
```

```lua lineNumbers title="Create a quieter instance on a custom bus, then play it"
local entity = core.audio_2d.create("sounds/ambient.ogg")
entity:set_volume_db(-10.0)
entity:set_bus("Ambient")
entity:play()
```
