---
title: self:set_stream_paused
description: Sets the paused state of the audio_2d stream
badge: Client
---

### Syntax

```lua
local status = self:set_stream_paused(
    pause
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | pause | When `true`, pauses the stream while preserving the playback position. When `false`, resumes from where it was paused |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Pause and resume an audio_2d stream"
local entity = core.audio_2d.create("sounds/ambient.ogg")
entity:play()

-- Pause
entity:set_stream_paused(true)

-- Resume
entity:set_stream_paused(false)
```
