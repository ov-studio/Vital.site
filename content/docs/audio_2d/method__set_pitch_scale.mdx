---
title: self:set_pitch_scale
description: Sets the pitch scale of the audio-2d instance
badge: Client
---

### Syntax

```lua
local status = self:set_pitch_scale(
    pitch_scale
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | pitch_scale | Pitch multiplier to apply<br/>`1.0` is normal pitch, `2.0` doubles it, and higher or lower values scale accordingly |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set a higher pitch on an audio-2d instance"
local entity = core.audio_2d.create("sounds/sfx.ogg")

entity:set_pitch_scale(1.5)
```
