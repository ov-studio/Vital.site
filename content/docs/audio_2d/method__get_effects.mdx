---
title: self:get_effects
description: Retrieves the names of all audio effects applied to the audio-2d instance
badge: Client
---

### Syntax

```lua
local effects = self:get_effects()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `table` | effects | Array of effect name strings in chain order |

---

### Examples

```lua lineNumbers title="List all effects on an audio-2d instance"
local entity = core.audio_2d.create("sounds/ambient.ogg")

entity:add_effect("my_reverb", "reverb")
entity:add_effect("my_amp", "amplify", { volume_db = 6.0 })

local effects = entity:get_effects()

for i, name in ipairs(effects) do
    core.engine.print("info", i, name)
end
-- 1   my_reverb
-- 2   my_amp
```
