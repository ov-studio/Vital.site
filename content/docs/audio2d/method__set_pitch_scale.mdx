---
title: self:set_pitch_scale
description: Sets the pitch scale of the Audio2D instance
badge: Client
---

### Syntax

```lua
local status = self:set_pitch_scale(
    pitch_scale
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | pitch_scale | Pitch multiplier. `1.0` is normal pitch, `2.0` doubles it, `0.5` halves it |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set a higher pitch on an Audio2D instance"
local entity = core.audio2d.create("sounds/sfx.ogg")

entity:set_pitch_scale(1.5)
```
