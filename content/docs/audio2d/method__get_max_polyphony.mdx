---
title: self:get_max_polyphony
description: Retrieves the maximum number of simultaneous voices for the Audio2D instance
badge: Client
---

### Syntax

```lua
local result = self:get_max_polyphony()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | result | Maximum number of simultaneous voices |

---

### Examples

```lua lineNumbers title="Get the max polyphony of an Audio2D instance"
local entity = core.audio2d.create("sounds/sfx.ogg")

core.engine.print("info", "Max polyphony:", entity:get_max_polyphony())
```
