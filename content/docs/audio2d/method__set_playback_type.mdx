---
title: self:set_playback_type
description: Sets the playback type of the Audio2D instance
badge: Client
---

### Syntax

```lua
local status = self:set_playback_type(
    type
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`core.audio2d.playback_type`](/docs/audio2d/enum/playback_type) | type | Playback type to apply to the instance |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Use sample-based playback for a short sound effect"
local entity = core.audio2d.create("sounds/sfx.ogg")

entity:set_playback_type(core.audio2d.playback_type.SAMPLE)
```

```lua lineNumbers title="Use stream-based playback for a long music track"
local entity = core.audio2d.create("sounds/music.ogg")

entity:set_playback_type(core.audio2d.playback_type.STREAM)
```
