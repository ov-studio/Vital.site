---
title: self:destroy
description: Destroys the Audio2D instance and frees its resources
badge: Client
---

### Syntax

```lua
local status = self:destroy()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Destroy an Audio2D instance"
local entity = core.audio2d.create("sounds/ambient.ogg")

entity:destroy()
```
