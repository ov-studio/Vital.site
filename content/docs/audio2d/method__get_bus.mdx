---
title: self:get_bus
description: Retrieves the name of the audio bus the Audio2D instance is routed through
badge: Client
---

### Syntax

```lua
local result = self:get_bus()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `string` | result | Name of the current audio bus |

---

### Examples

```lua lineNumbers title="Get the bus of an Audio2D instance"
local entity = core.audio2d.create("sounds/ambient.ogg")

core.engine.print("info", "Bus:", entity:get_bus())
```
