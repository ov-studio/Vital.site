---
title: resource:stopped
description: Fired when a resource has been stopped
badge: shared
---

### Signal

```
resource:stopped
```

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Name of the resource that was stopped |

### Notes

Fires after a resource has been stopped and its scripts unloaded. On the server this also broadcasts a stop packet to all connected clients. Use this to clean up any state tied to a specific resource.

---

### Example

```lua lineNumbers title="React to a resource stopping"
util.event.on("resource:stopped", function(name)
    core.engine.print("info", "Resource stopped:", name)
end)
```
