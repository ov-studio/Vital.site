---
title: resource:started
description: Fired when a resource has started successfully
badge: shared
---

### Signal

```
resource:started
```

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Name of the resource that started |

### Notes

Fires after a resource's scripts have been loaded and executed. On the server this also triggers a broadcast to all connected clients so they register and start their local copy of the resource.

---

### Example

```lua lineNumbers title="React to a resource starting"
util.event.on("resource:started", function(name)
    core.engine.print("info", "Resource started:", name)
end)
```
