---
title: sandbox:ready
description: Fired when the sandbox manager has finished initialising
badge: shared
---

### Signal

```
sandbox:ready
```

### Arguments

| No arguments are passed by this signal |
|----------------------------------------|

<Callout type="info">
  **This is the earliest signal available to Lua.**

  - For general game logic, prefer listening to [`core:ready`](/docs/engine) which fires after resources and subsystems are fully up.
  - Use `sandbox:ready` only when you need to react before resources begin loading.
</Callout>

---

### Example

```lua lineNumbers title="Detect sandbox ready"
util.event.on("sandbox:ready", function()
    core.engine.print("info", "Sandbox is ready")
end)
```
