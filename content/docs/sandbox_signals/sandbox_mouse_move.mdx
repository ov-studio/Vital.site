---
title: sandbox:mouse_move
description: Fired whenever the mouse cursor moves
badge: client
---

### Signal

```
sandbox:mouse_move
```

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `float` | x | Horizontal cursor position in pixels from the left of the viewport |
| `float` | y | Vertical cursor position in pixels from the top of the viewport |

### Notes

Fires for every mouse motion event. Can fire multiple times per frame under fast cursor movement. Coordinates are viewport-space pixels.

---

### Example

```lua lineNumbers title="Track cursor position"
local mx, my = 0, 0

util.event.on("sandbox:mouse_move", function(x, y)
    mx, my = x, y
end)

util.event.on("sandbox:draw", function()
    core.engine.draw_text("Cursor: " .. mx .. ", " .. my, 10, 10, 14)
end)
```
