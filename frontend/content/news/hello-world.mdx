## Creating a post

1. Create a new `.mdx` file in `frontend/content/news/`.
2. The file name becomes the URL, so `my-first-post.mdx` is served at `/news/my-first-post`.
3. Add the frontmatter block shown at the top of this file.
4. Write the post below it in Markdown.

## Frontmatter

| Field         | Required | Notes                                                    |
| ------------- | -------- | -------------------------------------------------------- |
| `title`       | Yes      | Post title                                               |
| `description` | No       | Shown on the news list and under the title               |
| `date`        | Yes      | `YYYY-MM-DD`, newest posts are listed first              |
| `author`      | No       | Defaults to `ov-studio`                                  |
| `tags`        | No       | List of tags, e.g. `[release, lua]`                      |
| `cover`       | No       | Banner image path, e.g. `/news/my-cover.png`             |
| `publish`     | No       | Set to `true` to show in the news feed. Defaults to off  |

Without a `cover`, a colorful banner is generated for the post automatically.

Posts with `publish: false` (or missing `publish`) never appear in the feed.

## Formatting

Regular Markdown works: **bold**, *italic*, [links](/docs), lists and blockquotes.

> Blockquotes look like this.

Code blocks are highlighted:

```lua
local function greet(name)
  print("Hello, " .. name)
end

greet("Vital")
```

## Images

Put images in `frontend/public/news/` and reference them by absolute path:

```md
![Alt text](/news/my-image.png)
```
