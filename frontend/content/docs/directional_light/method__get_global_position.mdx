---
title: self:get_global_position
description: Retrieves the global world-space position of the directional light
badge: client
---

### Syntax

```lua
local position = self:get_global_position()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Current global world-space position as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global world-space position of a directional light"
local entity = light.directional.create()
local position = entity:get_global_position()

core.engine.print("info", "Directional light position:", util.table.unpack(position))
```
