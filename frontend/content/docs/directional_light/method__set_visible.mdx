---
title: self:set_visible
description: Sets the visibility of the directional light
badge: client
---

### Syntax

```lua
local status = self:set_visible(
    visible
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | visible | Determines the visibility of the directional light:<br/>• When `true` - the directional light is shown<br/>• When `false` - the directional light is hidden |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Hide a directional light"
local entity = light.directional.create()

entity:set_visible(false)
```
