---
title: self:get_global_scale
description: Retrieves the global world-space scale of the directional light
badge: client
---

### Syntax

```lua
local scale = self:get_global_scale()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Current global scale as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global scale of a directional light"
local entity = light.directional.create()

core.engine.print("info", "Scale:", util.table.unpack(entity:get_global_scale()))
```
