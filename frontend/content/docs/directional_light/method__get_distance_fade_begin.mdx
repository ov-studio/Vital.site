---
title: self:get_distance_fade_begin
description: Retrieves the distance at which the directional light begins to fade out
badge: client
---

### Syntax

```lua
local distance = self:get_distance_fade_begin()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | distance | Fade begin distance in world units |

---

### Examples

```lua lineNumbers title="Get distance fade begin of a directional light"
local entity = light.directional.create()

core.engine.print("info", "Distance Fade Begin:", entity:get_distance_fade_begin())
```
