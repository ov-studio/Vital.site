---
title: self:is_visible
description: Checks whether the directional light is set as visible
badge: client
---

### Syntax

```lua
local result = self:is_visible()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the directional light is visible, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check visibility of a directional light"
local entity = light.directional.create()

core.engine.print("info", "Visible:", entity:is_visible())
```
