---
title: self:set_blend_splits_enabled
description: Sets whether blend splits is enabled on the directional light, blending between cascade shadow levels to reduce visible seams
badge: client
---

### Syntax

```lua
local status = self:set_blend_splits_enabled(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to enable blend splits, `false` to disable |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable blend splits on a directional light"
local entity = light.directional.create()

entity:set_blend_splits_enabled(true)
```
