---
title: self:to_local
description: Converts a world-space position to local-space relative to the directional light
badge: client
---

### Syntax

```lua
local local_position = self:to_local(
    global_point
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | global_point | Position in world space as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | local_position | Equivalent position in local space as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Convert a world position to the directional light's local space"
local entity = light.directional.create()
entity:set_position({10, 0, 0})

local local_pos = entity:to_local({10, 0, 5})
core.engine.print("info", util.table.unpack(local_pos))
```
