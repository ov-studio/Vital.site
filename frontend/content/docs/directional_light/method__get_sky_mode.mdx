---
title: self:get_sky_mode
description: Retrieves the sky interaction mode of the directional light
badge: client
---

### Syntax

```lua
local mode = self:get_sky_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`light.directional.sky_mode`](/docs/directional_light/enum/sky_mode) | mode | Current sky mode |

---

### Examples

```lua lineNumbers title="Get the sky mode of a directional light"
local entity = light.directional.create()

core.engine.print("info", "Sky Mode:", entity:get_sky_mode())
```
