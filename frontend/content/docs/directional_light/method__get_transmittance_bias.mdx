---
title: self:get_transmittance_bias
description: Retrieves the transmittance bias of the directional light used for subsurface scattering
badge: client
---

### Syntax

```lua
local bias = self:get_transmittance_bias()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | bias | Current transmittance bias value |

---

### Examples

```lua lineNumbers title="Get transmittance bias of a directional light"
local entity = light.directional.create()

core.engine.print("info", "Transmittance Bias:", entity:get_transmittance_bias())
```
