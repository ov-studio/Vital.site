---
title: self:get_shadow_mode
description: Retrieves the shadow rendering mode of the directional light
badge: client
---

### Syntax

```lua
local result = self:get_shadow_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`light.directional.shadow_mode`](/docs/directional_light/enum/shadow_mode) | result | Current shadow mode |

---

### Examples

```lua lineNumbers title="Get the shadow mode of a directional light"
local entity = light.directional.create()

core.engine.print("info", "Shadow Mode:", entity:get_shadow_mode())
```
