---
title: self:get_dimension
description: Retrieves the dimension of the directional light
badge: client
---

### Syntax

```lua
local dimension = self:get_dimension()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Current dimension id, inherited from the parent entity when none is set directly (`0` by default) |

---

### Examples

```lua lineNumbers title="Get the dimension of a directional light"
local entity = light.directional.create()

core.engine.print("info", "Directional light dimension:", entity:get_dimension())
```
