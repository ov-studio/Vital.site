---
title: gfx.sky.set_rotation
description: Sets the rotation of the sky
badge: client
---

### Syntax

```lua
local status = gfx.sky.set_rotation(
    rotation
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Sky rotation to apply in degrees as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set sky rotation"
gfx.sky.set_rotation({0, 90, 0})
```
