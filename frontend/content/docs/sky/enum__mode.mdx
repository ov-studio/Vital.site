title: gfx.sky.mode
description: Enumeration of supported sky material types
badge: client
---

### Values

| Constant | Description |
|----------|-------------|
| `gfx.sky.mode.PANORAMA` | Panorama sky material — renders a static equirectangular texture as the sky |
| `gfx.sky.mode.PROCEDURAL` | Procedural sky material — a stylized, tunable gradient sky with sun and cloud cover |
| `gfx.sky.mode.PHYSICAL` | Physical sky material — a physically based atmospheric scattering sky |
