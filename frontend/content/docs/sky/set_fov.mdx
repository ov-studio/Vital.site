---
title: gfx.sky.set_fov
description: Sets the custom field of view of the sky
badge: client
---

### Syntax

```lua
local status = gfx.sky.set_fov(
    fov
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | fov | Sky custom field of view to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set sky field of view"
gfx.sky.set_fov(0.0)
```
