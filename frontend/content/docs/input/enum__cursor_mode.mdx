title: util.input.cursor_mode
description: Enumeration of supported cursor visibility and confinement modes
badge: client
---

### Values

| Constant | Description |
|----------|-------------|
| `util.input.cursor_mode.VISIBLE` | Cursor is visible and confined to the game window — use for in-game menus, HUDs, and inventory. Stays visible as long as any resource requests it |
| `util.input.cursor_mode.HIDDEN` | Cursor is hidden but still moves freely and can leave the window |
| `util.input.cursor_mode.CAPTURED` | Cursor is hidden and locked to the window center — ideal for FPS-style camera control<br/>Raw mouse delta is still reported via [`util.input.get_cursor_velocity`](/docs/input/get_cursor_velocity) |
