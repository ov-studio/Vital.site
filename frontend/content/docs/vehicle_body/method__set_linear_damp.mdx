---
title: self:set_linear_damp
description: Sets the linear damping of the vehicle body
badge: client
---

### Syntax

```lua
local status = self:set_linear_damp(
    damp
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | damp | Linear damping value to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the linear damp of a vehicle body"
local entity = physics.vehicle.create()

entity:set_linear_damp(0.1)
```
