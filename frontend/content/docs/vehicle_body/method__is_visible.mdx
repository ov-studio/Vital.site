---
title: self:is_visible
description: Checks whether the vehicle body is visible
badge: client
---

### Syntax

```lua
local result = self:is_visible()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if visible, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check visibility of a vehicle body"
local entity = physics.vehicle.create()

core.engine.print("info", "Vehicle body visible:", entity:is_visible())
```
