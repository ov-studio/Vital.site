---
title: self:get_global_scale
description: Retrieves the global scale of the vehicle body
badge: client
---

### Syntax

```lua
local scale = self:get_global_scale()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Current global scale as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global scale of a vehicle body"
local entity = physics.vehicle.create()
local scale = entity:get_global_scale()

core.engine.print("info", "Scale:", util.table.unpack(scale))
```
