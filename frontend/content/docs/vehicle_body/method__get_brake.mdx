---
title: self:get_brake
description: Retrieves the whole-chassis brake force of the vehicle body
badge: shared
---

### Syntax

```lua
local result = self:get_brake()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current brake force |

---

### Examples

```lua lineNumbers title="Get the brake force of a vehicle body"
local entity = physics.vehicle.create()

core.engine.print("info", "Vehicle body brake:", entity:get_brake())
```
