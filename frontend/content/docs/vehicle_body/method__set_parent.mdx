---
title: self:set_parent
description: Attaches the vehicle body to another entity, or detaches it when no entity is given
badge: shared
---

### Syntax

```lua
local status = self:set_parent(
    entity = nil
)
```

<Callout type="warn">
  **Parenting between server and client entities is restricted.**

  - **On the client** — cannot be called on a server entity; raises an error.
  - **On the server** — a server entity can only be parented to another server (network-synced) entity.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `entity` | entity | Parent entity instance, omit or pass `nil` to detach the instance |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` if the reparent is invalid (target is itself or one of its descendants) |

---

### Examples

```lua lineNumbers title="Parent one vehicle body to another"
local parent = physics.vehicle.create()
local child = physics.vehicle.create()

child:set_parent(parent)
```

```lua lineNumbers title="Detach a vehicle body from its parent"
local parent = physics.vehicle.create()
local child = physics.vehicle.create()

child:set_parent(parent)
child:set_parent()
```
