---
title: self:set_freeze_mode
description: Sets the freeze mode of the vehicle body
badge: shared
---

### Syntax

```lua
local status = self:set_freeze_mode(
    mode
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/vehicle_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`physics.vehicle.freeze_mode`](/docs/vehicle_body/enum/freeze_mode) | mode | Freeze mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the freeze mode of a vehicle body"
local entity = physics.vehicle.create()

entity:set_freeze_mode(physics.vehicle.freeze_mode.KINEMATIC)
```
