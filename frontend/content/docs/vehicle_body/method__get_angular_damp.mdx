---
title: self:get_angular_damp
description: Retrieves the angular damping of the vehicle body
badge: shared
---

### Syntax

```lua
local result = self:get_angular_damp()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current angular damping |

---

### Examples

```lua lineNumbers title="Get the angular damp of a vehicle body"
local entity = physics.vehicle.create()

core.engine.print("info", "Vehicle body angular damp:", entity:get_angular_damp())
```
