---
title: self:set_collision_layer_value
description: Sets a specific bit on the vehicle body's collision layer
badge: shared
---

### Syntax

```lua
local status = self:set_collision_layer_value(
    layer_number,
    value
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/vehicle_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | layer_number | Layer bit index to set (1-32) |
| `bool` | value | Determines whether the bit is enabled:<br/>• When `true` - the bit is enabled<br/>• When `false` - the bit is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set a collision layer bit on a vehicle body"
local entity = physics.vehicle.create()

entity:set_collision_layer_value(2, true)
```
