---
title: self:get_type
description: Retrieves the type name of this vehicle body instance
badge: client
---

### Syntax

```lua
local type = self:get_type()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `string` | type | Type name of the instance, e.g. "physics.vehicle" |

---

### Examples

```lua lineNumbers title="Get the type of a vehicle body"
local entity = physics.vehicle.create()

core.engine.print("info", entity:get_type())
```
