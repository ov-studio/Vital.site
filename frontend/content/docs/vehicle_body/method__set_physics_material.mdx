---
title: self:set_physics_material
description: Applies a physics material to the vehicle body, controlling friction and bounce behavior
badge: shared
---

### Syntax

```lua
local status = self:set_physics_material(
    friction,
    bounce,
    rough = false,
    absorbent = false
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/vehicle_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | friction | Friction coefficient to apply |
| `float` | bounce | Bounce (restitution) coefficient to apply |
| `bool` | rough | Determines the friction combining behavior:<br/>• When `true` - friction combining favors the rougher surface<br/>• When `false` - friction combining does not favor the rougher surface |
| `bool` | absorbent | Determines the bounce combining behavior:<br/>• When `true` - bounce combining favors the less bouncy surface<br/>• When `false` - bounce combining does not favor the less bouncy surface |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply a physics material on a vehicle body"
local entity = physics.vehicle.create()

entity:set_physics_material(0.5, 0.2)
```
