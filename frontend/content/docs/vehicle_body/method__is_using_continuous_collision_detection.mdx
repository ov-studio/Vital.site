---
title: self:is_using_continuous_collision_detection
description: Checks whether continuous collision detection (CCD) is enabled on the vehicle body
badge: client
---

### Syntax

```lua
local result = self:is_using_continuous_collision_detection()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the condition is met, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check CCD on a vehicle body"
local entity = physics.vehicle.create()

core.engine.print("info", entity:is_using_continuous_collision_detection())
```
