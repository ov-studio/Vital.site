---
title: self:get_engine_force
description: Retrieves the whole-chassis engine force of the vehicle body
badge: shared
---

### Syntax

```lua
local result = self:get_engine_force()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current engine force |

---

### Examples

```lua lineNumbers title="Get the engine force of a vehicle body"
local entity = physics.vehicle.create()

core.engine.print("info", "Vehicle body engine force:", entity:get_engine_force())
```
