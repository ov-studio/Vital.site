---
title: self:look_at_from_position
description: Moves the vehicle body to a position and rotates it so its -Z axis points toward the given target
badge: shared
---

### Syntax

```lua
local status = self:look_at_from_position(
    position,
    target,
    up = {0, 1, 0}
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/vehicle_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | World-space position to move to as `{x, y, z}` |
| `vector3` | target | World-space position to look at as `{x, y, z}` |
| `vector3` | up | Up vector used to determine orientation as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Position and point a vehicle body"
local entity = physics.vehicle.create()

entity:look_at_from_position({0, 10, 0}, {0, 0, 0}, {0, 1, 0})
```
