---
title: self:get_linear_damp
description: Retrieves the linear damping of the vehicle body
badge: shared
---

### Syntax

```lua
local result = self:get_linear_damp()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current linear damping |

---

### Examples

```lua lineNumbers title="Get the linear damp of a vehicle body"
local entity = physics.vehicle.create()

core.engine.print("info", "Vehicle body linear damp:", entity:get_linear_damp())
```
