---
title: core.image.create
description: Creates a new image instance from a file path
badge: client
---

### Syntax

```lua
local instance = core.image.create(
    path,
    mipmaps = false
)
```

<Callout type="info">
  **Only needed if you already know a mipmap-based filter is coming.**

  - **Use it when** — an image is going to use `NEAREST_MIPMAP`, `LINEAR_MIPMAP`, or an `ANISOTROPIC` filter variant.
  - **Before compressing** — if both mipmaps and compression are needed, pass `true` here; [`self:compress`](/docs/image/method/compress) cannot generate mipmaps, so this is the only opportunity.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | path | File path to a supported image asset<br/>Refer [**Formats**](#formats) section |
| `bool` | mipmaps | Determines whether to generate a mipmap chain for the underlying image |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `image` | instance | Created image instance |

---

### Formats

| Format | Extension | Description |
|--------|-----------|-------------|
| JPEG | `.jpg` \| `.jpeg` | Lossy compressed image, best for photos |
| PNG | `.png` | Lossless compressed image, supports transparency |
| WebP | `.webp` | Modern format, supports both lossy and lossless |
| BMP | `.bmp` | Uncompressed bitmap, no lossy artifacts |
| DDS | `.dds` | GPU-native compressed format, ideal for 3D assets |
| KTX | `.ktx` \| `.ktx2` | Khronos texture format, supports GPU compression and mipmaps |

---

### Examples

```lua lineNumbers title="Create an image instance from a JPEG file"
local entity = core.image.create("assets/photo.jpg")
```

```lua lineNumbers title="Create an image instance from a PNG file"
local entity = core.image.create("assets/sprite.png")
```

```lua lineNumbers title="Create an image instance from a WebP file"
local entity = core.image.create("assets/image.webp")
```

```lua lineNumbers title="Create an image instance from a DDS file"
local entity = core.image.create("assets/terrain.dds")
```

```lua lineNumbers title="Create an image with mipmaps"
local entity = core.image.create("assets/terrain/cliff_diffuse.png", true)

entity:set_filter(core.image.texture_filter.LINEAR_MIPMAP_ANISOTROPIC)
```
