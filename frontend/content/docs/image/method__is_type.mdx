---
title: self:is_type
description: Checks whether the instance belongs to the specified type
badge: client
---

### Syntax

```lua
local result = self:is_type(
    name
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Type to check against |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the instance matches the given type, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check the type of an image instance"
local entity = core.image.create("assets/sprite.png")

core.engine.print("info", entity:is_type("image")) -- true
core.engine.print("info", entity:is_type("svg")) -- false
```
