---
title: self:is_compressed
description: Checks whether the image has been GPU block-compressed
badge: client
---

### Syntax

```lua
local result = self:is_compressed()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the image is GPU block-compressed, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check compression state before compressing"
local entity = core.image.create("assets/diffuse.png")

if not entity:is_compressed() then
    entity:compress(core.image.compression_mode.S3TC)
end
```

```lua lineNumbers title="Guard a convert call against compressed images"
local entity = core.image.create("assets/sprite.png")

if not entity:is_compressed() then
    entity:convert(core.image.texel_format.RGBA8)
end
```
