---
title: self:has_mipmaps
description: Checks whether the image has a generated mipmap chain
badge: client
---

### Syntax

```lua
local result = self:has_mipmaps()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the image has a mipmap chain, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check before applying a mipmap-based filter"
local entity = core.image.create("assets/diffuse.png")

if entity:has_mipmaps() then
    entity:set_filter(core.image.texture_filter.LINEAR_MIPMAP_ANISOTROPIC)
end
```

```lua lineNumbers title="Guard a compress call that requires mipmaps"
local entity = core.image.create("assets/terrain/cliff_diffuse.png")

if entity:has_mipmaps() then
    entity:set_filter(core.image.texture_filter.LINEAR_MIPMAP)
    entity:compress(core.image.compression_mode.BPTC)
end
```
