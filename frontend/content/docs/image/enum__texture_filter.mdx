---
title: core.image.texture_filter
description: Enumeration of sampling filters that can be applied to an individual image, overriding whatever draws it
badge: client
---

### Values

Constants are ordered from the shared default through crisp (nearest) to smooth (linear) sampling.

| Constant | Description |
|----------|-------------|
| `core.image.texture_filter.DEFAULT` | No per-image override — inherits whatever filter the drawing call defaults to |
| `core.image.texture_filter.NEAREST` | Point sampling — crisp, blocky edges, no blur at non-integer scales; ideal for pixel art |
| `core.image.texture_filter.NEAREST_MIPMAP` | Nearest sampling with mipmaps<br/>Requires the source to have mip levels — <br/>generate via [`core.image.create`](/docs/image/create)'s `mipmaps` parameter |
| `core.image.texture_filter.NEAREST_MIPMAP_ANISOTROPIC` | Nearest sampling with anisotropic mipmaps<br/>Requires the source to have mip levels — <br/>generate via [`core.image.create`](/docs/image/create)'s `mipmaps` parameter |
| `core.image.texture_filter.LINEAR` | Bilinear sampling — smooth, blurred edges at non-integer scales; the effective default before any override is set |
| `core.image.texture_filter.LINEAR_MIPMAP` | Linear sampling with mipmaps<br/>Requires the source to have mip levels — <br/>generate via [`core.image.create`](/docs/image/create)'s `mipmaps` parameter |
| `core.image.texture_filter.LINEAR_MIPMAP_ANISOTROPIC` | Linear sampling with anisotropic mipmaps<br/>Requires the source to have mip levels — <br/>generate via [`core.image.create`](/docs/image/create)'s `mipmaps` parameter |
