---
title: self:get_size
description: Retrieves the current size of the image
badge: client
---

### Syntax

```lua
local size = self:get_size()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector2` | size | Current size of the image as `{width, height}` |

---

### Examples

```lua lineNumbers title="Get the size of an image"
local entity = core.image.create("assets/sprite.png")
local size = entity:get_size()

core.engine.print("info", "Image size:", util.table.unpack(size))
```
