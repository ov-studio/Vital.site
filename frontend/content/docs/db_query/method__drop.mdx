---
title: self:drop
description: Drops the table from the database and removes it from the schema
badge: server
---

### Syntax

```lua
local promise = self:drop()
```

<Callout type="info">
  **This function returns a promise and starts processing the query.**

  - **Result** — use [`thread:await`](/docs/thread/method/await) inside a thread to retrieve the result.
  - **Inside a thread** — `self:await(db_query:drop())` waits for completion and returns the resolved values.
  - **Outside a thread** — the promise is still created, but must be awaited from a thread.
</Callout>

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `promise` | promise | See the [**Settlements**](#settlements) section |

---

### Settlements

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on success, `false` otherwise |
| `bool` | resolved | true |
| `string` | rejected | Error message describing the failure |

---

### Examples

```lua lineNumbers title="Drop the 'players' table from the database"
local db = core.database.create("127.0.0.1", "root", "", "vital_sandbox")

util.thread.create(function(self)
    local ok, err = self:await(db:table("players")
        :drop())

    if not ok then
        core.engine.print("error", err)
    end
end):resume()
```
