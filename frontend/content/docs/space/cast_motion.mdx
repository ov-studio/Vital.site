---
title: physics.space.cast_motion
description: Predicts how far a shape could travel along a motion vector before colliding, without actually moving anything
badge: shared
---

### Syntax

```lua
local motion_result = physics.space.cast_motion(
    shape,
    position,
    motion,
    options = {}
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `table` | shape | Shape descriptor table<br/>Refer [Shape](#shape) section |
| `vector3` | position | World-space starting position of the shape as `{x, y, z}` |
| `vector3` | motion | Motion vector to test as `{x, y, z}` |
| `table` | options | Optional query options table<br/>Refer [Options](#options) section |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `table` | motion_result | Table with `safe` and `unsafe` fractions of the motion that can be traveled, or `false` if the query failed |

---

### Shape

Shapes are described by a table, only the fields of the chosen `type` are read.

| Type | Key | Shape | Default | Description |
|------|-----|-------|---------|-------------|
| `string` | type | All | - | Shape kind to build<br/>• `"box"` - uses `size`<br/>• `"sphere"` - uses `radius`<br/>• `"capsule"` - uses `radius` and `height`<br/>• `"cylinder"` - uses `radius` and `height`<br/>Required, an unknown type makes the query return `false` |
| `vector3` | size | `box` | `{1, 1, 1}` | Full extents of the box as `{x, y, z}` |
| `number` | radius | `sphere`, `capsule`, `cylinder` | • `sphere` - `0.5`<br/>• `capsule`, `cylinder` - `0.4` | Radius of the shape |
| `number` | height | `capsule`, `cylinder` | `1.8` | Total height of the shape |

---

### Options

All fields are optional and fall back to their defaults if not specified.

| Type | Key | Default | Side | Description |
|------|-----|---------|------|-------------|
| `int` | mask | `4294967295` | Shared | Collision layers to test against, as a bitmask<br/>The default matches every layer |
| `table` | exclude | `{}` | Shared | Array of entities to ignore<br/>Only physics bodies and areas are accepted, any other value is skipped |
| `bool` | collide_bodies | `true` | Shared | • When `true` - physics bodies are tested<br/>• When `false` - physics bodies are ignored |
| `bool` | collide_areas | `false` | Shared | • When `true` - areas are tested<br/>• When `false` - areas are ignored |
| `int` | dimension | `0` | Shared | Dimension whose physics world is queried, from `0` to `65535`<br/>• Anything outside this range raises an error<br/>• A dimension with nothing in it simply finds nothing |

---

### Examples

```lua lineNumbers title="Predict a capsule's movement"
local motion_result = physics.space.cast_motion(
    { type = "capsule", radius = 0.4, height = 1.8 },
    position, {0, 0, -2}
)

core.engine.print("info", motion_result.safe)
```
