---
title: self:set_component_scale
description: Sets the local scale of a component on the model
badge: shared
---

### Syntax

```lua
local status = self:set_component_scale(
    component,
    scale,
    sync = true
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error when `sync` is `true`, as it is replicated.
  - **When `sync` is `false`** — only changes this client's local view, no ownership needed.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | component | Path of the component to update |
| `vector3` | scale | Scale to apply as `{x, y, z}` |
| `bool` | sync | Whether the change is replicated to other peers:<br/>• When `true` - it is replicated, and a client must own the entity or an error is raised<br/>• When `false` - it only applies on this client, and works on entities it doesn't own<br/>Ignored on the server, where changes are always replicated |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the local scale of a component"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")

entity:set_component_scale("Skeleton3D/Hat", {1.2, 1.2, 1.2})
```
