---
title: core.model.is_loaded
description: Retrieves whether a model has been loaded into memory
badge: shared
---

### Syntax

```lua
local result = core.model.is_loaded(
    name
)
```

<Callout type="idea">
  **Prefix the name with `:resourcename` to check a model loaded by another running resource.**

  - **Local name** — checks models loaded by the current resource.
  - **Cross-resource name** — prefix with `:resourcename` to check models loaded by another running resource.
  - **Example** — `:resource_a/character` checks the model `character` loaded by `resource_a`.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Name of the model to check |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the model is loaded, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check if a model is loaded"
core.engine.print("info", "Model loaded:", core.model.is_loaded("character"))
```

```lua lineNumbers title="Check if another resource's model is loaded"
core.engine.print("info", "Model loaded:", core.model.is_loaded(":resource_a/character"))
```
