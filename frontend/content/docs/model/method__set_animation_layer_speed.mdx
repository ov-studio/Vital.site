---
title: self:set_animation_layer_speed
description: Sets the playback speed of an animation layer
badge: shared
---

### Syntax

```lua
local status = self:set_animation_layer_speed(
    layer,
    speed,
    sync = true
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | layer | Index of the animation layer to modify |
| `float` | speed | New playback speed multiplier |
| `bool` | sync | Whether the call is replicated to other peers<br/>Defaults to `true` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Slow a layer down to half speed"
core.model.load("character", "models/character.glb")
local entity = core.model.create("character")

entity:play_animation_layer(0, "walk")
entity:set_animation_layer_speed(0, 0.5)
```
