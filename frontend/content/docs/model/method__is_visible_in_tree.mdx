---
title: self:is_visible_in_tree
description: Checks whether the model is visible in the current scene tree, accounting for parent visibility
badge: shared
---

### Syntax

```lua
local result = self:is_visible_in_tree()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if visible in the tree, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check tree visibility of a model"
core.model.load("character", "models/character.glb")
local entity = core.model.create("character")

core.engine.print("info", "Model visible in tree:", entity:is_visible_in_tree())
```
