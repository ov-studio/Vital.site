---
title: self:set_component_global_position
description: Sets the global position of a component on the model
badge: shared
---

### Syntax

```lua
local status = self:set_component_global_position(
    component,
    position
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | component | Path of the component to update |
| `vector3` | position | Global position to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the global position of a component"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")

entity:set_component_global_position("Skeleton3D/Hat", {0, 5, 0})
```
