---
title: core.model.unload
description: Unloads a previously loaded model from memory
badge: shared
---

### Syntax

```lua
local status = core.model.unload(
    name
)
```

<Callout type="info">
  **Only models loaded by the current resource can be unloaded.**

  - **Name scope** — `name` always resolves to a model of the current resource.
  - **No resource prefix** — `:resourcename` is not supported here, `name` is used as given.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Name of the model to unload |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Unload a loaded model from memory"
core.model.unload("character")
```
