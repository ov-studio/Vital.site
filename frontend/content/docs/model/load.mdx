---
title: core.model.load
description: Loads a model from a file path into memory under a given name
badge: shared
---

### Syntax

```lua
local status = core.model.load(
    name,
    path
)
```

<Callout type="info">
  **Models are always registered under the current resource.**

  - **Name scope** — `name` is registered as a model of the current resource.
  - **Access** — use `name` in the same resource, other resources must use `:resourcename/name`.
  - **Example** — `core.model.create(":resource_a/character")` uses `character` loaded by `resource_a`.
  - **No resource prefix** — `:resourcename` is not supported here, `name` is used as given.
  - **Cleanup** — models are unloaded automatically when the resource that loaded them stops.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Name to register the model under |
| `string` | path | File path to a supported model asset<br/>Refer [**Formats**](#formats) section |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Formats

| Format | Extension | Description |
|--------|-----------|-------------|
| GLB | `.glb` | Self contained binary GLTF asset |

---

### Examples

```lua lineNumbers title="Load a model from a GLB file"
core.model.load("character", "models/character.glb")
```
