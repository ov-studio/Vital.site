---
title: core.model.set_wireframe_all
description: Shows or hides the debug wireframe on all models, including ones created afterward
badge: client
---

### Syntax

```lua
local status = core.model.set_wireframe_all(
    state
)
```

<Callout type="info">
  **The wireframe follows the LOD that is currently drawn.**

  - **Level of detail** — the lines show the triangles of the active LOD, so you can watch a model thin out as the camera moves away, or as [`self:set_component_lod_bias`](/docs/model/method/set_component_lod_bias) changes.
  - **Local only** — this is a debug view on this client, it is never replicated to other peers.
  - **Overrides per-component choices** — every component of every model is set to `state`, refer [`self:set_component_wireframe`](/docs/model/method/set_component_wireframe) to toggle individual components.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to show wireframes on all models, `false` to hide them |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Toggle debug wireframes globally"
core.model.set_wireframe_all(true)
```
