---
title: core.model.set_wireframe_all
description: Shows or hides the debug wireframe on all models, including ones created afterward
badge: client
---

### Syntax

```lua
local status = core.model.set_wireframe_all(
    state
)
```

<Callout type="info">
  **The wireframe follows the mesh that is currently drawn.**

  - **Respects LOD** — draws whatever is currently visible, full detail or a lower LOD.
  - **Local only** — a debug view on this client, never replicated to other peers.
  - **Overrides components** — every component of every model is set to `state`.
  - **Per component** — use [`self:set_component_wireframe`](/docs/model/method/set_component_wireframe) to toggle individually.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines the wireframe visibility on all models:<br/>• When `true` - wireframes are shown on all models<br/>• When `false` - wireframes are hidden |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Toggle debug wireframes globally"
core.model.set_wireframe_all(true)
```
