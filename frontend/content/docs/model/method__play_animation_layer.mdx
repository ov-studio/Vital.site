---
title: self:play_animation_layer
description: Plays an animation on the given layer of the model
badge: shared
---

### Syntax

```lua
local status = self:play_animation_layer(
    layer,
    name,
    loop = true,
    speed = 1,
    weight = 1,
    blend_time = 0.25,
    sync = true
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error when `sync` is `true`, as it is replicated.
  - **When `sync` is `false`** — only changes this client's local view, no ownership needed.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | layer | Index of the animation layer to play on |
| `string` | name | Name of the animation to play |
| `bool` | loop | Determines whether the animation loops:<br/>• When `true` - the animation loops<br/>• When `false` - the animation plays once |
| `float` | speed | Playback speed multiplier |
| `float` | weight | Blend weight of the layer |
| `float` | blend_time | Time in seconds to blend into the animation |
| `bool` | sync | Whether the change is replicated to other peers:<br/>• When `true` - it is replicated, and a client must own the entity or an error is raised<br/>• When `false` - it only applies on this client, and works on entities it doesn't own<br/>Ignored on the server, where changes are always replicated |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Play a looping animation on layer 0"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")

entity:play_animation_layer(0, "idle")
```

```lua lineNumbers title="Layer an upper-body animation over a base animation"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")

entity:play_animation_layer(0, "walk")
entity:set_animation_layer_filter(1, true, {"Skeleton3D:spine", "Skeleton3D:arm_l", "Skeleton3D:arm_r"})
entity:play_animation_layer(1, "wave", false, 1, 1, 0.1)
```
