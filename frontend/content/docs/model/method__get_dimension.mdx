---
title: self:get_dimension
description: Retrieves the dimension of the model
badge: shared
---

### Syntax

```lua
local dimension = self:get_dimension()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Current dimension id |

---

### Examples

```lua lineNumbers title="Get the dimension of a model"
local entity = core.model.create("character")

core.engine.print("info", "Model dimension:", entity:get_dimension())
```
