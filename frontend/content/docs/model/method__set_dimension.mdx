---
title: self:set_dimension
description: Sets the dimension of the model
badge: shared
---

### Syntax

```lua
local status = self:set_dimension(
    dimension
)
```

<Callout type="idea">
  **Dimensions are fully isolated from each other.**

  - **Rendering** — the client only shows entities that match the dimension of its active camera.
  - **Hierarchy** — the dimension applies to the entity and all of its children.
  - **Attached** — a parented entity follows its parent's dimension, so setting its own raises an error.
</Callout>

<Callout type="warn">
  **Dimension changes on network-synced entities are restricted to their owner.**

  - **On the server** — the new dimension is replicated to all clients.
  - **On the client** — only the sync authority can change it, any other call raises an error.
</Callout>

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Dimension id to apply<br/>Must be within `0` to `65535` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the dimension of a model"
local entity = core.model.create("character")

entity:set_dimension(1)
```
