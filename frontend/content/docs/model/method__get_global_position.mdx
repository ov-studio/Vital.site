---
title: self:get_global_position
description: Retrieves the global position of the model
badge: shared
---

### Syntax

```lua
local position = self:get_global_position()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Current global position as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global position of a model"
core.model.load("character", "models/character.glb")
local entity = core.model.create("character")
local position = entity:get_global_position()

core.engine.print("info", "Model position:", util.table.unpack(position))
```
