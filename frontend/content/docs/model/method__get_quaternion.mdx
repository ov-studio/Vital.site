---
title: self:get_quaternion
description: Retrieves the local rotation of the model as a quaternion
badge: shared
---

### Syntax

```lua
local quaternion = self:get_quaternion()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `quaternion` | quaternion | Current rotation as `{x, y, z, w}` |

---

### Examples

```lua lineNumbers title="Get the quaternion of a model"
core.model.load("character", "models/character.glb")
local entity = core.model.create("character")
local quaternion = entity:get_quaternion()

core.engine.print("info", "Model quaternion:", util.table.unpack(quaternion))
```
