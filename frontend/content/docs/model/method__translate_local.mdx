---
title: self:translate_local
description: Translates the model by an offset in its own local coordinate space
badge: shared
---

### Syntax

```lua
local status = self:translate_local(
    offset
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error when the entity is owned by the server or by another client.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | offset | Offset to translate by as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Translate a model locally"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")

entity:translate_local({0, 0, -1})
```
