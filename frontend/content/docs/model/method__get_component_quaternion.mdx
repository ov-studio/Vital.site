---
title: self:get_component_quaternion
description: Retrieves the local rotation of a component on the model as a quaternion
badge: shared
---

### Syntax

```lua
local quaternion = self:get_component_quaternion(
    component
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | component | Path of the component to query |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `quaternion` | quaternion | Current local rotation of the component as `{x, y, z, w}` |

---

### Examples

```lua lineNumbers title="Get the quaternion of a component"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")
local quaternion = entity:get_component_quaternion("Skeleton3D/Hat")

core.engine.print("info", "Component quaternion:", util.table.unpack(quaternion))
```
