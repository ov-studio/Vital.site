---
title: self:get_components
description: Retrieves a list of all component paths on the model
badge: shared
---

### Syntax

```lua
local components = self:get_components(
    include_all = false
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | include_all | Determines which components are listed:<br/>• When `true` - components that are currently not rendered are listed as well<br/>• When `false` - only the components currently rendered on the model are listed |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `table` | components | Array of component path strings |

---

### Examples

```lua lineNumbers title="Print all component paths on a model"
local entity = core.model.create("character")
local components = entity:get_components()

core.engine.iprint(components)
```
