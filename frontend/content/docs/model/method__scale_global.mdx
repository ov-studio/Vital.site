---
title: self:scale_global
description: Scales the model in the global coordinate space
badge: shared
---

### Syntax

```lua
local status = self:scale_global(
    scale
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Scale factor to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Scale a model globally"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")

entity:scale_global({2, 2, 2})
```
