---
title: core.model.create
description: Creates a model instance from a previously loaded model
badge: shared
---

### Syntax

```lua
local entity = core.model.create(
    name
)
```

<Callout type="idea">
  **Prefix the name with `:resourcename` to use a model loaded by another running resource.**

  - **Local name** — resolves to a model loaded by the current resource.
  - **Cross-resource name** — prefix with `:resourcename` to resolve to a model loaded by another running resource.
  - **Example** — `:resource_a/character` instantiates the model `character` loaded by `resource_a`.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Name of the loaded model to instantiate |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `model` | instance | Created model instance |

---

### Examples

```lua lineNumbers title="Create an instance from a loaded model"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")
```

```lua lineNumbers title="Create an instance from another resource's model"
local entity = core.model.create(":resource_a/character")
```
