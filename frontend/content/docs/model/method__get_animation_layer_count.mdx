---
title: self:get_animation_layer_count
description: Retrieves the number of animation layers on the model
badge: shared
---

### Syntax

```lua
local count = self:get_animation_layer_count()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | count | Number of animation layers |

---

### Examples

```lua lineNumbers title="Get the number of animation layers"
core.model.load("character", "models/character.glb")
local entity = core.model.create("character")

core.engine.print("info", "Layers:", entity:get_animation_layer_count())
```
