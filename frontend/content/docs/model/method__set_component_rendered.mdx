---
title: self:set_component_rendered
description: Sets whether a component of the model is rendered
badge: shared
---

### Syntax

```lua
local status = self:set_component_rendered(
    component,
    state,
    sync = true
)
```

<Callout type="info">
  **Rendered state is separate from visibility.**

  - See [`self:set_component_visible`](/docs/model/method/set_component_visible) to toggle the component's visibility instead.
  - A component that stops rendering is kept alive, so it can be rendered again later without reloading the model.
</Callout>

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error when `sync` is `true`, as it is replicated.
  - **When `sync` is `false`** — only changes this client's local view, no ownership needed.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | component | Path of the component to update<br/>Supports `*` as a wildcard to match multiple components by pattern |
| `bool` | state | Determines the component's rendered state:<br/>• When `true` - the component is rendered<br/>• When `false` - the component stops rendering |
| `bool` | sync | Whether the change is replicated to other peers:<br/>• When `true` - it is replicated, and a client must own the entity or an error is raised<br/>• When `false` - it only applies on this client, and works on entities it doesn't own<br/>Ignored on the server, where changes are always replicated |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Stop rendering a component"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")

entity:set_component_rendered("Skeleton3D/Hat", false)
```
