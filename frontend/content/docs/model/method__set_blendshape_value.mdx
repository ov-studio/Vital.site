---
title: self:set_blendshape_value
description: Sets the value of a blendshape on a specific component
badge: shared
---

### Syntax

```lua
local status = self:set_blendshape_value(
    component,
    blendshape,
    value,
    sync = true
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is always replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error when `sync` is `true`, since the change would be replicated.
  - **When `sync` is `false`** — only changes this client's local view and is never replicated, so it works on entities the client does not own.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | component | Path of the component containing the blendshape |
| `string` | blendshape | Name of the blendshape to update<br/>Supports `*` as a wildcard to match multiple blend shapes by pattern |
| `float` | value | Value to apply to the blendshape |
| `bool` | sync | Whether the change is replicated to other peers:<br/>• When `true` - it is replicated, and a client must own the entity or an error is raised<br/>• When `false` - it only applies on this client, and works on entities it doesn't own<br/>Ignored on the server, where changes are always replicated |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set various blendshape's value on a model"
local entity = core.model.create("character")

-- Set a single blendshape value
entity:set_blendshape_value("Skeleton3D/Head", "smile", 1.0)

-- Set blendshape values using a wildcard
entity:set_blendshape_value("Skeleton3D/Head", "eye_*", 0.5)

-- Reset a blendshape to default
entity:set_blendshape_value("Skeleton3D/Head", "sad", 0.0)

-- Change a blendshape on this client only, such as an expression on another player's model
entity:set_blendshape_value("Skeleton3D/Head", "blink", 1.0, false)
```
