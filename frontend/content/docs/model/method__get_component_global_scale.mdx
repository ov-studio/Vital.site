---
title: self:get_component_global_scale
description: Retrieves the global scale of a component on the model
badge: shared
---

### Syntax

```lua
local scale = self:get_component_global_scale(
    component
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | component | Path of the component to read, as returned by `self:get_components` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Current global scale of the component as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global scale of a component"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")
local scale = entity:get_component_global_scale("Skeleton3D/Hat")

core.engine.print("info", "Component scale:", util.table.unpack(scale))
```
