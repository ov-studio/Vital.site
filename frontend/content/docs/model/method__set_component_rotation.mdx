---
title: self:set_component_rotation
description: Sets the local rotation of a component on the model
badge: shared
---

### Syntax

```lua
local status = self:set_component_rotation(
    component,
    rotation,
    sync = true
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is always replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error when `sync` is `true`, since the change would be replicated.
  - **When `sync` is `false`** — only changes this client's local view and is never replicated, so it works on entities the client does not own.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | component | Path of the component to update |
| `vector3` | rotation | Rotation to apply in degrees as `{x, y, z}` |
| `bool` | sync | Whether the change is replicated to other peers:<br/>• When `true` - it is replicated, and a client must own the entity or an error is raised<br/>• When `false` - it only applies on this client, and works on entities it doesn't own<br/>Ignored on the server, where changes are always replicated |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Rotate a component 25 degrees on the Y axis"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")

entity:set_component_rotation("Skeleton3D/Hat", {0, 25, 0})
```
