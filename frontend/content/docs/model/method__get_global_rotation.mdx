---
title: self:get_global_rotation
description: Retrieves the global rotation of the model
badge: shared
---

### Syntax

```lua
local rotation = self:get_global_rotation()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Current global rotation in degrees as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global rotation of a model"
core.model.load("character", "models/character.glb")
local entity = core.model.create("character")
local rotation = entity:get_global_rotation()

core.engine.print("info", "Model rotation:", util.table.unpack(rotation))
```
