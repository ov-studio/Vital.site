---
title: self:rotate_local
description: Rotates the model around an axis in its own local coordinate space
badge: shared
---

### Syntax

```lua
local status = self:rotate_local(
    axis,
    degrees
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | axis | Axis to rotate around as `{x, y, z}` |
| `float` | degrees | Angle to rotate by in degrees |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Rotate a model locally"
core.model.load("character", "models/character.glb")

local entity = core.model.create("character")

entity:rotate_local({0, 1, 0}, 45)
```
