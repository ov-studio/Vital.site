---
title: self:set_component_visible
description: Toggles the visibility of one or more components on the model
badge: shared
---

### Syntax

```lua
local status = self:set_component_visible(
    component,
    state,
    sync = true
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | component | Path of the component to update<br/>Supports `*` as a wildcard to match multiple components by pattern |
| `bool` | state | Determines the component's visibility:<br/>• When `true` - the component is shown<br/>• When `false` - the component is hidden |
| `bool` | sync | Whether the call is replicated to other peers<br/>Ignored on the server, where changes are always replicated |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Toggle various component's visibility on a model"
local entity = core.model.create("character")

-- Show the hat
entity:set_component_visible("Skeleton3D/Hat", true)

-- Hide the hat
entity:set_component_visible("Skeleton3D/Hat", false)

-- Hide all hats at once using a wildcard
entity:set_component_visible("Skeleton3D/Hat_*", false)

-- Show only Hat_1
entity:set_component_visible("Skeleton3D/Hat_1", true)
```
