---
title: self:set_component_visible
description: Toggles the visibility of one or more components on the model
badge: shared
---

### Syntax

```lua
local status = self:set_component_visible(
    component,
    state,
    sync = true
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is always replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/model/method/get_syncer).
  - **On any other client** — raises an error when `sync` is `true`, since the change would be replicated.
  - **When `sync` is `false`** — only changes this client's local view and is never replicated, so it works on entities the client does not own.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | component | Path of the component to update<br/>Supports `*` as a wildcard to match multiple components by pattern |
| `bool` | state | Determines the component's visibility:<br/>• When `true` - the component is shown<br/>• When `false` - the component is hidden |
| `bool` | sync | Whether the change is replicated to other peers:<br/>• When `true` - it is replicated, and a client must own the entity or an error is raised<br/>• When `false` - it only applies on this client, and works on entities it doesn't own<br/>Ignored on the server, where changes are always replicated |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Toggle various component's visibility on a model"
local entity = core.model.create("character")

-- Show the hat
entity:set_component_visible("Skeleton3D/Hat", true)

-- Hide the hat
entity:set_component_visible("Skeleton3D/Hat", false)

-- Hide all hats at once using a wildcard
entity:set_component_visible("Skeleton3D/Hat_*", false)

-- Show only Hat_1
entity:set_component_visible("Skeleton3D/Hat_1", true)
```
