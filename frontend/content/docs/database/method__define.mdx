---
title: self:define
description: Defines the schema for a table, registering it for use with the database instance
badge: server
---

### Syntax

```lua
local status = self:define(
    table,
    columns
)
```

<Callout type="warn">
  **Defining a schema does not create the table in the core.database.** Call [`self:sync`](/docs/database/method/sync) after all schemas have been defined to synchronise and create any tables that do not already exist.

  - **Before sync** — the schema is registered locally on the database instance only.
  - **After sync** — the table is created in the database if it does not already exist.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | table | Name of the table to define |
| `table` | columns | Map of column names to their column definition<br/>Refer [**Definitions**](#definitions) section |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Definitions

Each entry in the `columns` table is a key-value pair where the key is the column name and the value is a definition table with the following fields:

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `type` | `string` | `"VARCHAR(255)"` | SQL column type:<br/>• `"INT"` \| `"INT UNSIGNED"` \| `"BIGINT"`<br/>• `"FLOAT"` \| `"DOUBLE"`<br/>• `"BOOLEAN"`<br/>• `"VARCHAR(n)"` \| `"TEXT"`<br/>• `"DATETIME"` \| `"TIMESTAMP"` |
| `primary` | `bool` | `false` | Determines whether this column is the primary key:<br/>• When `true` - the column is used as the table's primary key<br/>• When `false` - the column is not part of the primary key |
| `autoincrement` | `bool` | `false` | Determines whether this column auto-increments:<br/>• When `true` - the column's value increases automatically with each insert<br/>• When `false` - the column's value must be provided manually |
| `nullable` | `bool` | `true` | Determines whether this column allows `NULL` values:<br/>• When `true` - the column may be left empty<br/>• When `false` - the column requires a value on insert |

---

### Examples

```lua lineNumbers title="Define and sync the 'players' table"
local entity = core.database.create("127.0.0.1", "root", "", "vital_sandbox")

entity:define("players", {
    id = { type = "INT UNSIGNED", primary = true, autoincrement = true, nullable = false },
    name = { type = "VARCHAR(64)", nullable = false },
    score = { type = "INT", nullable = true }
})
entity:sync()
```
