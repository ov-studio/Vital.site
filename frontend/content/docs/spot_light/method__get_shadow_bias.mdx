---
title: self:get_shadow_bias
description: Retrieves the shadow bias of the spot light
badge: client
---

### Syntax

```lua
local result = self:get_shadow_bias()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current shadow bias value |

---

### Examples

```lua lineNumbers title="Get shadow bias of a spot light"
local entity = light.spot.create()

core.engine.print("info", "Shadow Bias:", entity:get_shadow_bias())
```
