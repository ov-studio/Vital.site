---
title: self:get_range
description: Retrieves the maximum range of the spot light
badge: client
---

### Syntax

```lua
local result = self:get_range()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current light range in world units |

---

### Examples

```lua lineNumbers title="Get the range of a spot light"
local entity = light.spot.create()

core.engine.print("info", "Spot light range:", entity:get_range())
```
