---
title: self:is_visible_in_tree
description: Checks whether the spot light is effectively visible within the scene tree, accounting for parent visibility
badge: client
---

### Syntax

```lua
local result = self:is_visible_in_tree()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the spot light is visible in the scene tree, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check scene-tree visibility of a spot light"
local entity = light.spot.create()

core.engine.print("info", "Visible In Tree:", entity:is_visible_in_tree())
```
