---
title: self:get_dimension
description: Retrieves the dimension of the spot light
badge: client
---

### Syntax

```lua
local dimension = self:get_dimension()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Current dimension id |

---

### Examples

```lua lineNumbers title="Get the dimension of a spot light"
local entity = light.spot.create()

core.engine.print("info", "Spot light dimension:", entity:get_dimension())
```
