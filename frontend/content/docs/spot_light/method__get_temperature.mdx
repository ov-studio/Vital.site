---
title: self:get_temperature
description: Retrieves the color temperature of the spot light in Kelvin
badge: client
---

### Syntax

```lua
local result = self:get_temperature()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current color temperature in Kelvin |

---

### Examples

```lua lineNumbers title="Get temperature of a spot light"
local entity = light.spot.create()

core.engine.print("info", "Spot light temperature:", entity:get_temperature())
```
