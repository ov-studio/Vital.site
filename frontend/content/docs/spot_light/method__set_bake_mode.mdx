---
title: self:set_bake_mode
description: Sets the bake mode of the spot light
badge: client
---

### Syntax

```lua
local status = self:set_bake_mode(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`light.spot.bake_mode`](/docs/spot_light/enum/bake_mode) | mode | Bake mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply bake mode on a spot light"
local entity = light.spot.create()

entity:set_bake_mode(light.spot.bake_mode.STATIC)
```
