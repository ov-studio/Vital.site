---
title: self:get_bake_mode
description: Retrieves the bake mode of the spot light
badge: client
---

### Syntax

```lua
local mode = self:get_bake_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`light.spot.bake_mode`](/docs/spot_light/enum/bake_mode) | mode | Current bake mode |

---

### Examples

```lua lineNumbers title="Get bake mode of a spot light"
local entity = light.spot.create()

core.engine.print("info", "Bake Mode:", entity:get_bake_mode())
```
