---
title: self:get_shadow_normal_bias
description: Retrieves the shadow normal bias of the spot light
badge: client
---

### Syntax

```lua
local bias = self:get_shadow_normal_bias()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | bias | Current shadow normal bias value |

---

### Examples

```lua lineNumbers title="Get shadow normal bias of a spot light"
local entity = light.spot.create()

core.engine.print("info", "Shadow Normal Bias:", entity:get_shadow_normal_bias())
```
