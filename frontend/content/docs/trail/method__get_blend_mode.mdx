---
title: self:get_blend_mode
description: Retrieves the blend mode used to draw the ribbon
badge: client
---

### Syntax

```lua
local mode = self:get_blend_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`particle.trail.blend_mode`](/docs/trail/enum/blend_mode) | mode | Current blend mode |

---

### Examples

```lua lineNumbers title="Get the blend mode"
local entity = particle.trail.create()

core.engine.print("info", entity:get_blend_mode())
```
