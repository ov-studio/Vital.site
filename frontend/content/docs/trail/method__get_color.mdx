---
title: self:get_color
description: Retrieves the colors of the ribbon
badge: client
---

### Syntax

```lua
local from, to = self:get_color()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `color` | from | Color at the trail as `{r, g, b, a}` |
| `color` | to | Color at the end of the ribbon as `{r, g, b, a}` |

---

### Examples

```lua lineNumbers title="Get the ribbon colors"
local entity = particle.trail.create()

local from, to = entity:get_color()

core.engine.print("info", util.table.unpack(from))
core.engine.print("info", util.table.unpack(to))
```
