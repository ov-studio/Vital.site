---
title: particle.trail.create
description: Creates a new trail
badge: client
---

### Syntax

```lua
local instance = particle.trail.create()
```

<Callout type="info">
  **A trail draws the path it travels.**

  - **Follows its position** — move it every frame, e.g. onto a bone, and the trail draws the path it travelled.
  - **Fades out** — the trail is full width and color at its start, then thins out and fades towards its end, see [`self:set_lifetime`](/docs/trail/method/set_lifetime), [`self:set_width`](/docs/trail/method/set_width) and [`self:set_color`](/docs/trail/method/set_color).
  - **At rest** — while the trail stands still it shrinks away on its own.
  - **Not a particle emitter** — a mesh built from its path, so it needs no emission, amount or velocity settings.
</Callout>

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `trail` | instance | Trail instance |

---

### Examples

```lua lineNumbers title="Draw a trail behind a hand"
local trail = particle.trail.create()

trail:set_width(0.08)
trail:set_lifetime(0.4)
trail:set_color({0.1, 0.5, 0.8, 0.9}, {0.55, 0.8, 1, 0})

util.event.on("sandbox:process", function()
    trail:set_global_position(model:get_bone_position("DEF-hand.R"))
end)
```
