---
title: self:get_quaternion
description: Retrieves the local rotation of the trail as a quaternion
badge: client
---

### Syntax

```lua
local quaternion = self:get_quaternion()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `quaternion` | quaternion | Current rotation quaternion as `{x, y, z, w}` |

---

### Examples

```lua lineNumbers title="Get the quaternion rotation of a trail"
local entity = particle.trail.create()
local quaternion = entity:get_quaternion()

core.engine.print("info", "Trail quaternion:", util.table.unpack(quaternion))
```
