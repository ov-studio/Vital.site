---
title: self:set_blend_mode
description: Sets the blend mode used to draw the trail
badge: client
---

### Syntax

```lua
local status = self:set_blend_mode(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`particle.trail.blend_mode`](/docs/trail/enum/blend_mode) | mode | Blend mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Draw a glowing trail"
local entity = particle.trail.create()

entity:set_blend_mode(particle.trail.blend_mode.ADD)
```
