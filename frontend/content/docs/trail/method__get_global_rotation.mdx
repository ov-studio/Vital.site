---
title: self:get_global_rotation
description: Retrieves the global rotation of the trail in Euler degrees
badge: client
---

### Syntax

```lua
local rotation = self:get_global_rotation()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Current global rotation as Euler degrees `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global rotation of a trail"
local entity = particle.trail.create()
local rotation = entity:get_global_rotation()

core.engine.print("info", "Trail global rotation:", util.table.unpack(rotation))
```
