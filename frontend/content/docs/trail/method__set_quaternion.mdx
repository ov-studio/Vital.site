---
title: self:set_quaternion
description: Sets the local rotation of the trail using a quaternion
badge: client
---

### Syntax

```lua
local status = self:set_quaternion(
    quaternion
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `quaternion` | quaternion | Rotation quaternion to apply as `{x, y, z, w}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the quaternion rotation of a trail"
local entity = particle.trail.create()

entity:set_quaternion({0, 0, 0, 1})
```
