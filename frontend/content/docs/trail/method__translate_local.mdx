---
title: self:translate_local
description: Translates the trail by an offset relative to its own local axes
badge: client
---

### Syntax

```lua
local status = self:translate_local(
    offset
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | offset | Translation offset to apply in local space as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Translate a trail along its local forward axis"
local entity = particle.trail.create()

entity:translate_local({0, 0, -1})
```
