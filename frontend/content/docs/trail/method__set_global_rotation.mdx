---
title: self:set_global_rotation
description: Sets the global rotation of the trail in Euler degrees
badge: client
---

### Syntax

```lua
local status = self:set_global_rotation(
    rotation
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Global rotation to apply as Euler degrees `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the global rotation of a trail"
local entity = particle.trail.create()

entity:set_global_rotation({0, 90, 0})
```
