---
title: particle.trail.blend_mode
description: Enumeration of the blend modes used to draw the ribbon
badge: client
---

### Values

| Constant | Description |
|----------|-------------|
| `particle.trail.blend_mode.MIX` | Standard alpha blending |
| `particle.trail.blend_mode.ADD` | Adds the ribbon color to the scene — glowing effects |
| `particle.trail.blend_mode.SUB` | Subtracts the ribbon color from the scene |
| `particle.trail.blend_mode.MUL` | Multiplies the ribbon color with the scene |
