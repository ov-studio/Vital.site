---
title: particle.trail.blend_mode
description: Enumeration of the blend modes used to draw the trail
badge: client
---

### Values

| Constant | Description |
|----------|-------------|
| `particle.trail.blend_mode.MIX` | Standard alpha blending |
| `particle.trail.blend_mode.ADD` | Adds the trail color to the scene — glowing effects |
| `particle.trail.blend_mode.SUB` | Subtracts the trail color from the scene |
| `particle.trail.blend_mode.MUL` | Multiplies the trail color with the scene |
