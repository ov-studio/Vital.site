---
title: self:set_width
description: Sets the width of the ribbon at its start
badge: client
---

### Syntax

```lua
local status = self:set_width(
    width
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | width | Ribbon width at its start in world units, it thins out to nothing at the end |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the ribbon width"
local entity = particle.trail.create()

entity:set_width(0.08)
```
