---
title: self:set_paused
description: Sets the paused state of the audio-3d stream
badge: client
---

### Syntax

```lua
local status = self:set_paused(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines the paused state of the stream:<br/>• When `true` - the stream is paused while preserving the playback position<br/>• When `false` - the stream resumes from where it was paused |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Pause and resume an audio-3d stream"
local entity = core.audio_3d.create("sounds/ambient.ogg")

-- Play
entity:play()

-- Pause
entity:set_paused(true)

-- Resume
entity:set_paused(false)
```
