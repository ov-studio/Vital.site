---
title: self:get_panning_strength
description: Retrieves the panning strength of the audio-3d instance
badge: client
---

### Syntax

```lua
local result = self:get_panning_strength()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current panning strength |

---

### Examples

```lua lineNumbers title="Get the panning strength of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Panning strength:", entity:get_panning_strength())
```
