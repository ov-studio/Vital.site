---
title: self:set_dimension
description: Sets the dimension of the audio-3d instance
badge: client
---

### Syntax

```lua
local status = self:set_dimension(
    dimension
)
```

<Callout type="idea">
  **Audio is only heard from the dimension it is in.**

  - **Hearing** — the client mutes it while its active camera is in another dimension, playback keeps running.
  - **Attached** — a parented instance follows its parent's dimension, so setting its own raises an error.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Dimension id to apply<br/>Must be within `0` to `65535` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the dimension of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg", true)

entity:set_dimension(1)
```
