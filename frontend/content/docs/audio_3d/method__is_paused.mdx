---
title: self:is_paused
description: Checks whether the audio-3d stream is currently paused
badge: client
---

### Syntax

```lua
local result = self:is_paused()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the stream is paused, `false` otherwise |

---

### Examples

```lua lineNumbers title="Resume a paused audio-3d stream"
local entity = core.audio_3d.create("sounds/ambient.ogg")

entity:play()
entity:set_paused(true)

if entity:is_paused() then
    entity:set_paused(false)
end
```
