---
title: self:get_dimension
description: Retrieves the dimension of the audio-3d instance
badge: client
---

### Syntax

```lua
local dimension = self:get_dimension()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Current dimension id |

---

### Examples

```lua lineNumbers title="Get the dimension of an audio-3d instance"
local entity = core.audio_3d.create("sounds/ambient.ogg")

core.engine.print("info", "Audio dimension:", entity:get_dimension())
```
