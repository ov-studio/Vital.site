---
title: self:set_dimension
description: Sets the dimension of the animatable body
badge: shared
---

### Syntax

```lua
local status = self:set_dimension(
    dimension
)
```

<Callout type="idea">
  **Dimensions are fully isolated from each other.**

  - **Rendering** — the client only shows entities that match the dimension of its active camera.
  - **Physics** — bodies and areas only collide with, trigger, and get hit by queries of the same dimension.
  - **Hierarchy** — the dimension applies to the entity and all of its children.
  - **Attached** — an entity parented to another entity always follows its parent's dimension and cannot set its own, the call returns `false`. Detaching it keeps the dimension it had.
</Callout>

<Callout type="warn">
  **Dimension changes on network-synced entities are restricted to their owner.**

  - **On the server** — the new dimension is replicated to all clients.
  - **On the client** — only the peer holding sync authority can change the entity, the change is sent to the server and relayed to the other peers. Any other call raises an error.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Dimension id to apply, from `0` to `65535` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` if the dimension is outside `0` to `65535`, or the entity is attached to a parent |

---

### Examples

```lua lineNumbers title="Set the dimension of an animatable body"
local entity = physics.animatable.create()

entity:set_dimension(1)
```
