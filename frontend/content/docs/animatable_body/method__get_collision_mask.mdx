---
title: self:get_collision_mask
description: Retrieves the collision mask bitmask of the animatable body
badge: shared
---

### Syntax

```lua
local result = self:get_collision_mask()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | result | Current collision mask bitmask |

---

### Examples

```lua lineNumbers title="Get the collision mask of a animatable body"
local entity = physics.animatable.create()

core.engine.print("info", "Animatable body collision mask:", entity:get_collision_mask())
```
