---
title: self:get_dimension
description: Retrieves the dimension of the animatable body
badge: shared
---

### Syntax

```lua
local dimension = self:get_dimension()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Current dimension id |

---

### Examples

```lua lineNumbers title="Get the dimension of an animatable body"
local entity = physics.animatable.create()

core.engine.print("info", "Animatable body dimension:", entity:get_dimension())
```
