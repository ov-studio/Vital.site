---
title: physics.animatable.create
description: Creates a new animatable body instance and adds it to the scene
badge: client
---

### Syntax

```lua
local instance = physics.animatable.create()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `object` | instance | Created animatable body instance |

---

### Examples

```lua lineNumbers title="Create a animatable body instance"
local entity = physics.animatable.create()
local shape = physics.collision_shape.create(entity)

shape:set_shape_box({4, 1, 8})
entity:set_sync_to_physics(true)
```
