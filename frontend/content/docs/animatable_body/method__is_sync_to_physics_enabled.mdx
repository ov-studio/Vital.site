---
title: self:is_sync_to_physics_enabled
description: Checks whether the animatable body synchronizes its motion to the physics step, ensuring accurate collision response while it moves
badge: client
---

### Syntax

```lua
local result = self:is_sync_to_physics_enabled()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if sync to physics is enabled, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check sync to physics on a animatable body"
local entity = physics.animatable.create()

core.engine.print("info", "Sync To Physics Enabled:", entity:is_sync_to_physics_enabled())
```
