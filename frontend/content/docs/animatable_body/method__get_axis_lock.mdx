---
title: self:get_axis_lock
description: Checks whether a specific movement axis is locked on the animatable body
badge: client
---

### Syntax

```lua
local result = self:get_axis_lock(
    axis
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | axis | Axis enum value — refer to [`physics.animatable.axis`](/docs/animatable_body/enum/axis) |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the axis is locked, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check an axis lock on a animatable body"
local entity = physics.animatable.create()

core.engine.print("info", "Axis Lock:", entity:get_axis_lock(physics.animatable.axis.LINEAR_X))
```
