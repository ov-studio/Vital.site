---
title: self:set_sync_to_physics
description: Sets whether the animatable body synchronizes its motion to the physics step — enable this when moving it every frame from a script so it correctly pushes and carries other bodies
badge: shared
---

### Syntax

```lua
local status = self:set_sync_to_physics(
    state
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/animatable_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to enable sync to physics, `false` to disable |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable sync to physics on a animatable body"
local entity = physics.animatable.create()

entity:set_sync_to_physics(true)
```
