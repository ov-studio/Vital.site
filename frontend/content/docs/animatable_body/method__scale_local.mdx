---
title: self:scale_local
description: Scales the animatable body in its own local coordinate space
badge: client
---

### Syntax

```lua
local status = self:scale_local(
    scale
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Scale factor to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Scale a animatable body locally"
local entity = physics.animatable.create()

entity:scale_local({2, 2, 2})
```
