---
title: self:get_scale
description: Retrieves the local scale of the animatable body
badge: client
---

### Syntax

```lua
local scale = self:get_scale()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Current local scale as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the local scale of a animatable body"
local entity = physics.animatable.create()
local scale = entity:get_scale()

core.engine.print("info", "Scale:", util.table.unpack(scale))
```
