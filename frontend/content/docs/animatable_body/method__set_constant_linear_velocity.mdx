---
title: self:set_constant_linear_velocity
description: Sets the constant linear velocity the animatable body applies to bodies resting on it, such as a conveyor surface
badge: shared
---

### Syntax

```lua
local status = self:set_constant_linear_velocity(
    velocity
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/animatable_body/method/get_syncer).
  - **On any other client** — raises an error when the entity is owned by the server or by another client.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | velocity | Velocity to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the constant linear velocity of a animatable body"
local entity = physics.animatable.create()

entity:set_constant_linear_velocity({2, 0, 0})
```
