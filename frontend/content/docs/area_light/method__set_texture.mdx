---
title: self:set_texture
description: Applies a texture to the area light, which modulates its emitted light pattern
badge: client
---

### Syntax

```lua
local status = self:set_texture(
    path
)
```

<Callout type="idea">
  **Prefix the path with `:resourcename` to load a texture from another running resource.**

  - **Local path** — resolves relative to the current resource's directory.
  - **Cross-resource path** — prefix with `:resourcename` to resolve relative to another running resource's directory.
  - **Example** — `:resource_a/textures/light_panel.png` loads `textures/light_panel.png` from inside `resource_a`.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | path | File path to the texture to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply a texture to an area light"
local entity = light.area.create()

entity:set_texture("textures/light_panel.png")
```
