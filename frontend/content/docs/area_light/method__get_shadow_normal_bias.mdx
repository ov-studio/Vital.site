---
title: self:get_shadow_normal_bias
description: Retrieves the shadow normal bias of the area light
badge: client
---

### Syntax

```lua
local result = self:get_shadow_normal_bias()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current shadow normal bias value |

---

### Examples

```lua lineNumbers title="Get shadow normal bias of a area light"
local entity = light.area.create()

core.engine.print("info", "Shadow Normal Bias:", entity:get_shadow_normal_bias())
```
