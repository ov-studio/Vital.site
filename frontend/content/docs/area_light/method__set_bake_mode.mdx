---
title: self:set_bake_mode
description: Sets the bake mode of the area light
badge: client
---

### Syntax

```lua
local status = self:set_bake_mode(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`light.area.bake_mode`](/docs/area_light/enum/bake_mode) | mode | Bake mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply bake mode on a area light"
local entity = light.area.create()

entity:set_bake_mode(light.area.bake_mode.STATIC)
```
