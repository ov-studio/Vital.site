---
title: self:set_negative
description: Sets whether the area light operates in negative mode, subtracting light from the scene
badge: client
---

### Syntax

```lua
local status = self:set_negative(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether negative mode is enabled:<br/>• When `true` - negative mode is enabled<br/>• When `false` - negative mode is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply negative on a area light"
local entity = light.area.create()

entity:set_negative(true)
```
