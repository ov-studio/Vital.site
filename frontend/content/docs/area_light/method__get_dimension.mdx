---
title: self:get_dimension
description: Retrieves the dimension of the area light
badge: client
---

### Syntax

```lua
local dimension = self:get_dimension()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Current dimension id |

---

### Examples

```lua lineNumbers title="Get the dimension of an area light"
local entity = light.area.create()

core.engine.print("info", "Area light dimension:", entity:get_dimension())
```
