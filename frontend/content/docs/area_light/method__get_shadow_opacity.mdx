---
title: self:get_shadow_opacity
description: Retrieves the shadow opacity of the area light
badge: client
---

### Syntax

```lua
local opacity = self:get_shadow_opacity()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | opacity | Current shadow opacity, from `0.0` to `1.0` |

---

### Examples

```lua lineNumbers title="Get shadow opacity of a area light"
local entity = light.area.create()

core.engine.print("info", "Shadow Opacity:", entity:get_shadow_opacity())
```
