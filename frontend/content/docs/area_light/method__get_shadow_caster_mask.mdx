---
title: self:get_shadow_caster_mask
description: Retrieves the shadow caster mask of the area light, which controls which layers cast shadows
badge: client
---

### Syntax

```lua
local mask = self:get_shadow_caster_mask()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | mask | Current shadow caster mask bitmask |

---

### Examples

```lua lineNumbers title="Get shadow caster mask of a area light"
local entity = light.area.create()

core.engine.print("info", "Shadow Caster Mask:", entity:get_shadow_caster_mask())
```
