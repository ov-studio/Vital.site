---
title: self:get_shadow_blur
description: Retrieves the shadow blur amount of the area light
badge: client
---

### Syntax

```lua
local result = self:get_shadow_blur()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current shadow blur amount |

---

### Examples

```lua lineNumbers title="Get shadow blur of a area light"
local entity = light.area.create()

core.engine.print("info", "Shadow Blur:", entity:get_shadow_blur())
```
