---
title: self:set_projector
description: Applies a texture as a projector on the area light, casting its pattern into the scene
badge: client
---

### Syntax

```lua
local status = self:set_projector(
    path
)
```

<Callout type="idea">
  **Prefix the path with `:resourcename` to load a projector texture from another running resource.**

  - **Local path** — resolves relative to the current resource's directory.
  - **Cross-resource path** — prefix with `:resourcename` to resolve relative to another running resource's directory.
  - **Example** — `:resource_a/textures/gobo_pattern.png` loads `textures/gobo_pattern.png` from inside `resource_a`.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | path | File path to the texture to use as a projector |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply a projector texture to a area light"
local entity = light.area.create()

entity:set_projector("textures/gobo_pattern.png")
```
