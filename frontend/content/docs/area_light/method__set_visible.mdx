---
title: self:set_visible
description: Sets the visibility of the area light
badge: client
---

### Syntax

```lua
local status = self:set_visible(
    visible
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | visible | Determines the visibility of the area light:<br/>• When `true` - the area light is shown<br/>• When `false` - the area light is hidden |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Hide a area light"
local entity = light.area.create()

entity:set_visible(false)
```
