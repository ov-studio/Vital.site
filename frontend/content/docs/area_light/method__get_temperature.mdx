---
title: self:get_temperature
description: Retrieves the color temperature of the area light in Kelvin
badge: client
---

### Syntax

```lua
local kelvin = self:get_temperature()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | kelvin | Current color temperature in Kelvin |

---

### Examples

```lua lineNumbers title="Get temperature of a area light"
local entity = light.area.create()

core.engine.print("info", "Temperature:", entity:get_temperature())
```
