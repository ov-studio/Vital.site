---
title: self:get_specular
description: Retrieves the specular contribution factor of the area light
badge: client
---

### Syntax

```lua
local specular = self:get_specular()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | specular | Current specular factor, from `0.0` to `1.0` |

---

### Examples

```lua lineNumbers title="Get specular of a area light"
local entity = light.area.create()

core.engine.print("info", "Specular:", entity:get_specular())
```
