---
title: util.http.post
description: Executes a POST request on specified url
badge: shared
---

### Syntax

```lua
local promise = util.http.post(
    url,
    body,
    headers = {
        "Content-Type: application/json"
    },
    timeout = 60
)
```

<Callout type="info">
  **This function returns a promise and starts processing the query.**

  - **Result** — use [`thread:await`](/docs/thread/method/await) inside a thread to retrieve the result.
  - **Inside a thread** — `self:await(util.http.post(...))` waits for the response and returns the resolved values.
  - **Outside a thread** — the promise is still created, but must be awaited from a thread.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | url | Request URL to query |
| `string` | body | Request body for query |
| `table` | headers | Request headers for query |
| `int` | timeout | Read timeout in seconds |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `promise` | promise | See the [**Settlements**](#settlements) section |

---

### Settlements

| Type | Name | Description |
|---------|------|-------------|
| `bool` | status | `true` on success, `false` otherwise |
| `string` | resolved | Response body returned by the server |
| `string` | rejected | Error message describing the failure |

---

### Examples

```lua lineNumbers title="Send a basic POST request with a JSON body"
util.thread.create(function(self)
    local ok, result = self:await(util.http.post("https://api.example.com/users",
        util.table.encode({
            name = "John Doe",
            email = "john@example.com"
        })
    ))

    if ok then
        core.engine.print("info", "Response:", result)
    else
        core.engine.print("error", "Request failed:", result)
    end
end):resume()
```

```lua lineNumbers title="Send a POST with custom authorization header and timeout"
util.thread.create(function(self)
    local ok, result = self:await(util.http.post("https://api.example.com/users",
        util.table.encode({
            name = "John Doe",
            email = "john@example.com"
        }),
        {
            "Authorization: Bearer my-token"
        },
        30
    ))

    if ok then
        core.engine.print("info", "Response:", result)
    else
        core.engine.print("error", "Request failed:", result)
    end
end):resume()
```
