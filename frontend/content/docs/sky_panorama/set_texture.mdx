---
title: gfx.sky.panorama.set_texture
description: Sets the texture of the panorama sky material
badge: client
---

### Syntax

```lua
local status = gfx.sky.panorama.set_texture(
    path
)
```

<Callout type="idea">
  **Prefix the path with `:resourcename` to load a panorama texture from another running resource.**

  - **Local path** — resolves relative to the current resource's directory.
  - **Cross-resource path** — prefix with `:resourcename` to resolve relative to another running resource's directory.
  - **Example** — `:resource_a/assets/sky/panorama.hdr` loads `assets/sky/panorama.hdr` from inside `resource_a`.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | path | File path of the panorama texture to assign |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set panorama sky texture"
gfx.sky.panorama.set_texture("assets/sky/panorama.hdr")
```
