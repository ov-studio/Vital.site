---
title: gfx.sky.panorama.set_filtering_enabled
description: Sets whether texture filtering is enabled on the panorama sky material
badge: client
---

### Syntax

```lua
local status = gfx.sky.panorama.set_filtering_enabled(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether filtering is enabled:<br/>• When `true` - filtering is enabled<br/>• When `false` - filtering is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable panorama sky texture filtering"
gfx.sky.panorama.set_filtering_enabled(true)
```
