---
title: self:get_collision_layer
description: Retrieves the collision layer bitmask of the static body
badge: client
---

### Syntax

```lua
local layer = self:get_collision_layer()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | layer | Current collision layer bitmask |

---

### Examples

```lua lineNumbers title="Get the collision layer of a static body"
local entity = physics.static.create()

core.engine.print("info", entity:get_collision_layer())
```
