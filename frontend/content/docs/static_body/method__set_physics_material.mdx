---
title: self:set_physics_material
description: Applies a physics material to the static body, controlling friction and bounce behavior
badge: shared
---

### Syntax

```lua
local status = self:set_physics_material(
    friction,
    bounce,
    rough = false,
    absorbent = false
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/static_body/method/get_syncer).
  - **On any other client** — raises an error when the entity is owned by the server or by another client.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | friction | Friction coefficient to apply |
| `float` | bounce | Bounce (restitution) coefficient to apply |
| `bool` | rough | Whether friction combining should favor the rougher surface |
| `bool` | absorbent | Whether bounce combining should favor the less bouncy surface |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply a physics material on a static body"
local entity = physics.static.create()

entity:set_physics_material(0.5, 0.2)
```
