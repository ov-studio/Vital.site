---
title: self:look_at
description: Rotates the static body so its -Z axis points toward the given world-space target
badge: shared
---

### Syntax

```lua
local status = self:look_at(
    target,
    up = {0, 1, 0}
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/static_body/method/get_syncer).
  - **On any other client** — raises an error when the entity is owned by the server or by another client.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | target | World-space position to look at as `{x, y, z}` |
| `vector3` | up | Up vector used to determine orientation as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Point a static body at the world origin"
local entity = physics.static.create()

entity:set_position({0, 10, 0})
entity:look_at({0, 0, 0}, {0, 1, 0})
```
