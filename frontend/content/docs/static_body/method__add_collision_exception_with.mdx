---
title: self:add_collision_exception_with
description: Adds another physics body to this static body's collision exception list so the two no longer collide with each other
badge: shared
---

### Syntax

```lua
local status = self:add_collision_exception_with(
    body
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/static_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `object` | body | Physics body instance to exclude from collision — must be the same physics type as this instance |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Add a collision exception on a static body"
local a = physics.static.create()
local b = physics.static.create()

a:add_collision_exception_with(b)
```
