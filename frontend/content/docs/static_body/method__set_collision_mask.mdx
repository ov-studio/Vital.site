---
title: self:set_collision_mask
description: Sets the collision mask bitmask of the static body
badge: shared
---

### Syntax

```lua
local status = self:set_collision_mask(
    mask
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/static_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | mask | Collision mask bitmask to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the collision mask of a static body"
local entity = physics.static.create()

entity:set_collision_mask(1)
```
