---
title: self:get_quaternion
description: Retrieves the local rotation of the static body as a quaternion
badge: client
---

### Syntax

```lua
local quaternion = self:get_quaternion()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector4` | quaternion | Current rotation as `{x, y, z, w}` |

---

### Examples

```lua lineNumbers title="Get the quaternion of a static body"
local entity = physics.static.create()
local quaternion = entity:get_quaternion()

core.engine.print("info", "Static body quaternion:", util.table.unpack(quaternion))
```
