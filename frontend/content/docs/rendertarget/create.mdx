---
title: core.rendertarget.create
description: Creates a new rendertarget instance
badge: client
---

### Syntax

```lua
local instance = core.rendertarget.create(
    size,
    transparent = false,
    hdr = false
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector2` | size | Size of the rendertarget as `{width, height}` |
| `bool` | transparent | Determines whether the rendertarget has a transparent background:<br/>• When `true` - the background is transparent<br/>• When `false` - the background is opaque |
| `bool` | hdr | Determines the color format of the rendertarget:<br/>• When `true` - 16 bit float, values above `1` are kept and gradients stay smooth<br/>• When `false` - 8 bit, values are clamped between `0` and `1` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `rendertarget` | instance | Created rendertarget instance |

---

### Examples

```lua lineNumbers title="Create a rendertarget and set it as active"
local entity = core.rendertarget.create({1920, 1080}, false)

entity:set_active()
```

```lua lineNumbers title="Create an HDR rendertarget for light values above 1"
local entity = core.rendertarget.create({512, 288}, true, true)

core.engine.print("info", "HDR:", entity:is_hdr()) -- true
```
