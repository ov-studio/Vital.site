---
title: gfx.gtao.get_blur
description: Retrieves the current denoise blur strength of the GTAO post-processing effect
badge: client
---

### Syntax

```lua
local result = gfx.gtao.get_blur()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current blur value |

---

### Examples

```lua lineNumbers title="Get the current gtao denoise blur strength"
core.engine.print("info", "GTAO denoise blur strength:", gfx.gtao.get_blur())
```
