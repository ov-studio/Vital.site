---
title: gfx.gtao.is_half_res
description: Retrieves whether the GTAO post-processing effect is computed at half resolution
badge: client
---

### Syntax

```lua
local result = gfx.gtao.is_half_res()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if occlusion is computed at half resolution, `false` if at full resolution |

---

### Examples

```lua lineNumbers title="Print the current gtao resolution mode"
core.engine.print("info", "GTAO half resolution:", gfx.gtao.is_half_res())
```
