---
title: gfx.gtao.set_quality
description: Sets the quality level of the GTAO post-processing effect
badge: client
---

### Syntax

```lua
local status = gfx.gtao.set_quality(
    quality
)
```

<Callout type="info">
  **Higher qualities take more samples per pixel.**

  - **Default** — [`gfx.gtao.quality.HIGH`](/docs/gtao/enum/quality).
  - **Cost** — higher qualities are slower, [`gfx.gtao.quality.ULTRA`](/docs/gtao/enum/quality) is the most expensive.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`gfx.gtao.quality`](/docs/gtao/enum/quality) | quality | Quality level to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set gtao quality to ultra"
gfx.gtao.set_quality(gfx.gtao.quality.ULTRA)
```

```lua lineNumbers title="Set gtao quality to low for maximum performance"
gfx.gtao.set_quality(gfx.gtao.quality.LOW)
```
