---
title: gfx.gtao.set_enabled
description: Toggles the GTAO post-processing effect
badge: client
---

### Syntax

```lua
local status = gfx.gtao.set_enabled(
    state
)
```

<Callout type="info">
  **GTAO and SSAO both darken the scene.**

  - **SSAO** — avoid enabling [`gfx.ssao.set_enabled`](/docs/ssao/set_enabled) together, the occlusion would be applied twice.
  - **Default** — disabled.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines GTAO's state:<br/>• When `true` - GTAO is enabled<br/>• When `false` - GTAO is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Toggle gtao effect"
-- Enable GTAO
gfx.gtao.set_enabled(true)

-- Disable GTAO
gfx.gtao.set_enabled(false)
```
