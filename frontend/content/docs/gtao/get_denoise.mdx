---
title: gfx.gtao.get_denoise
description: Retrieves the current denoise mode of the GTAO post-processing effect
badge: client
---

### Syntax

```lua
local result = gfx.gtao.get_denoise()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`gfx.gtao.denoise_mode`](/docs/gtao/enum/denoise_mode) | result | Current denoise mode |

---

### Examples

```lua lineNumbers title="Print the current gtao denoise mode"
core.engine.print("info", "GTAO denoise mode:", gfx.gtao.get_denoise())
```
