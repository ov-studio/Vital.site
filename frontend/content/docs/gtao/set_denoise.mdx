---
title: gfx.gtao.set_denoise
description: Sets the denoise mode of the GTAO post-processing effect
badge: client
---

### Syntax

```lua
local status = gfx.gtao.set_denoise(
    mode
)
```

<Callout type="info">
  **Denoising smooths the sampling noise of the occlusion.**

  - **Default** — [`gfx.gtao.denoise_mode.SOFT`](/docs/gtao/enum/denoise_mode).
  - **Cost** — each denoise pass adds a small GPU cost, [`gfx.gtao.denoise_mode.OFF`](/docs/gtao/enum/denoise_mode) is the cheapest.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`gfx.gtao.denoise_mode`](/docs/gtao/enum/denoise_mode) | mode | Denoise mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set gtao denoise mode to soft"
gfx.gtao.set_denoise(gfx.gtao.denoise_mode.SOFT)
```

```lua lineNumbers title="Disable gtao denoising"
gfx.gtao.set_denoise(gfx.gtao.denoise_mode.OFF)
```
