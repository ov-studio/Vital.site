---
title: gfx.gtao.get_quality

badge: client
---

### Syntax

```lua
local result = gfx.gtao.get_quality()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`gfx.gtao.quality`](/docs/gtao/enum/quality) | result | Current quality level |

---

### Examples

```lua lineNumbers title="Print the current gtao quality"
core.engine.print("info", "GTAO quality:", gfx.gtao.get_quality())
```
