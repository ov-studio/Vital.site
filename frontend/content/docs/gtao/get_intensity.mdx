---
title: gfx.gtao.get_intensity
description: Retrieves the current intensity of the GTAO post-processing effect
badge: client
---

### Syntax

```lua
local result = gfx.gtao.get_intensity()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Current intensity value |

---

### Examples

```lua lineNumbers title="Get the current gtao intensity"
core.engine.print("info", "GTAO intensity:", gfx.gtao.get_intensity())
```
