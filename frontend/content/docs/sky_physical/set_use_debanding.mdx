---
title: gfx.sky.physical.set_use_debanding
description: Sets whether debanding is enabled on the physical sky material
badge: client
---

### Syntax

```lua
local status = gfx.sky.physical.set_use_debanding(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether debanding is enabled:<br/>• When `true` - debanding is enabled<br/>• When `false` - debanding is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable physical sky debanding"
gfx.sky.physical.set_use_debanding(true)
```
