---
title: self:get_global_scale
description: Retrieves the global scale of the particle emitter derived from its global transform
badge: client
---

### Syntax

```lua
local scale = self:get_global_scale()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Current global scale as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global scale of a particle emitter"
local entity = particle.gpu.create()
local scale = entity:get_global_scale()

core.engine.print("info", "Emitter global scale:", util.table.unpack(scale))
```
