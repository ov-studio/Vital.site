---
title: self:restart
description: Restarts the emitter, clearing every live particle
badge: client
---

### Syntax

```lua
local status = self:restart()
```

<Callout type="info">
  **Fires [`particle:emit`](/docs/event/signal/particle_emit) as the new cycle starts.**

  - **Every call** — fires on every call, even if already emitting, since a new cycle begins each time.
  - **Reset** — every live particle is cleared and the cycle starts again from the beginning.
  - **Replay** — use it to replay a one-shot emitter straight after [`particle:finish`](/docs/event/signal__particle_finish).
</Callout>

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Restart the emitter"
local entity = particle.gpu.create()

entity:emit()
entity:restart()
```
