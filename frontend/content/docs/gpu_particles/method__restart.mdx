---
title: self:restart
description: Restarts the emitter, clearing every live particle
badge: client
---

### Syntax

```lua
local status = self:restart()
```

<Callout type="info">
  **Fires [`particle:emit`](/docs/event/signal/particle_emit) as the new cycle starts.**

  - Fires on every call, even if the emitter was already emitting, because a new cycle begins each time.
  - Every live particle is cleared and the cycle starts again from the beginning.
  - Use it to replay a one-shot emitter straight after [`particle:finished`](/docs/event/signal/particle_finished).
</Callout>

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Restart the emitter"
local entity = particle.gpu.create()

entity:emit()
entity:restart()
```
