---
title: self:set_turbulence
description: Sets whether turbulence is applied to the particles
badge: client
---

### Syntax

```lua
local status = self:set_turbulence(
    state,
    strength = 1,
    scale = 1.5
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to enable turbulence, `false` to disable it |
| `float` | strength | How strongly particles are pushed around<br/>Left unchanged when omitted |
| `float` | scale | Size of the turbulence noise<br/>Left unchanged when omitted |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Add swirl to the particles"
local entity = particle.gpu.create()

entity:set_turbulence(true, 0.8, 2)
```

```lua lineNumbers title="Disable turbulence"
local entity = particle.gpu.create()

entity:set_turbulence(false)
```
