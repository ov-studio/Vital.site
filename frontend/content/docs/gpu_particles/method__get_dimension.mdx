---
title: self:get_dimension
description: Retrieves the dimension of the particle emitter
badge: client
---

### Syntax

```lua
local dimension = self:get_dimension()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Current dimension id |

---

### Examples

```lua lineNumbers title="Get the dimension of a particle emitter"
local entity = particle.gpu.create()

core.engine.print("info", "Particle emitter dimension:", entity:get_dimension())
```
