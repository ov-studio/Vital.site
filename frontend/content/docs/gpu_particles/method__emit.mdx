---
title: self:emit
description: Starts emitting particles
badge: client
---

### Syntax

```lua
local status = self:emit()
```

<Callout type="info">
  **Fires [`particle:emit`](/docs/event/signal/particle_emit) when emission actually starts.**

  - Calling it on an emitter that is already emitting does nothing and fires no signal.
</Callout>

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Start emitting"
local entity = particle.gpu.create()

entity:emit()
```
