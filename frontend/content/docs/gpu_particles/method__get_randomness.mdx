---
title: self:get_randomness
description: Retrieves how random the emission timing is
badge: client
---

### Syntax

```lua
local ratio = self:get_randomness()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | ratio | Randomness between `0` and `1` |

---

### Examples

```lua lineNumbers title="Get the emission randomness"
local entity = particle.gpu.create()

core.engine.print("info", entity:get_randomness())
```
