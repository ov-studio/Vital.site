---
title: self:is_emitting
description: Checks whether the emitter is currently emitting
badge: client
---

### Syntax

```lua
local result = self:is_emitting()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the emitter is emitting, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check whether an emitter is emitting"
local entity = particle.gpu.create()

core.engine.print("info", entity:is_emitting())
```
