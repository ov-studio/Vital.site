---
title: self:reset_color_ramp
description: Removes the color fade applied with `self:set_color_ramp`
badge: client
---

### Syntax

```lua
local status = self:reset_color_ramp()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Remove the color ramp"
local entity = particle.gpu.create()

entity:set_color_ramp({1, 0.9, 0.3, 1}, {1, 0.2, 0, 0})
entity:reset_color_ramp()
```
