---
title: self:is_billboard
description: Checks whether particles always face the camera
badge: client
---

### Syntax

```lua
local result = self:is_billboard()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if particles face the camera, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check whether particles are billboards"
local entity = particle.gpu.create()

core.engine.print("info", entity:is_billboard())
```
