---
title: self:set_rotation
description: Sets the local rotation of the particle emitter in Euler degrees
badge: client
---

### Syntax

```lua
local status = self:set_rotation(
    euler_degrees
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | euler_degrees | Local rotation to apply as Euler degrees `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the local rotation of a particle emitter"
local entity = particle.gpu.create()

entity:set_rotation({0, 45, 0})
```
