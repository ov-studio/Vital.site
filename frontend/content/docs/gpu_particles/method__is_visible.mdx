---
title: self:is_visible
description: Checks whether the particle emitter is visible
badge: client
---

### Syntax

```lua
local result = self:is_visible()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if visible, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check visibility of a particle emitter"
local entity = particle.gpu.create()

core.engine.print("info", "Particle emitter visible:", entity:is_visible())
```
