---
title: self:get_lifetime
description: Retrieves how long each particle lives
badge: client
---

### Syntax

```lua
local result = self:get_lifetime()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Particle lifetime in seconds |

---

### Examples

```lua lineNumbers title="Get the particle lifetime"
local entity = particle.gpu.create()

core.engine.print("info", entity:get_lifetime())
```
