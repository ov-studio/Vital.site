---
title: self:reset_material
description: Goes back to the plain built-in particle material
badge: client
---

### Syntax

```lua
local status = self:reset_material()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Reset the material"
local entity = particle.gpu.create()

entity:set_material("assets/spark.png")
entity:reset_material()
```
