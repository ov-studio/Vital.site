---
title: self:set_billboard
description: Sets whether particles always face the camera
badge: client
---

### Syntax

```lua
local status = self:set_billboard(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines the particle orientation:<br/>• When `true` - particles face the camera<br/>• When `false` - particles keep their orientation |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Stop particles facing the camera"
local entity = particle.gpu.create()

entity:set_billboard(false)
```
