---
title: self:set_one_shot
description: Sets whether the emitter emits a single cycle and then stops
badge: client
---

### Syntax

```lua
local status = self:set_one_shot(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to emit a single cycle, `false` to emit continuously |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Make an emitter one-shot"
local entity = particle.gpu.create()

entity:set_one_shot(true)
```
