---
title: self:set_position
description: Sets the local position of the particle emitter
badge: client
---

### Syntax

```lua
local status = self:set_position(
    position
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Local position to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the local position of a particle emitter"
local entity = particle.gpu.create()

entity:set_position({0, 5, 10})
```
