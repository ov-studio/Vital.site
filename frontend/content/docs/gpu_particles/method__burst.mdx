---
title: self:burst
description: Emits a single cycle of particles
badge: client
---

### Syntax

```lua
local status = self:burst()
```

<Callout type="info">
  **Fire-and-forget effects need cleaning up.**

  - Listen for [`particle:finish`](/docs/event/signal__particle_finish) and call `self:destroy` from it — it fires once every particle of the cycle is gone.
  - [`particle:emit`](/docs/event/signal/particle_emit) fires as soon as the burst starts.
  - Switches the emitter to one-shot, so it plays a single cycle and then stops.
</Callout>

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Emit a single cycle"
local entity = particle.gpu.create()

entity:set_one_shot(true)
entity:burst()
```

```lua lineNumbers title="Burst and clean up"
local entity = particle.gpu.create()

util.event.on("particle:finish", function(emitter)
    emitter:destroy()
end)

entity:burst()
```
