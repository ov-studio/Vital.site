---
title: self:get_contact_normal
description: Retrieves the surface normal at the point where the wheel is touching the ground
badge: client
---

### Syntax

```lua
local normal = self:get_contact_normal()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | normal | Contact normal as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the contact normal of a vehicle wheel"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

core.engine.print("info", entity:get_contact_normal())
```
