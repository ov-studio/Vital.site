---
title: self:set_rotation
description: Sets the local rotation of the vehicle wheel in radians
badge: shared
---

### Syntax

```lua
local status = self:set_rotation(
    rotation
)
```

<Callout type="info">
  **Use `self:set_rotation_degrees` to provide the rotation in degrees instead.**
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Rotation to apply in radians as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the local rotation of a vehicle wheel"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

entity:set_rotation({0, math.pi*0.5, 0})
```
