---
title: self:set_use_as_traction
description: Sets whether the wheel is used as a traction (driven) wheel
badge: shared
---

### Syntax

```lua
local status = self:set_use_as_traction(
    state
)
```

<Callout type="warn">
  **Replicated vehicle wheels can only be modified by the server or the owner of their body.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of.
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
  - **Attached entities** — a vehicle wheel follows the authority of its body.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether this is a driven wheel:<br/>• When `true` - the wheel is driven<br/>• When `false` - the wheel is not driven |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable traction on a vehicle wheel"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

entity:set_use_as_traction(true)
```
