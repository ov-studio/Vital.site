---
title: self:set_steering
description: Sets the per-wheel steering angle override
badge: shared
---

### Syntax

```lua
local status = self:set_steering(
    steering
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | steering | Per-wheel steering angle override to apply in degrees |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the steering of a vehicle wheel"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

entity:set_steering(15)
```
