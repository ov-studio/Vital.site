---
title: self:get_global_rotation
description: Retrieves the global rotation of the vehicle wheel in degrees
badge: client
---

### Syntax

```lua
local rotation = self:get_global_rotation()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Current global rotation in degrees as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global rotation of a vehicle wheel"
local entity = physics.vehicle_wheel.create()
local rotation = entity:get_global_rotation()

core.engine.print("info", "Rotation:", util.table.unpack(rotation))
```
