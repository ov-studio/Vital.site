---
title: physics.vehicle_wheel.create
description: Creates a new vehicle wheel instance and attaches it to a vehicle body
badge: shared
---

### Syntax

```lua
local instance = physics.vehicle_wheel.create(
    body
)
```

<Callout type="warn">
  **Attaching requires authority over the target body.**

  - **On the server** — always allowed.
  - **On the owning client** — allowed when the client is the syncer of the body.
  - **On any other client** — raises an error when the body is owned by the server or by another client.
  - **Client-local bodies** — bodies that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `object` | body | Vehicle body instance to attach the wheel to |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `object` | instance | Created vehicle wheel instance |

---

### Examples

```lua lineNumbers title="Create a vehicle wheel instance"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

entity:set_position({-1, -0.5, 1.5})
entity:set_use_as_traction(true)
```
