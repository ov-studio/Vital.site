---
title: self:set_global_rotation
description: Sets the global rotation of the vehicle wheel
badge: shared
---

### Syntax

```lua
local status = self:set_global_rotation(
    rotation
)
```

<Callout type="warn">
  **Modifying a replicated vehicle wheel is only allowed for the server or the client that owns its body.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of.
  - **On any other client** — raises an error when the entity is owned by the server or by another client.
  - **Client-local entities** — entities that are not replicated are unrestricted.
  - **Attached entities** — a vehicle wheel follows the authority of the body it is attached to.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | rotation | Rotation to apply in degrees as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the global rotation of a vehicle wheel"
local entity = physics.vehicle_wheel.create()

entity:set_global_rotation({0, 90, 0})
```
