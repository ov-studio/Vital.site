---
title: self:get_damping_relaxation
description: Retrieves the suspension relaxation damping of the wheel
badge: client
---

### Syntax

```lua
local value = self:get_damping_relaxation()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | value | Current relaxation damping |

---

### Examples

```lua lineNumbers title="Get the relaxation damping of a vehicle wheel"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

core.engine.print("info", entity:get_damping_relaxation())
```
