---
title: self:get_steering
description: Retrieves the per-wheel steering angle override
badge: client
---

### Syntax

```lua
local value = self:get_steering()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | value | Current per-wheel steering value |

---

### Examples

```lua lineNumbers title="Get the steering of a vehicle wheel"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

core.engine.print("info", "Vehicle wheel steering:", entity:get_steering())
```
