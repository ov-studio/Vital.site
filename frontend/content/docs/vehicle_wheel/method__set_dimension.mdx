---
title: self:set_dimension
description: Sets the dimension of the vehicle wheel
badge: shared
---

### Syntax

```lua
local status = self:set_dimension(
    dimension
)
```

<Callout type="idea">
  **A vehicle wheel follows the dimension of the entity it is attached to.**

  - **Inherited** — a vehicle wheel without a dimension of its own uses the dimension of its parent.
  - **Direct** — setting a dimension on it overrides the inherited one.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Dimension id to apply, must be `0` or greater |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` if the dimension is negative |

---

### Examples

```lua lineNumbers title="Set the dimension of a vehicle wheel"
local entity = physics.vehicle_wheel.create()

entity:set_dimension(1)
```
