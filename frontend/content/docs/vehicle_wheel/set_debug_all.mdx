---
title: physics.vehicle_wheel.set_debug_all
description: Shows or hides the debug overlay on all vehicle wheels, including ones created afterward
badge: client
---

### Syntax

```lua
local status = physics.vehicle_wheel.set_debug_all(
    state
)
```

<Callout type="info">
  **The overlay shows the wheel's live state.**

  - **Ring** — cyan while the wheel has full grip, shifting toward red as it skids, and magenta while it is airborne. The yellow spoke marks wheel rotation.
  - **Suspension** — a white cross at the connection point, an orange ray down to the bottom of the wheel at rest, a blue bar for the suspension travel range, and a line to the wheel center that turns from green to red as the spring compresses.
  - **Contact** — a red cross at the contact point, with the surface normal drawn from it.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to show the debug overlay on all vehicle wheels, `false` to hide it |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Toggle the wheel debug overlay globally"
physics.vehicle_wheel.set_debug_all(true)
```
