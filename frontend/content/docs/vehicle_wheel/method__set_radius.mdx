---
title: self:set_radius
description: Sets the radius of the wheel
badge: client
---

### Syntax

```lua
local status = self:set_radius(
    radius
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | radius | Wheel radius to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the radius of a vehicle wheel"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

entity:set_radius(0.4)
```
