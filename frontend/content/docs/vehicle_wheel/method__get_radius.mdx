---
title: self:get_radius
description: Retrieves the radius of the wheel
badge: client
---

### Syntax

```lua
local value = self:get_radius()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | value | Current wheel radius |

---

### Examples

```lua lineNumbers title="Get the radius of a vehicle wheel"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

core.engine.print("info", "Vehicle wheel radius:", entity:get_radius())
```
