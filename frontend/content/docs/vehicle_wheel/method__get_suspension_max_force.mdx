---
title: self:get_suspension_max_force
description: Retrieves the maximum force the suspension can exert on the wheel
badge: client
---

### Syntax

```lua
local value = self:get_suspension_max_force()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | value | Current suspension max force |

---

### Examples

```lua lineNumbers title="Get the suspension max force of a vehicle wheel"
local car = physics.vehicle.create()
local entity = physics.vehicle_wheel.create(car)

core.engine.print("info", entity:get_suspension_max_force())
```
