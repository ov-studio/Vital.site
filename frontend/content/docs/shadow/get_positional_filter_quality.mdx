---
title: gfx.shadow.get_positional_filter_quality
description: Retrieves the current soft shadow filter quality of positional lights
badge: client
---

### Syntax

```lua
local result = gfx.shadow.get_positional_filter_quality()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`gfx.shadow.quality`](/docs/shadow/enum/quality) | result | Current filter quality |

---

### Examples

```lua lineNumbers title="Print the positional filter quality"
core.engine.print("info", "Positional filter quality:", gfx.shadow.get_positional_filter_quality())
```
