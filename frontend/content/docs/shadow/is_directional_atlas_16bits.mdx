---
title: gfx.shadow.is_directional_atlas_16bits
description: Retrieves whether the directional shadow atlas uses a 16-bit depth buffer
badge: client
---

### Syntax

```lua
local result = gfx.shadow.is_directional_atlas_16bits()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the atlas uses a 16-bit depth buffer, `false` otherwise |

---

### Examples

```lua lineNumbers title="Print the directional atlas depth precision"
core.engine.print("info", "Directional atlas 16-bit:", gfx.shadow.is_directional_atlas_16bits())
```
