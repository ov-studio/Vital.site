---
title: gfx.shadow.is_positional_atlas_16bits
description: Retrieves whether the positional shadow atlas uses a 16-bit depth buffer
badge: client
---

### Syntax

```lua
local result = gfx.shadow.is_positional_atlas_16bits()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the atlas uses a 16-bit depth buffer, `false` if it uses a 32-bit depth buffer |

---

### Examples

```lua lineNumbers title="Print the positional atlas depth precision"
core.engine.print("info", "Positional atlas 16-bit:", gfx.shadow.is_positional_atlas_16bits())
```
