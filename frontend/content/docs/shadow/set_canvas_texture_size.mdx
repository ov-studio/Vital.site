---
title: gfx.shadow.set_canvas_texture_size
description: Sets the size of the 2D shadow texture
badge: client
---

### Syntax

```lua
local status = gfx.shadow.set_canvas_texture_size(
    size
)
```

<Callout type="info">
  **Only 2D light shadows are affected.**

  - **Shared** — the texture is shared by every 2D light with shadows.
  - **3D lights** — directional, omni and spot lights are not affected, see [`gfx.shadow.set_directional_atlas_size`](/docs/shadow/set_directional_atlas_size) and [`gfx.shadow.set_positional_atlas_size`](/docs/shadow/set_positional_atlas_size).
  - **Default** — `2048`.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | size | Texture size in pixels<br/>Must be between `256` and `16384`, values that are not a power of two are rounded up to the next one<br/>An error is raised if the value is out of range |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set a 4096 2D shadow texture"
gfx.shadow.set_canvas_texture_size(4096)
```
