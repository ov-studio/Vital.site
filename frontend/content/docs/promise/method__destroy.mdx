---
title: self:destroy
description: Destroys the promise instance and frees its resources
badge: shared
---

### Syntax

```lua
local status = self:destroy()
```

<Callout type="warn">
  **Destroying a pending promise will leave any threads awaiting it suspended indefinitely.**

  - **Before destroying** — settle the promise or make sure no threads are awaiting it first.
  - **Settled promise** — safe to destroy at any time.
  - **Pending promise with active waiters** — awaiting threads will never resume.
</Callout>

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Destroy a promise instance"
local entity = util.promise.create()

entity:resolve(true)
entity:destroy()
```
