---
title: self:apply_to_material
description: Applies the shader to matching materials of a model, or of every model
badge: client
---

### Syntax

```lua
local count = self:apply_to_material(
    model,
    component,
    material,
    priority = 0
)
```

<Callout type="info">
  **The shader automatically inherits values from the surface's original material.**

  - **Model instance** — applies to that model only and lasts as long as the model does. It does not apply to models spawned later.
  - **Wildcard `"*"`** — applies to all live models and is registered persistently for models spawned later.
  - **Priority** — when several shaders cover the same surface, the one with the highest `priority` is shown. On equal priority, the most recently applied shader wins. Applying the same shader to the same target again updates its priority and counts as the latest apply.
  - **Fallback** — when the shown shader is removed with [`self:remove_from_material`](/docs/shader/method/remove_from_material), destroyed or its resource stops, the next best shader takes over automatically. The surface only returns to its original material when no other shader covers it.
  - **Auto-binding** — see the [**Uniform Cheatsheet**](/docs/shader/cheatsheet/uniform) for uniform names populated automatically.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `model` \| `string` \| `nil` | model | Model instance to apply to<br/>Use `"*"` / `nil` to match every model and register the assignment for future spawns |
| `string` | component | Mesh component name or wildcard pattern to match |
| `string` | material | Surface material name or wildcard pattern to match |
| `int` | priority | Priority of this assignment, higher values win<br/>Can be negative |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | count | Number of surfaces on already-live models that matched |

---

### Examples

```lua lineNumbers title="Apply a shader to every material of one model"
core.model.load("character", "models/character.glb")

local model = core.model.create("character")
local entity = core.shader.create("assets/shaders/dissolve.glsl", core.shader.shader_mode.SPATIAL)

entity:apply_to_material(model, "*", "*")
```

```lua lineNumbers title="Apply a shader to a single material on all models, including future spawns"
local entity = core.shader.create("assets/shaders/dissolve.glsl", core.shader.shader_mode.SPATIAL)

entity:apply_to_material("*", "Skeleton3D/Body", "skin")
```

```lua lineNumbers title="Let a higher priority shader win regardless of apply order"
core.model.load("character", "models/character.glb")

local model = core.model.create("character")
local base = core.shader.create("assets/shaders/toon.glsl", core.shader.shader_mode.SPATIAL)
local highlight = core.shader.create("assets/shaders/highlight.glsl", core.shader.shader_mode.SPATIAL)

highlight:apply_to_material(model, "*", "*", 100)
base:apply_to_material(model, "*", "*") -- highlight is still shown, priority 100 beats 0
```

```lua lineNumbers title="Draw a translucent shader on top of the base shader"
core.model.load("character", "models/character.glb")

local model = core.model.create("character")
local base = core.shader.create("assets/shaders/toon.glsl", core.shader.shader_mode.SPATIAL)
local puddle = core.shader.create("assets/shaders/puddle.glsl", core.shader.shader_mode.SPATIAL)

base:apply_to_material(model, "*", "*")
puddle:apply_to_material(model, "*", "*", nil, true) -- drawn over toon, base is visible where puddle's ALPHA is 0
```

```lua lineNumbers title="Stack several layers, higher priority is drawn further on top"
local puddle = core.shader.create("assets/shaders/puddle.glsl", core.shader.shader_mode.SPATIAL)
local snow = core.shader.create("assets/shaders/snow.glsl", core.shader.shader_mode.SPATIAL)

puddle:apply_to_material("*", "*", "*", 0, true)
snow:apply_to_material("*", "*", "*", 10, true) -- snow is drawn over puddle
```

```lua lineNumbers title="Layer on top of a surface's own material without replacing it"
local puddle = core.shader.create("assets/shaders/puddle.glsl", core.shader.shader_mode.SPATIAL)

puddle:apply_to_material("*", "*", "*", nil, true) -- shaders from other scripts keep working as the base
```

```lua lineNumbers title="Switch an assignment between base and layered"
core.model.load("character", "models/character.glb")

local model = core.model.create("character")
local puddle = core.shader.create("assets/shaders/puddle.glsl", core.shader.shader_mode.SPATIAL)

puddle:apply_to_material(model, "*", "*")              -- puddle is the base
puddle:apply_to_material(model, "*", "*", 0, true)     -- same assignment, now layered
puddle:apply_to_material(model, "Body", "*", 0, false) -- Body: puddle is the base again, other components stay layered
```
