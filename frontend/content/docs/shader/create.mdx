---
title: core.shader.create
description: Creates a new shader instance by loading GLSL source from a file path
badge: client
---

### Syntax

```lua
local instance = core.shader.create(
    path,
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | path | File path to a GLSL shader asset |
| [`core.shader.shader_mode`](/docs/shader/enum/shader_mode) | mode | Rendering pipeline to target:<br/>• `CANVAS_ITEM` - 2D canvas shader<br/>• `SPATIAL` - 3D material shader<br/>• `POST_PROCESS` - full-screen effect over the rendered scene |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `shader` | instance | Created shader instance |

---

### Examples

```lua lineNumbers title="Load a canvas-item shader from a file"
local entity = core.shader.create("assets/shaders/ripple.glsl", core.shader.shader_mode.CANVAS_ITEM)

util.event.on("sandbox:draw", function()
    core.engine.draw_material(
        {0, 0}, 
        core.display.get_resolution(), 
        entity
    )
end)
```
