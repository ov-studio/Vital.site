---
title: Uniform Cheatsheet
description: Auto-inherited uniforms from the model's original material — no manual set_param needed
---

When a shader is applied to a model via `shader:apply_to_material(...)`, Vital automatically reads the
model surface's original `BaseMaterial3D` and feeds matching values into your shader uniforms.

Name your uniforms to match the tables below and they are populated for free. Any value you set
manually via `shader:set_param` takes priority over the auto-bind.

---

## Canvas Item

| Topic | Behavior |
|---|---|
| Auto-inherited uniforms | None, no `BaseMaterial3D` is involved |
| Feeding values | `shader:set_param` |

---

## Spatial

### Textures

Any `sampler2D` uniform whose name contains one of the keywords (e.g. `my_albedo_tex`) gets the matching texture. Matching is case-insensitive.

| Keywords | Source slot |
|---|---|
| `albedo_texture`, `diffuse_texture`, `basecolor_texture`, `base_color_texture` | Albedo / Base Color |
| `normal_texture` | Normal Map |
| `rough_texture`, `roughness_texture` | Roughness |
| `metal_texture`, `metallic_texture` | Metallic |
| `emission_texture` | Emission |
| `occlusion_texture`, `ao_texture`, `ambient_texture` | Ambient Occlusion |

### Scalars & Vectors

Uniform names must match exactly.

| Uniform name | Type | Source value |
|---|---|---|
| `roughness` | `float` | `BaseMaterial3D.roughness` |
| `metallic` | `float` | `BaseMaterial3D.metallic` |
| `specular` | `float` | `BaseMaterial3D.specular` |
| `normal_scale` | `float` | `BaseMaterial3D.normal_scale` |
| `emission_energy` | `float` | `BaseMaterial3D.emission_energy_multiplier` |
| `alpha_scissor_threshold` | `float` | `BaseMaterial3D.alpha_scissor_threshold` |
| `uv1_scale` | `vec3` | `BaseMaterial3D.uv1_scale` |
| `uv1_offset` | `vec3` | `BaseMaterial3D.uv1_offset` |

### Colors

Uniform names must match exactly. Declare as `vec4`, `vec3` or `Color`, Vital converts automatically.

| Uniform name | Source value |
|---|---|
| `albedo_color`, `albedo` | `BaseMaterial3D.albedo` |
| `emission`, `emission_color` | `BaseMaterial3D.emission` |

### Channel Masks

Packed textures such as glTF ORM (`ao` = R, `roughness` = G, `metallic` = B). Each uniform is a `vec4` mask for the channel Godot reads for that property, so `dot(texture, mask)` extracts it.

| Uniform name | Type | Example value |
|---|---|---|
| `roughness_channel` | `vec4` | `vec4(0,1,0,0)` |
| `metallic_channel` | `vec4` | `vec4(0,0,1,0)` |
| `ao_channel` | `vec4` | `vec4(1,0,0,0)` |

```glsl
uniform sampler2D orm_texture;
uniform vec4 roughness_channel;

void fragment() {
    ROUGHNESS = dot(texture(orm_texture, UV), roughness_channel);
}
```

## Post Process

Spatial shaders drawn on a full-screen quad. No uniforms are auto-inherited, feed values with `shader:set_param`.

| Topic | Behavior |
|---|---|
| Defaults | `shader_type spatial;` and `render_mode unshaded, cull_disabled, depth_test_disabled, depth_draw_never;` are added when the source omits them |
| Full-screen quad | Set `POSITION = vec4(VERTEX.xy, 1.0, 1.0);` in `vertex()` |
| Drawing | `core.engine.draw_material` inside `"sandbox:draw"` |

---

## Priority

Highest first.

| Order | Source | Used when |
|---|---|---|
| 1 | `shader:set_param` | Always, if set |
| 2 | Original surface material | The model has one and the uniform name matches |
| 3 | Default value declared in GLSL | Nothing above applies |

## Examples

```lua lineNumbers title="Spatial shader using auto-inherited uniforms"
local shader = core.shader.create_from_raw([[
    uniform sampler2D albedo_texture  : source_color, hint_default_white;
    uniform vec4      albedo_color    : source_color = vec4(1.0);
    uniform float     roughness       = 0.5;
    uniform float     metallic        = 0.0;
    uniform vec3      uv1_scale       = vec3(1.0);
    uniform vec3      uv1_offset      = vec3(0.0);

    void fragment() {
        vec2 uv   = UV * uv1_scale.xy + uv1_offset.xy;
        vec4 tex  = texture(albedo_texture, uv) * albedo_color;
        ALBEDO    = tex.rgb;
        ROUGHNESS = roughness;
        METALLIC  = metallic;
    }
]], core.shader.shader_mode.SPATIAL)

-- albedo_texture, roughness, metallic, uv1_scale, uv1_offset
-- are all pulled from the model's original material automatically.
shader:apply_to_material(my_model, "*", "*")
```
