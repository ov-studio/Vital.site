---
title: self:remove_from_material
description: Removes a shader assignment previously made with `self:apply_to_material`
badge: client
---

### Syntax

```lua
local count = self:remove_from_material(
    model,
    component,
    material
)
```

<Callout type="info">
  **Surfaces fall back to the next best shader.**

  - **What is removed** — this shader's own assignments on the given target that are covered by `component` and `material`. `"*"` covers everything, so `self:remove_from_material(model, "*", "*")` removes all of them.
  - **Layered** — base and layered assignments are removed alike. Remaining layers keep their order and stay on top.
  - **Narrower pattern** — never removes a broader assignment. Removing `"Body"` leaves an assignment made with `"*"` on the other components.
  - **Fallback** — each affected surface is handed to the next best assignment (highest priority, then most recently applied) and returns to its original material only when no other shader covers it.
  - **Earlier assignment** — if a later assignment of this shader was hiding an earlier one on the same surface, the earlier one shows again.
  - **Target** — a model instance removes assignments made for that model. `"*"` / `nil` removes assignments made with `"*"`. The two do not affect each other.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `model` \| `string` \| `nil` | model | Model instance to remove from<br/>Use `"*"` / `nil` to remove the persistent assignment made for every model |
| `string` | component | Mesh component name or wildcard pattern to match |
| `string` | material | Surface material name or wildcard pattern to match |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | count | Number of surfaces that were handed to another shader or restored |

---

### Examples

```lua lineNumbers title="Remove a shader from one model"
core.model.load("character", "models/character.glb")

local model = core.model.create("character")
local entity = core.shader.create("assets/shaders/dissolve.glsl", core.shader.shader_mode.SPATIAL)

entity:apply_to_material(model, "*", "*")
entity:remove_from_material(model, "*", "*")
```

```lua lineNumbers title="Remove a persistent shader assignment from all models"
local entity = core.shader.create("assets/shaders/dissolve.glsl", core.shader.shader_mode.SPATIAL)

entity:remove_from_material("*", "*", "*")
```

```lua lineNumbers title="Fall back to the previous shader"
core.model.load("character", "models/character.glb")

local model = core.model.create("character")
local a = core.shader.create("assets/shaders/toon.glsl", core.shader.shader_mode.SPATIAL)
local b = core.shader.create("assets/shaders/dissolve.glsl", core.shader.shader_mode.SPATIAL)

a:apply_to_material(model, "*", "*")
b:apply_to_material(model, "*", "*") -- b is shown
b:remove_from_material(model, "*", "*") -- a is shown again
```

```lua lineNumbers title="Remove a layer and keep the base shader"
core.model.load("character", "models/character.glb")

local model = core.model.create("character")
local base = core.shader.create("assets/shaders/toon.glsl", core.shader.shader_mode.SPATIAL)
local puddle = core.shader.create("assets/shaders/puddle.glsl", core.shader.shader_mode.SPATIAL)

base:apply_to_material(model, "*", "*")
puddle:apply_to_material(model, "*", "*", nil, true) -- puddle is drawn over toon
puddle:remove_from_material(model, "*", "*") -- only toon is shown again
```
