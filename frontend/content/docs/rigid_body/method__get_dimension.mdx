---
title: self:get_dimension
description: Retrieves the dimension of the rigid body
badge: shared
---

### Syntax

```lua
local dimension = self:get_dimension()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Current dimension id |

---

### Examples

```lua lineNumbers title="Get the dimension of a rigid body"
local entity = physics.rigid.create()

core.engine.print("info", "Rigid body dimension:", entity:get_dimension())
```
