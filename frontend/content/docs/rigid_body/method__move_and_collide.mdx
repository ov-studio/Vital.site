---
title: self:move_and_collide
description: Moves the rigid body by a motion vector, stopping and reporting the first collision encountered along the way
badge: shared
---

### Syntax

```lua
local collision = self:move_and_collide(
    motion,
    test_only = false
)
```

<Callout type="warn">
  **Moving a replicated entity is only allowed for the server or the client that owns it.**

  - **On the server** — always allowed, and the new position is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of.
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **When `test_only` is `true`** — only tests the motion, so it works on any entity.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | motion | Motion vector to move by as `{x, y, z}` |
| `bool` | test_only | Determines whether the motion is only tested:<br/>• When `true` - the motion is only tested, without actually moving the body<br/>• When `false` - the body is moved |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `table` | collision | Table with `position`, `normal`, `travel`, `remainder`, and `depth` fields, or `false` if no collision occurred |

---

### Examples

```lua lineNumbers title="Move a rigid body and detect collisions"
local entity = physics.rigid.create()

local collision = entity:move_and_collide({0, 0, -1})
if collision then
    core.engine.print("info", "Collision normal:", util.table.unpack(collision.normal))
end
```
