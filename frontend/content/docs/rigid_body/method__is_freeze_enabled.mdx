---
title: self:is_freeze_enabled
description: Checks whether the rigid body is currently frozen
badge: client
---

### Syntax

```lua
local result = self:is_freeze_enabled()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the condition is met, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check freeze state of a rigid body"
local entity = physics.rigid.create()

core.engine.print("info", "Rigid body freeze enabled:", entity:is_freeze_enabled())
```
