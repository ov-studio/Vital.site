---
title: self:set_constant_torque
description: Overwrites the rigid body's persistent constant torque
badge: client
---

### Syntax

```lua
local status = self:set_constant_torque(
    torque
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | torque | Torque vector to set as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Overwrite the constant torque"
local entity = physics.rigid.create()

entity:set_constant_torque({0, 0, 0})
```
