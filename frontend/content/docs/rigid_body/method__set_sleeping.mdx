---
title: self:set_sleeping
description: Sets whether the rigid body is sleeping
badge: shared
---

### Syntax

```lua
local status = self:set_sleeping(
    state
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/rigid_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines the sleep state of the body:<br/>• When `true` - the body is put to sleep<br/>• When `false` - the body is woken up |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Put a rigid body to sleep"
local entity = physics.rigid.create()

entity:set_sleeping(true)
```
