---
title: self:set_angular_velocity
description: Sets the angular velocity of the rigid body
badge: client
---

### Syntax

```lua
local status = self:set_angular_velocity(
    velocity
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | velocity | Angular velocity to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the angular velocity of a rigid body"
local entity = physics.rigid.create()

entity:set_angular_velocity({0, 1, 0})
```
