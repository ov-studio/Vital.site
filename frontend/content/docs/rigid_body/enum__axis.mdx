---
title: physics.rigid.axis
description: Enumeration of movement axes that can be individually locked on a physics body
badge: client
---

### Values

| Constant | Description |
|----------|-------------|
| `physics.rigid.axis.LINEAR_X` | Linear motion along the X axis |
| `physics.rigid.axis.LINEAR_Y` | Linear motion along the Y axis |
| `physics.rigid.axis.LINEAR_Z` | Linear motion along the Z axis |
| `physics.rigid.axis.ANGULAR_X` | Angular rotation around the X axis |
| `physics.rigid.axis.ANGULAR_Y` | Angular rotation around the Y axis |
| `physics.rigid.axis.ANGULAR_Z` | Angular rotation around the Z axis |

---

### Examples

```lua lineNumbers title="Lock the X linear axis on a body"
local entity = physics.rigid.create()

entity:set_axis_lock(physics.rigid.axis.LINEAR_X, true)
```
