---
title: self:get_angular_velocity
description: Retrieves the angular velocity of the rigid body
badge: client
---

### Syntax

```lua
local velocity = self:get_angular_velocity()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | velocity | Current angular velocity as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the angular velocity of a rigid body"
local entity = physics.rigid.create()
local velocity = entity:get_angular_velocity()

core.engine.print("info", "Rigid body velocity:", util.table.unpack(velocity))
```
