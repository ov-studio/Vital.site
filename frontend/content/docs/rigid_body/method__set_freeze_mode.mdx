---
title: self:set_freeze_mode
description: Sets the freeze mode of the rigid body
badge: client
---

### Syntax

```lua
local status = self:set_freeze_mode(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | mode | Freeze mode enum value — refer to [`physics.rigid.freeze_mode`](/docs/rigid_body/enum/freeze_mode) |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the freeze mode of a rigid body"
local entity = physics.rigid.create()

entity:set_freeze_mode(physics.rigid.freeze_mode.KINEMATIC)
```
