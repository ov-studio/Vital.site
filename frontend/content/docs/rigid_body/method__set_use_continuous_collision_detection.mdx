---
title: self:set_use_continuous_collision_detection
description: Sets whether continuous collision detection (CCD) is enabled, preventing fast-moving bodies from tunneling through thin geometry
badge: shared
---

### Syntax

```lua
local status = self:set_use_continuous_collision_detection(
    state
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/rigid_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether CCD is enabled:<br/>• When `true` - CCD is enabled<br/>• When `false` - CCD is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable CCD on a rigid body"
local entity = physics.rigid.create()

entity:set_use_continuous_collision_detection(true)
```
