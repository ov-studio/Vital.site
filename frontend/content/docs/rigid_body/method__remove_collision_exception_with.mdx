---
title: self:remove_collision_exception_with
description: Removes a previously added collision exception from the rigid body, restoring collision between the two bodies
badge: shared
---

### Syntax

```lua
local status = self:remove_collision_exception_with(
    body
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/rigid_body/method/get_syncer).
  - **On any other client** — raises an error when the entity is owned by the server or by another client.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `object` | body | Physics body instance to remove from the exception list — must be the same physics type as this instance |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Remove a collision exception on a rigid body"
local a = physics.rigid.create()
local b = physics.rigid.create()

a:add_collision_exception_with(b)
a:remove_collision_exception_with(b)
```
