---
title: self:get_axis_lock
description: Checks whether a specific movement axis is locked on the rigid body
badge: client
---

### Syntax

```lua
local result = self:get_axis_lock(
    axis
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | axis | Axis enum value — refer to [`physics.rigid.axis`](/docs/rigid_body/enum/axis) |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the axis is locked, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check an axis lock on a rigid body"
local entity = physics.rigid.create()

core.engine.print("info", "Rigid body axis lock:", entity:get_axis_lock(physics.rigid.axis.LINEAR_X))
```
