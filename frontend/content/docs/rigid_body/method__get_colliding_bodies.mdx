---
title: self:get_colliding_bodies
description: Retrieves a list of rigid bodies of the same type currently colliding with this rigid body
badge: client
---

### Syntax

```lua
local bodies = self:get_colliding_bodies()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `table` | bodies | Array of colliding rigid body instances |

---

### Examples

```lua lineNumbers title="Get colliding bodies of a rigid body"
local entity = physics.rigid.create()

for i, body in ipairs(entity:get_colliding_bodies()) do
    core.engine.print("info", body)
end
```
