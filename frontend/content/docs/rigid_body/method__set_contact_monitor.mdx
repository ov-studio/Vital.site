---
title: self:set_contact_monitor
description: Sets whether contact monitoring is enabled on the rigid body
badge: shared
---

### Syntax

```lua
local status = self:set_contact_monitor(
    state
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/rigid_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether contact monitoring is enabled:<br/>• When `true` - contact monitoring is enabled<br/>• When `false` - contact monitoring is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable contact monitoring on a rigid body"
local entity = physics.rigid.create()

entity:set_contact_monitor(true)
```
