---
title: self:apply_force
description: Applies a continuous force to the rigid body at a specific position, inducing torque, for the current physics step
badge: shared
---

### Syntax

```lua
local status = self:apply_force(
    force,
    position = {0, 0, 0}
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/rigid_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | force | Force vector to apply as `{x, y, z}` |
| `vector3` | position | World-space position offset to apply the force at |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply an off-center force"
local entity = physics.rigid.create()

entity:apply_force({0, 20, 0}, {1, 0, 0})
```
