---
title: self:set_can_sleep
description: Sets whether the rigid body is allowed to sleep when at rest
badge: client
---

### Syntax

```lua
local status = self:set_can_sleep(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to allow the body to sleep, `false` to keep it always active |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Disable sleep on a rigid body"
local entity = physics.rigid.create()

entity:set_can_sleep(false)
```
