---
title: self:is_sleeping
description: Checks whether the rigid body is currently sleeping (excluded from active physics simulation)
badge: client
---

### Syntax

```lua
local result = self:is_sleeping()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the condition is met, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check if a rigid body is sleeping"
local entity = physics.rigid.create()

core.engine.print("info", entity:is_sleeping())
```
