---
title: self:is_lock_rotation_enabled
description: Checks whether rotation is locked on the rigid body
badge: client
---

### Syntax

```lua
local result = self:is_lock_rotation_enabled()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the condition is met, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check rotation lock on a rigid body"
local entity = physics.rigid.create()

core.engine.print("info", entity:is_lock_rotation_enabled())
```
