### Values

<Callout type="info">
  **MSAA works alongside the antialiasing mode, it does not replace it.**

  - **Edges** — operates on geometry edges at the rasterization level.
  - **Combined** — works alongside [`gfx.antialiasing.aa_mode`](/docs/antialiasing/enum/aa_mode), it is not a replacement for FXAA/TAA.
</Callout>

| Constant | Description |
|----------|-------------|
| `gfx.antialiasing.msaa_mode.DISABLED` | MSAA is disabled. Fastest setting |
| `gfx.antialiasing.msaa_mode.X2` | 2× multi-sample antialiasing. Moderate performance cost |
| `gfx.antialiasing.msaa_mode.X4` | 4× multi-sample antialiasing. Good compromise between performance and quality |
| `gfx.antialiasing.msaa_mode.X8` | 8× multi-sample antialiasing. Very high performance cost |
