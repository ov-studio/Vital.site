---
title: core.engine.set_fps_limit
description: Sets the maximum frames per second
badge: shared
---

### Syntax

```lua
local status = core.engine.set_fps_limit(
    limit
)
```

<Callout type="info">
  **Behaviour depends on where it is called.**

  - **Server** — sets the FPS limit for every client, applied instantly at runtime and to clients that join later.
  - **Client** — sets the local FPS limit, which never exceeds the server's limit.
  - **No limit** — `0` removes the limit and is the default on both sides.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | limit | Maximum frames per second to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Limits the FPS to 60"
core.engine.set_fps_limit(60)
```

```lua lineNumbers title="Removes the FPS limit"
core.engine.set_fps_limit(0)
```
