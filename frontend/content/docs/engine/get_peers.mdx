---
title: core.engine.get_peers
description: Retrieves the ids of all connected peers
badge: server
---

### Syntax

```lua
local result = core.engine.get_peers()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `table` | result | Array of connected peer ids |

---

### Examples

```lua lineNumbers title="List every connected peer"
core.engine.iprint(core.engine.get_peers())
```
