---
title: core.engine.is_sandbox_ui_visible
description: Retrieves whether any sandbox UI is currently visible
badge: client
---

### Syntax

```lua
local result = core.engine.is_sandbox_ui_visible()
```

<Callout type="warn">
  **Scripts must check this themselves to stop reacting to game input.**

  - **Covers** — the console, the main menu, the splash and any visible, non-overlay webview that has focus without `forward_input`.
  - **Not covered** — `forward_input` webviews and overlays don't count, so the player can keep moving while they are open.
  - **Your responsibility** — key binds and polled input (`util.input.is_pressed`, `util.input.get_cursor_velocity`) keep reporting while a UI is open, so check this flag each frame before moving or rotating.
</Callout>

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if any sandbox UI is visible or has taken input focus, `false` otherwise |

---

### Examples

```lua lineNumbers title="Checks if any sandbox UI is currently visible"
core.engine.print("info", "Sandbox UI visible:", core.engine.is_sandbox_ui_visible())
```

```lua lineNumbers title="Ignores movement and camera input while a UI is open"
util.event.on("sandbox:process", function(delta)
    if core.engine.is_sandbox_ui_visible() then return end

    local velocity = util.input.get_cursor_velocity()
    -- Rotate the camera using velocity
end)
```
