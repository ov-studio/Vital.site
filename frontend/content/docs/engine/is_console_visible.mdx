---
title: core.engine.is_console_visible
description: Retrieves whether the console is currently visible
badge: client
---

### Syntax

```lua
local result = core.engine.is_console_visible()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the console is visible, `false` otherwise |

---

### Examples

```lua lineNumbers title="Checks if the console is currently visible"
core.engine.print("info", "Console visible:", core.engine.is_console_visible())
```
