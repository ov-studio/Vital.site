---
title: core.engine.get_platform
description: Retrieves current platform type
badge: shared
---

### Syntax

```lua
local result = core.engine.get_platform()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `string` | result | Current platform type:<br/>• `"client"` - indicates client-side execution<br/>• `"server"` - indicates server-side execution |

---

### Examples

```lua lineNumbers title="Prints current platform type"
core.engine.print("info", "Platform Type:", core.engine.get_platform())
```
