---
title: core.engine.disconnect_peer
description: Disconnects a connected peer from the server
badge: server
---

### Syntax

```lua
local status = core.engine.disconnect_peer(
    peer_id,
    reason = nil
)
```

<Callout type="warn">
  **The peer must be currently connected.**

  - An error is raised if `peer_id` does not belong to a connected peer.
  - The `reason` is clipped to 200 characters.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | peer_id | Peer id to disconnect |
| `string` | reason | Message shown to the player in their main menu |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Disconnect a peer when it joins"
util.event.on("peer:join", function(peer_id)
    core.engine.disconnect_peer(peer_id)
end)
```

```lua lineNumbers title="Kick a peer with a message"
core.engine.disconnect_peer(peer_id, "Kicked for using a modified client")
```
