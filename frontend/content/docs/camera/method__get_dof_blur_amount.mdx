---
title: self:get_dof_blur_amount
description: Retrieves the depth-of-field blur amount of the camera
badge: client
---

### Syntax

```lua
local amount = self:get_dof_blur_amount()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | amount | Current DOF blur amount |

---

### Examples

```lua lineNumbers title="Get the DOF blur amount of a camera"
local entity = core.camera.create()

core.engine.print("info", "DOF blur amount:", entity:get_dof_blur_amount())
```
