---
title: self:set_dof_blur_near_transition
description: Sets the near depth-of-field blur transition distance of the camera
badge: client
---

### Syntax

```lua
local status = self:set_dof_blur_near_transition(
    distance
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | distance | Near DOF blur transition distance to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the near DOF blur transition distance"
local entity = core.camera.create()

entity:set_dof_blur_near_enabled(true)
entity:set_dof_blur_near_distance(2)
entity:set_dof_blur_near_transition(1)
```
