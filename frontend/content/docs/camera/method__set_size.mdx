---
title: self:set_size
description: Sets the orthogonal size of the camera
badge: client
---

### Syntax

```lua
local status = self:set_size(
    size
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | size | Orthogonal size to apply to the camera |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the orthogonal size of a camera"
local entity = core.camera.create()

entity:set_projection(core.camera.projection.ORTHOGONAL)
entity:set_size(10)
```
