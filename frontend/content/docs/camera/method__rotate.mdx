---
title: self:rotate
description: Rotates the camera around the given axis by the specified angle in world space
badge: client
---

### Syntax

```lua
local status = self:rotate(
    axis,
    degrees
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | axis | World-space axis to rotate around as `{x, y, z}` |
| `float` | degrees | Angle to rotate in degrees |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Rotate a camera around the Y axis"
local entity = core.camera.create()

entity:rotate({0, 1, 0}, 45)
```
