---
title: self:set_keep_aspect
description: Sets the aspect ratio preservation mode of the camera
badge: client
---

### Syntax

```lua
local status = self:set_keep_aspect(
    mode
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`core.camera.keep_aspect`](/docs/camera/enum/keep_aspect) | mode | Aspect ratio mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the keep aspect mode of a camera"
local entity = core.camera.create()

entity:set_keep_aspect(core.camera.keep_aspect.HEIGHT)
```
