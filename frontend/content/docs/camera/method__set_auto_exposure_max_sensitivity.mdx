---
title: self:set_auto_exposure_max_sensitivity
description: Sets the maximum sensitivity for auto exposure
badge: client
---

### Syntax

```lua
local status = self:set_auto_exposure_max_sensitivity(
    sensitivity
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | sensitivity | Maximum auto exposure sensitivity value |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the maximum auto exposure sensitivity"
local entity = core.camera.create()

entity:set_auto_exposure_enabled(true)
entity:set_auto_exposure_max_sensitivity(800)
```
