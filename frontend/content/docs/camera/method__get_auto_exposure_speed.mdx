---
title: self:get_auto_exposure_speed
description: Retrieves the auto exposure adjustment speed of the camera
badge: client
---

### Syntax

```lua
local speed = self:get_auto_exposure_speed()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | speed | Current auto exposure adjustment speed |

---

### Examples

```lua lineNumbers title="Get the auto exposure speed of a camera"
local entity = core.camera.create()

core.engine.print("info", "Auto exposure speed:", entity:get_auto_exposure_speed())
```
