---
title: self:is_dof_blur_near_enabled
description: Checks whether near depth-of-field blur is enabled on the camera
badge: client
---

### Syntax

```lua
local result = self:is_dof_blur_near_enabled()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if near DOF blur is enabled, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check if near DOF blur is enabled"
local entity = core.camera.create()

core.engine.print("info", "Near DOF blur:", entity:is_dof_blur_near_enabled())
```
