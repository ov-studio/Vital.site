---
title: self:get_h_offset
description: Retrieves the horizontal offset of the camera
badge: client
---

### Syntax

```lua
local offset = self:get_h_offset()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | offset | Current horizontal offset of the camera |

---

### Examples

```lua lineNumbers title="Get the horizontal offset of a camera"
local entity = core.camera.create()

core.engine.print("info", "Horizontal offset:", entity:get_h_offset())
```
