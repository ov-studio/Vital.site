---
title: self:set_far_clip
description: Sets the far clipping plane distance of the camera
badge: client
---

### Syntax

```lua
local status = self:set_far_clip(
    z_far
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | z_far | Far clipping distance to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the far clip distance of a camera"
local entity = core.camera.create()

entity:set_far_clip(1000)
```
