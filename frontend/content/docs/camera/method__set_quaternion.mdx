---
title: self:set_quaternion
description: Sets the rotation of the camera using a quaternion
badge: client
---

### Syntax

```lua
local status = self:set_quaternion(
    quaternion
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector4` | quaternion | Rotation quaternion to apply as `{x, y, z, w}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the quaternion rotation of a camera"
local entity = core.camera.create()

entity:set_quaternion({0, 0, 0, 1})
```
