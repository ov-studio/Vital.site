---
title: self:set_h_offset
description: Sets the horizontal offset of the camera
badge: client
---

### Syntax

```lua
local status = self:set_h_offset(
    offset
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | offset | Horizontal offset to apply to the camera view |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the horizontal offset of a camera"
local entity = core.camera.create()

entity:set_h_offset(0.5)
```
