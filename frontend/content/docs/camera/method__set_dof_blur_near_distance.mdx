---
title: self:set_dof_blur_near_distance
description: Sets the near depth-of-field blur distance of the camera
badge: client
---

### Syntax

```lua
local status = self:set_dof_blur_near_distance(
    distance
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | distance | Near DOF blur distance to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the near DOF blur distance of a camera"
local entity = core.camera.create()

entity:set_dof_blur_near_enabled(true)
entity:set_dof_blur_near_distance(2)
```
