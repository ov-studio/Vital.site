---
title: self:set_dof_blur_near_enabled
description: Enables or disables near depth-of-field blur on the camera
badge: client
---

### Syntax

```lua
local status = self:set_dof_blur_near_enabled(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to enable near DOF blur, `false` to disable |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable near DOF blur on a camera"
local entity = core.camera.create()

entity:set_dof_blur_near_enabled(true)
entity:set_dof_blur_near_distance(2)
```
