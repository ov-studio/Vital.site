---
title: self:set_dof_blur_far_enabled
description: Enables or disables far depth-of-field blur on the camera
badge: client
---

### Syntax

```lua
local status = self:set_dof_blur_far_enabled(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether far DOF blur is enabled:<br/>• When `true` - far DOF blur is enabled<br/>• When `false` - far DOF blur is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable far DOF blur on a camera"
local entity = core.camera.create()

entity:set_dof_blur_far_enabled(true)
entity:set_dof_blur_far_distance(20)
```
