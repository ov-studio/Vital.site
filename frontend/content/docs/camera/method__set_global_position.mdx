---
title: self:set_global_position
description: Sets the global world-space position of the camera
badge: client
---

### Syntax

```lua
local status = self:set_global_position(
    position
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Global position to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the global position of a camera"
local entity = core.camera.create()

entity:set_global_position({0, 5, 10})
```
