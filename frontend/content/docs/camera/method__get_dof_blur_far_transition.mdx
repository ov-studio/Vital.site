---
title: self:get_dof_blur_far_transition
description: Retrieves the far depth-of-field blur transition distance of the camera
badge: client
---

### Syntax

```lua
local distance = self:get_dof_blur_far_transition()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | distance | Current far DOF blur transition distance |

---

### Examples

```lua lineNumbers title="Get the far DOF blur transition distance"
local entity = core.camera.create()

core.engine.print("info", "Far DOF transition:", entity:get_dof_blur_far_transition())
```
