---
title: self:get_bake_mode
description: Retrieves the bake mode of the point light
badge: client
---

### Syntax

```lua
local mode = self:get_bake_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | mode | Current bake mode enum value |

---

### Examples

```lua lineNumbers title="Get bake mode of a point light"
local entity = light.point.create()

core.engine.print("info", "Bake Mode:", entity:get_bake_mode())
```
