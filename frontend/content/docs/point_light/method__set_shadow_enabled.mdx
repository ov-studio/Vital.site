---
title: self:set_shadow_enabled
description: Sets whether the point light casts shadows
badge: client
---

### Syntax

```lua
local status = self:set_shadow_enabled(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether shadow casting is enabled:<br/>• When `true` - shadow casting is enabled<br/>• When `false` - shadow casting is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply shadow enabled on a point light"
local entity = light.point.create()

entity:set_shadow_enabled(true)
```
