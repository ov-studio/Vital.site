---
title: self:set_distance_fade_enabled
description: Sets whether distance-based fade is enabled on the point light
badge: client
---

### Syntax

```lua
local status = self:set_distance_fade_enabled(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether distance fade is enabled:<br/>• When `true` - distance fade is enabled<br/>• When `false` - distance fade is disabled |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply distance fade enabled on a point light"
local entity = light.point.create()

entity:set_distance_fade_enabled(true)
```
