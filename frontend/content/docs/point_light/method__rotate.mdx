---
title: self:rotate
description: Rotates the point light around an axis in the parent's coordinate space
badge: client
---

### Syntax

```lua
local status = self:rotate(
    axis,
    degrees
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | axis | Axis to rotate around as `{x, y, z}` |
| `float` | degrees | Angle in degrees |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Rotate a point light 90 degrees around the Y axis"
local entity = light.point.create()

entity:rotate({0, 1, 0}, 90)
```
