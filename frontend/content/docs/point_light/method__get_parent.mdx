---
title: self:get_parent
description: Retrieves the entity the point light is currently parented to
badge: client
---

### Syntax

```lua
local parent = self:get_parent()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `entity` \| `bool` | parent | Parent entity instance, `false` if the instance has no parent |

---

### Examples

```lua lineNumbers title="Get the parent of a point light"
local parent = light.point.create()
local child = light.point.create()

child:set_parent(parent)

core.engine.print("info", child:get_parent() == parent) -- true
core.engine.print("info", parent:get_parent()) -- false
```
