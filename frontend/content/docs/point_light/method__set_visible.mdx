---
title: self:set_visible
description: Sets the visibility of the point light
badge: client
---

### Syntax

```lua
local status = self:set_visible(
    visible
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | visible | Determines the visibility of the point light:<br/>• When `true` - the point light is shown<br/>• When `false` - the point light is hidden |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Hide a point light"
local entity = light.point.create()

entity:set_visible(false)
```
