---
title: self:get_color
description: Retrieves the color of the point light
badge: client
---

### Syntax

```lua
local color = self:get_color()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `color` | color | Current light color as `{r, g, b}` |

---

### Examples

```lua lineNumbers title="Get color of a point light"
local entity = light.point.create()

core.engine.print("info", "Color:", entity:get_color())
```
