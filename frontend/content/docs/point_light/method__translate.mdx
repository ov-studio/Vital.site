---
title: self:translate
description: Moves the point light by the given offset in the parent's coordinate space
badge: client
---

### Syntax

```lua
local status = self:translate(
    offset
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | offset | Offset to translate by as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Move a point light 2 units upward"
local entity = light.point.create()

entity:translate({0, 2, 0})
```
