---
title: self:destroy
description: Destroys the texture instance and frees its resources
badge: client
---

### Syntax

```lua
local status = self:destroy()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Destroy a texture instance"
local entity = core.texture.create("assets/sprite.png")

entity:destroy()
```
