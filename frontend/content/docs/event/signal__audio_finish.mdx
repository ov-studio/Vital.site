---
title: audio:finish
description: Fired when an audio instance reaches the end of its playback
badge: client
---

### Signal

```lua
"audio:finish"
```

<Callout type="warn">
  **Only playbacks that reach their natural end finish.**

  - **Natural end** — fires once the sound has played all the way through, after which [`self:is_playing`](/docs/audio_2d/method/is_playing) returns `false`.
  - **Stopping** — calling [`self:stop`](/docs/audio_2d/method/stop) does not fire this signal, the playback was interrupted rather than finished.
  - **Looped audio** — looped audio never finishes. See [`self:set_looped`](/docs/audio_2d/method/set_looped).
  - **Still alive** — the audio is still alive when the signal fires, so you can play it again, chain the next sound or call [`self:destroy`](/docs/audio_2d/method/destroy) on it for fire and forget sounds.
  - **Audio types** — fires for both [`core.audio_2d`](/docs/audio_2d/create) and [`core.audio_3d`](/docs/audio_3d/create).
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `core.audio_2d` \| `core.audio_3d` | audio | Audio instance whose playback has finished |

---

### Examples

```lua lineNumbers title="Clean up a fire and forget sound"
local function play_once(path)
    local entity = core.audio_2d.create(path)
    entity:play()
end

util.event.on("audio:finish", function(audio)
    audio:destroy()
end)

play_once("sounds/click.ogg")
```

```lua lineNumbers title="Play a playlist one track after another"
local playlist = { "music/intro.ogg", "music/main.ogg", "music/outro.ogg" }
local index = 0

local function next_track()
    index = index + 1
    if not playlist[index] then return end
    local entity = core.audio_2d.create(playlist[index])
    entity:play()
end

util.event.on("audio:finish", function(audio)
    audio:destroy()
    next_track()
end)

next_track()
```
