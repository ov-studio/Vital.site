---
title: entity:destroy
description: Fired when any entity instance is removed from the engine registry
badge: shared
---

### Signal

```lua
"entity:destroy"
```

<Callout type="info">
  **The entity reference is still valid during the handler.**

  - **Cleanup** — use it for last-moment cleanup before the entity is gone.
  - **After the handler** — after the handler returns the entity is removed from the registry and marked as destroyed.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `entity` | entity | The entity instance being destroyed |

---

### Example

```lua lineNumbers title="Clean up on entity destruction"
util.event.on("entity:destroy", function(entity)
    core.engine.print("info", "Entity destroyed:", entity:get_type())
end)
```
