---
title: audio:start
description: Fired when an audio instance starts playing
badge: client
---

### Signal

```lua
"audio:start"
```

<Callout type="info">
  **Fires once per playback, not once per loop.**

  - Triggered by [`self:play`](/docs/audio_2d/method/play) when the audio was not already playing, and by `autoplay` on a freshly created audio.
  - Calling [`self:play`](/docs/audio_2d/method/play) on audio that is already playing restarts it silently and does not fire the signal.
  - Resuming from [`self:set_paused`](/docs/audio_2d/method/set_paused) does not fire the signal, the playback never stopped.
  - Fires for both [`core.audio_2d`](/docs/audio_2d/create) and [`core.audio_3d`](/docs/audio_3d/create). Use `audio:is_type` to tell them apart.
  - Detected once per frame, so a play followed by a stop inside the same frame may not be reported.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `core.audio_2d` \| `core.audio_3d` | audio | Audio instance that started playing |

---

### Example

```lua lineNumbers title="React when a sound starts playing"
local entity = core.audio_2d.create("sounds/ambient.ogg")

util.event.on("audio:start", function(audio)
    core.engine.print("info", "audio:start:", audio:get_playback_position())
end)

entity:play()
```
