---
title: resource:stop
description: Fired when a resource has been stopped
badge: shared
---

### Signal

```lua
"resource:stop"
```

<Callout type="info">
  **On the server, stopping a resource also notifies all connected clients.**

  - **Clients** — clients will automatically stop their local copy of the resource after this fires on the server.
  - **Cleanup** — use this to clean up any state tied to the stopped resource.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Name of the resource that was stopped |

---

### Example

```lua lineNumbers title="React to a resource stopping"
util.event.on("resource:stop", function(name)
    core.engine.print("info", "Resource stopped:", name)
end)
```
