---
title: area:enter
description: Fired when a body or another area enters the area
badge: shared
---

### Signal

```lua
"area:enter"
```

<Callout type="info">
  **Only physics entities known to the sandbox trigger this signal.**

  - Fires for rigid, static, character and animatable bodies, as well as other areas.
  - Refer [`physics.area`](/docs/area/create) to create and configure the area that emits it.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `physics.area` | area | Area instance that was affected |
| `physics.rigid` \| `physics.static` \| `physics.character` \| `physics.animatable` \| `physics.area` | entity | Entity instance that triggered the signal |

---

### Example

```lua lineNumbers title="React when an entity enters an area"
local area = physics.area.create()

util.event.on("area:enter", function(area, entity)
    core.engine.print("info", "Entity entered area:", entity:get_type())
end)
```
