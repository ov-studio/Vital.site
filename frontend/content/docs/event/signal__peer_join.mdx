---
title: peer:join
description: Fired when a peer connects to the server
badge: server
---

### Signal

```lua
"peer:join"
```

<Callout type="info">
  **This signal is only fired on the server.**

  - The server starts every running resource on the peer after this fires.
  - Fires only after the peer has been authenticated and sent the full world state, so it is safe to interact with right away.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `int` | peer_id | Id of the peer that joined |

---

### Example

```lua lineNumbers title="Greet a joining peer"
util.event.on("peer:join", function(peer_id)
    core.engine.print("info", "Peer joined:", peer_id)
end)
```
