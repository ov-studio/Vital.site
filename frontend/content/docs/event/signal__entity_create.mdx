---
title: entity:create
description: Fired when any entity instance is registered into the engine
badge: shared
---

### Signal

```lua
"entity:create"
```

<Callout type="info">
  **Fires for all entity types — Model, Webview, Font, and any other registered entity.**

  - **Argument** — the `entity` argument is the same instance returned by the entity's constructor.
  - **Timing** — fires immediately after the entity is inserted into the registry.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `entity` | entity | The newly created entity instance |

---

### Example

```lua lineNumbers title="React to any entity being created"
util.event.on("entity:create", function(entity)
    core.engine.print("info", "Entity created:", entity:get_type())
end)
```
