---
title: peer:nickname:change
description: Fired when the player nickname is changed
badge: client
---

### Signal

```lua
"peer:nickname:change"
```

<Callout type="info">
  **This signal is only fired on the client.**

  - **Arguments** — both arguments are the effective username, an empty nickname resolves to the operating system username.
  - **Unchanged name** — it is not fired when the resulting username stays the same, e.g. when only whitespace changes.
  - **Initial value** — it is not fired for the nickname loaded at client start, use [`core.engine.get_nickname`](/docs/engine/get_nickname) to read it.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `string` | old_name | Username before the change |
| `string` | new_name | Username after the change |

---

### Example

```lua lineNumbers title="React to a nickname change"
util.event.on("peer:nickname:change", function(old_name, new_name)
    core.engine.print("info", "Nickname changed:", old_name, "->", new_name)
end)
```

```lua lineNumbers title="Keep a cached name up to date"
local player_name = core.engine.get_nickname()

util.event.on("peer:nickname:change", function(_, new_name)
    player_name = new_name
end)
```
