---
title: sandbox:key_input
description: Fired when a keyboard key or mouse button is pressed or released
badge: client
---

### Signal

```lua
"sandbox:key_input"
```

### Arguments

| Type | Name | Description |
|------|------|-------------|
| [`util.input.key`](/docs/input/enum/key) | keycode | Key or mouse button identifier |
| `bool` | pressed | `true` if pressed, `false` if released |

<Callout type="info">
  **Fires for both keyboard keys and mouse buttons.**

  - Key-repeat echoes are suppressed — only the initial press and release are reported.
  - If the engine console intercepts a key on press, that key will not fire this signal.
  - Refer to the [`util.input.key`](/docs/input/enum/key) enum for keycode values.
</Callout>

---

### Example

```lua lineNumbers title="Detect spacebar press"
util.event.on("sandbox:key_input", function(keycode, pressed)
    if keycode == util.input.key.SPACE and pressed then
        core.engine.print("info", "Space pressed")
    end
end)
```

```lua lineNumbers title="Detect left mouse button"
util.event.on("sandbox:key_input", function(keycode, pressed)
    if keycode == util.input.key.MOUSE_LEFT then
        core.engine.print("info", "LMB " .. (pressed and "down" or "up"))
    end
end)
```
