---
title: resource:start
description: Fired when a resource has started successfully
badge: shared
---

### Signal

```lua
"resource:start"
```

<Callout type="info">
  **On the server, starting a resource also notifies all connected clients.**

  - **Clients** — clients will automatically receive and register the resource after this fires on the server.
  - **Timing** — fires after the resource's scripts have run, so it is already running.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Name of the resource that started |

---

### Example

```lua lineNumbers title="React to a resource starting"
util.event.on("resource:start", function(name)
    core.engine.print("info", "Resource started:", name)
end)
```
