---
title: webview:resize
description: Fired when a webview is resized
badge: client
---

### Signal

```lua
"webview:resize"
```

<Callout type="info">
  **Also triggers the input forwarder selection to be re-evaluated.**

  - Use this to adjust layout or re-anchor UI elements that depend on the webview's size.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `core.webview` | webview | The webview instance that was resized |

---

### Example

```lua lineNumbers title="React to webview resize"
util.event.on("webview:resize", function(webview)
    local size = webview:get_size()
    core.engine.print("info", "Webview resized:", size[1], size[2])
end)
```
