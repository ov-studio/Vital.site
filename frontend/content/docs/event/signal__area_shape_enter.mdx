---
title: area:shape_enter
description: Fired when a body or another area enters one of the area's collision shapes
badge: shared
---

### Signal

```lua
"area:shape_enter"
```

<Callout type="info">
  **Only physics entities known to the sandbox trigger this signal.**

  - **Supported entities** — fires for rigid, static, character and animatable bodies, as well as other areas.
  - **Area** — refer [`physics.area`](/docs/area/create) to create and configure the area that emits it.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `physics.area` | area | Area instance that was affected |
| `physics.rigid` \| `physics.static` \| `physics.character` \| `physics.animatable` \| `physics.area` | entity | Entity instance that triggered the signal |

---

### Example

```lua lineNumbers title="React when an entity enters a collision shape of an area"
local area = physics.area.create()

util.event.on("area:shape_enter", function(area, entity)
    core.engine.print("info", "Entity entered area shape:", entity:get_type())
end)
```
