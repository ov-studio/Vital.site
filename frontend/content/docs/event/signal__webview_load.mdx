---
title: webview:load
description: Fired when a webview finishes loading a page
badge: client
---

### Signal

```lua
"webview:load"
```

<Callout type="info">
  **Fires once the page has fully loaded.**

  - **Ready** — safe to interact with page content or send initial messages after this fires.
  - **Earlier hook** — use [`webview:preload`](/docs/event/signal/webview_preload) instead to react to the start of a page load.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `core.webview` | webview | The webview instance triggering the event |
| `string` | url | The URL that finished loading |

---

### Example

```lua lineNumbers title="Detect webview page load"
util.event.on("webview:load", function(webview, url)
    core.engine.print("info", "Webview loaded:", url)
end)
```
