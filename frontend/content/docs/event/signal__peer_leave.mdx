---
title: peer:leave
description: Fired when a peer disconnects from the server
badge: server
---

### Signal

```lua
"peer:leave"
```

<Callout type="info">
  **This signal is only fired on the server.**

  - **Cleanup** — use it to clean up any state you keep per peer.
  - **Admitted peers** — fires only for peers that were admitted, see [`peer:join`](/docs/event/signal/peer_join).
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `int` | peer_id | Id of the peer that left |

---

### Example

```lua lineNumbers title="Clean up after a leaving peer"
local players = {}

util.event.on("peer:leave", function(peer_id)
    players[peer_id] = nil
end)
```
