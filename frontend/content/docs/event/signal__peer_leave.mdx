---
title: peer:leave
description: Fired when a peer disconnects from the server
badge: server
---

### Signal

```lua
"peer:leave"
```

<Callout type="info">
  **This signal is only fired on the server.**

  - Use it to clean up any state you keep per peer.
  - Fires only for peers that already triggered [`peer:join`](/docs/event/signal/peer_join), a peer that drops before being admitted never reaches your scripts.
</Callout>

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `int` | peer_id | Id of the peer that left |

---

### Example

```lua lineNumbers title="Clean up after a leaving peer"
local players = {}

util.event.on("peer:leave", function(peer_id)
    players[peer_id] = nil
end)
```
