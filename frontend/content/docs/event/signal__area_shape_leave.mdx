---
title: area:shape_leave
description: Fired when a body or another area leaves one of the area's collision shapes
badge: shared
---

### Signal

```lua
"area:shape_leave"
```

### Arguments

| Type | Name | Description |
|------|------|-------------|
| `area` | area | Area instance that was affected |
| `userdata` | entity | Rigid, static, character, animatable body or area instance that triggered the signal |

<Callout type="info">
  **Only physics entities known to the sandbox trigger this signal.**

  - Fires for rigid, static, character and animatable bodies, as well as other areas.
  - Refer [`physics.area`](/docs/area/create) to create and configure the area that emits it.
</Callout>

---

### Example

```lua lineNumbers title="React when an entity leaves a collision shape of an area"
local area = physics.area.create()

util.event.on("area:shape_leave", function(area, entity)
    core.engine.print("info", "area:shape_leave:", entity:get_type())
end)
```
