---
title: self:set_monitorable
description: Sets whether the area can be detected by other monitoring areas
badge: shared
---

### Syntax

```lua
local status = self:set_monitorable(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines whether other areas can detect this area:<br/>• When `true` - detection by other areas is allowed<br/>• When `false` - detection by other areas is disallowed |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable monitorable on an area"
local entity = physics.area.create()

entity:set_monitorable(true)
```
