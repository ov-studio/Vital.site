---
title: physics.area.create
description: Creates a new area instance and adds it to the scene
badge: client
---

### Syntax

```lua
local instance = physics.area.create()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `object` | instance | Created area instance |

---

### Examples

```lua lineNumbers title="Create a area instance"
local entity = physics.area.create()

local shape = physics.collision_shape.create(entity)
shape:set_shape_box({4, 4, 4})

entity:set_monitoring(true)
```
