---
title: self:get_overlapping_areas
description: Retrieves all other areas currently overlapping this area
badge: client
---

### Syntax

```lua
local areas = self:get_overlapping_areas()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `table` | areas | Array of overlapping area instances |

---

### Examples

```lua lineNumbers title="Get overlapping areas on an area"
local entity = physics.area.create()

for i, other in ipairs(entity:get_overlapping_areas()) do
    core.engine.print("info", other)
end
```
