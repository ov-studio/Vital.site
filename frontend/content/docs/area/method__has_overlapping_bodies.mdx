---
title: self:has_overlapping_bodies
description: Checks whether any physics bodies currently overlap the area
badge: client
---

### Syntax

```lua
local result = self:has_overlapping_bodies()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the condition is met, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check overlapping bodies on an area"
local entity = physics.area.create()

core.engine.print("info", entity:has_overlapping_bodies())
```
