---
title: self:get_global_position
description: Retrieves the global position of the area
badge: client
---

### Syntax

```lua
local position = self:get_global_position()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Current global position as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global position of a area"
local entity = physics.area.create()
local position = entity:get_global_position()

core.engine.print("info", "Position:", util.table.unpack(position))
```
