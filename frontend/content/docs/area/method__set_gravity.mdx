---
title: self:set_gravity
description: Sets the gravity magnitude of the area
badge: client
---

### Syntax

```lua
local status = self:set_gravity(
    gravity
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | gravity | Gravity magnitude to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the gravity magnitude of an area"
local entity = physics.area.create()

entity:set_gravity(9.8)
```
