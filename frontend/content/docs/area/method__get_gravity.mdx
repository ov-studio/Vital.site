---
title: self:get_gravity
description: Retrieves the gravity magnitude of the area
badge: client
---

### Syntax

```lua
local gravity = self:get_gravity()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | gravity | Current gravity magnitude |

---

### Examples

```lua lineNumbers title="Get the gravity magnitude of an area"
local entity = physics.area.create()

core.engine.print("info", entity:get_gravity())
```
