---
title: self:set_priority
description: Sets the priority of the area, used to resolve overlapping area override order
badge: client
---

### Syntax

```lua
local status = self:set_priority(
    priority
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | priority | Priority value to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the priority of an area"
local entity = physics.area.create()

entity:set_priority(1)
```
