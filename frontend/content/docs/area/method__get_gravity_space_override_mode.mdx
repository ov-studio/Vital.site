---
title: self:get_gravity_space_override_mode
description: Retrieves the gravity space override mode of the area
badge: client
---

### Syntax

```lua
local mode = self:get_gravity_space_override_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | mode | Current space override enum value — refer to [`physics.area.space_override`](/docs/area/enum/space_override) |

---

### Examples

```lua lineNumbers title="Get the gravity space override mode of an area"
local entity = physics.area.create()

core.engine.print("info", "Gravity Space Override Mode:", entity:get_gravity_space_override_mode())
```
