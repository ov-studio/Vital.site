---
title: self:get_gravity_space_override_mode
description: Retrieves the gravity space override mode of the area
badge: shared
---

### Syntax

```lua
local result = self:get_gravity_space_override_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`physics.area.space_override`](/docs/area/enum/space_override) | result | Current space override mode |

---

### Examples

```lua lineNumbers title="Get the gravity space override mode of an area"
local entity = physics.area.create()

core.engine.print("info", "Area gravity space override mode:", entity:get_gravity_space_override_mode())
```
