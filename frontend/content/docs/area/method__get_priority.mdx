---
title: self:get_priority
description: Retrieves the priority of the area, used to resolve overlapping area override order
badge: shared
---

### Syntax

```lua
local result = self:get_priority()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | result | Current priority |

---

### Examples

```lua lineNumbers title="Get the priority of an area"
local entity = physics.area.create()

core.engine.print("info", "Area priority:", entity:get_priority())
```
