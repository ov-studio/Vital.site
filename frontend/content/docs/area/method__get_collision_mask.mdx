---
title: self:get_collision_mask
description: Retrieves the collision mask bitmask of the area
badge: client
---

### Syntax

```lua
local mask = self:get_collision_mask()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | mask | Current collision mask bitmask |

---

### Examples

```lua lineNumbers title="Get the collision mask of a area"
local entity = physics.area.create()

core.engine.print("info", "Collision Mask:", entity:get_collision_mask())
```
