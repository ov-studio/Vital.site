---
title: util.easing.bounce_in
description: Applies a bounce ease-in — simulates a ball bouncing before the main motion begins
badge: shared
---

### Syntax

```lua
local result = util.easing.bounce_in(
    progress
)
```

<Callout type="info">
  **Bounce easing simulates the physics of a ball dropping and bouncing multiple times before coming to rest.**

  - **Always within [0, 1]** — unlike Back or Elastic, Bounce never exits the normal range.
  - **Best for** — dropped objects, notification alerts, progress bars completing, and any grounded physical motion.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | progress | Interpolation factor, typically in the range [0, 1] |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | result | Eased progress value |

---

### Examples

```lua lineNumbers title="Sample output at key progress values"
core.engine.print("info", util.easing.bounce_in(0.0))  -- 0.0
core.engine.print("info", util.easing.bounce_in(0.25)) -- near start
core.engine.print("info", util.easing.bounce_in(0.5))  -- midpoint
core.engine.print("info", util.easing.bounce_in(0.75)) -- near end
core.engine.print("info", util.easing.bounce_in(1.0))  -- 1.0
```

```lua lineNumbers title="Pair with lerp to animate a value"
local result = util.easing.lerp(0, 100, util.easing.bounce_in(0.5))

core.engine.print("info", result)
```

```lua lineNumbers title="Animate a circle across the screen"
local resolution = core.engine.get_resolution()
local duration = 1.5
local start_tick = core.engine.get_tick()

util.event.on("sandbox:draw", function()
    local elapsed = (core.engine.get_tick() - start_tick) / 1000.0
    local t = math.min(elapsed / duration, 1.0)
    local x = util.easing.lerp(0, resolution[1], util.easing.bounce_in(t))

    core.engine.draw_circle({x, resolution[2]*0.5}, 16, {1, 1, 1, 1})
end)
```
