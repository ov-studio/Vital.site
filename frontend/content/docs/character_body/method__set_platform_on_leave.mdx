---
title: self:set_platform_on_leave
description: Sets the platform-leave velocity behavior of the character body
badge: shared
---

### Syntax

```lua
local status = self:set_platform_on_leave(
    mode
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/character_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| [`physics.character.platform_on_leave`](/docs/character_body/enum/platform_on_leave) | mode | Platform-on-leave mode to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set platform on leave for a character body"
local entity = physics.character.create()

entity:set_platform_on_leave(physics.character.platform_on_leave.ADD_VELOCITY)
```
