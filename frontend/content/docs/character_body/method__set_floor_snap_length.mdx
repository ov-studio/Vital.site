---
title: self:set_floor_snap_length
description: Sets the distance the character body will snap down to stay attached to the floor when walking down slopes or steps
badge: shared
---

### Syntax

```lua
local status = self:set_floor_snap_length(
    length
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/character_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | length | Snap length to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the floor snap length of a character body"
local entity = physics.character.create()

entity:set_floor_snap_length(0.1)
```
