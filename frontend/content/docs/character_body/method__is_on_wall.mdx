---
title: self:is_on_wall
description: Checks whether the character body is currently touching a wall
badge: client
---

### Syntax

```lua
local result = self:is_on_wall()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the condition is met, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check if a character body is on a wall"
local entity = physics.character.create()

core.engine.print("info", "On Wall:", entity:is_on_wall())
```
