---
title: self:get_platform_velocity
description: Retrieves the velocity of the moving platform the character body is currently standing on
badge: client
---

### Syntax

```lua
local velocity = self:get_platform_velocity()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | velocity | Platform velocity as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the platform velocity of a character body"
local entity = physics.character.create()
local velocity = entity:get_platform_velocity()

core.engine.print("info", "Velocity:", util.table.unpack(velocity))
```
