---
title: self:set_syncer
description: Assigns the peer that holds sync authority over the character body
badge: server
---

### Syntax

```lua
local status = self:set_syncer(
    peer_id
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | peer_id | Peer that receives sync authority:<br/>• When `0` - authority is handed back to the server<br/>• Any other value - must be the id of a connected peer, otherwise an error is raised |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Hand a character body to a connected peer"
local entity = physics.character.create()
local peers = core.engine.get_peers()

if peers[1] then
    entity:set_syncer(peers[1])
end
```
