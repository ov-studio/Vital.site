---
title: self:get_collision_priority
description: Retrieves the collision priority of the character body, used to resolve overlapping collision resolution
badge: client
---

### Syntax

```lua
local priority = self:get_collision_priority()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `float` | priority | Current collision priority |

---

### Examples

```lua lineNumbers title="Get the collision priority of a character body"
local entity = physics.character.create()

core.engine.print("info", entity:get_collision_priority())
```
