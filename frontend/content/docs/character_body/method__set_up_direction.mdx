---
title: self:set_up_direction
description: Sets the up direction used by the character body to determine floor, wall, and ceiling surfaces
badge: client
---

### Syntax

```lua
local status = self:set_up_direction(
    direction
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | direction | Up direction to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the up direction of a character body"
local entity = physics.character.create()

entity:set_up_direction({0, 1, 0})
```
