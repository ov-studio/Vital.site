---
title: self:get_motion_mode
description: Retrieves the motion mode of the character body
badge: shared
---

### Syntax

```lua
local result = self:get_motion_mode()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| [`physics.character.motion_mode`](/docs/character_body/enum/motion_mode) | result | Current motion mode |

---

### Examples

```lua lineNumbers title="Get the motion mode of a character body"
local entity = physics.character.create()

core.engine.print("info", "Character body motion mode:", entity:get_motion_mode())
```
