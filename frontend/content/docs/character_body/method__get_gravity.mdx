---
title: self:get_gravity
description: Retrieves the current combined gravity vector affecting the character body
badge: client
---

### Syntax

```lua
local gravity = self:get_gravity()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | gravity | Current gravity vector as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the gravity affecting a character body"
local entity = physics.character.create()
local gravity = entity:get_gravity()

core.engine.print("info", "Character body gravity:", util.table.unpack(gravity))
```
