---
title: self:scale_global
description: Scales the character body in the global coordinate space
badge: client
---

### Syntax

```lua
local status = self:scale_global(
    scale
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Scale factor to apply as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Scale a character body globally"
local entity = physics.character.create()

entity:scale_global({2, 2, 2})
```
