---
title: self:is_type
description: Checks whether the instance belongs to the specified type
badge: client
---

### Syntax

```lua
local result = self:is_type(
    name
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Type to check against |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the instance matches the given type, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check the type of a character body instance"
local entity = physics.character.create()

core.engine.print("info", entity:is_type("physics.character")) -- true
core.engine.print("info", entity:is_type("model"))  -- false
```
