---
title: self:get_velocity
description: Retrieves the current velocity of the character body
badge: client
---

### Syntax

```lua
local velocity = self:get_velocity()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | velocity | Current velocity as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the velocity of a character body"
local entity = physics.character.create()
local velocity = entity:get_velocity()

core.engine.print("info", "Character body velocity:", util.table.unpack(velocity))
```
