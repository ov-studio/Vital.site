---
title: self:set_slide_on_ceiling_enabled
description: Sets whether the character body slides along ceilings instead of stopping abruptly when its head hits one
badge: shared
---

### Syntax

```lua
local status = self:set_slide_on_ceiling_enabled(
    state
)
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, see [`self:get_syncer`](/docs/character_body/method/get_syncer).
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | Determines the behavior on ceilings:<br/>• When `true` - the body slides along ceilings<br/>• When `false` - the body stops abruptly |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Enable slide on ceiling for a character body"
local entity = physics.character.create()

entity:set_slide_on_ceiling_enabled(true)
```
