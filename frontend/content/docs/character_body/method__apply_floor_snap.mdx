---
title: self:apply_floor_snap
description: Immediately snaps the character body to the floor if it is within snapping distance
badge: shared
---

### Syntax

```lua
local status = self:apply_floor_snap()
```

<Callout type="warn">
  **Replicated entities can only be modified by the server or the client that owns them.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of, refer [`self:get_syncer`](/docs/character_body/method/get_syncer).
  - **On any other client** — raises an error when the entity is owned by the server or by another client.
  - **Client-local entities** — entities that are not replicated are unrestricted.
</Callout>

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Apply floor snap on a character body"
local entity = physics.character.create()

entity:apply_floor_snap()
```
