---
title: self:get_position
description: Retrieves the local position of the character body
badge: client
---

### Syntax

```lua
local position = self:get_position()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Current local position as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the local position of a character body"
local entity = physics.character.create()
local position = entity:get_position()

core.engine.print("info", "Character body position:", util.table.unpack(position))
```
