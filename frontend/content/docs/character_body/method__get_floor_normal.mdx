---
title: self:get_floor_normal
description: Retrieves the normal of the floor the character body is currently standing on
badge: client
---

### Syntax

```lua
local normal = self:get_floor_normal()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | normal | Floor normal as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the floor normal of a character body"
local entity = physics.character.create()

core.engine.print("info", entity:get_floor_normal())
```
