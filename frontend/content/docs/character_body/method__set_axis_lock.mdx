---
title: self:set_axis_lock
description: Locks or unlocks a specific movement axis on the character body
badge: client
---

### Syntax

```lua
local status = self:set_axis_lock(
    axis,
    lock
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `int` | axis | Axis enum value — refer to [`physics.character.axis`](/docs/character_body/enum/axis) |
| `bool` | lock | `true` to lock the axis, `false` to unlock it |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Lock an axis on a character body"
local entity = physics.character.create()

entity:set_axis_lock(physics.character.axis.LINEAR_X, true)
```
