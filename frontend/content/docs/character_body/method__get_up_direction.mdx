---
title: self:get_up_direction
description: Retrieves the up direction used by the character body to determine floor, wall, and ceiling surfaces
badge: client
---

### Syntax

```lua
local direction = self:get_up_direction()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | direction | Current up direction as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the up direction of a character body"
local entity = physics.character.create()

core.engine.print("info", entity:get_up_direction())
```
