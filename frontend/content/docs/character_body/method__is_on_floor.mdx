---
title: self:is_on_floor
description: Checks whether the character body is currently touching a floor
badge: client
---

### Syntax

```lua
local result = self:is_on_floor()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the condition is met, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check if a character body is on the floor"
local entity = physics.character.create()

core.engine.print("info", "Character body on floor:", entity:is_on_floor())
```
