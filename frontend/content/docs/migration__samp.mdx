## Overview

SA-MP is a multiplayer modification for GTA San Andreas. Its scripting language is Pawn — a compiled, statically typed language designed for embedded use. SA-MP has not received updates since 2019.

Vital.sandbox uses **Lua** — dynamically typed, first-class functions, coroutines, and closures. The API surface is consistent and structured. Asset formats, the resource system, and scripting patterns differ significantly from SA-MP.

## What carries over

Pawn must be fully rewritten in Lua. There is no transpiler. The logic and systems you have built translate once you understand the equivalent APIs:

| System | SA-MP | Vital.sandbox |
|--------|-------|---------------|
| Events | `OnPlayerConnect`, `OnVehicleDeath`, etc. (callbacks) | `util.event.on` / `util.event.emit` — unified, priority-ordered, remote firing, async callbacks |
| Timers | `SetTimer` / `SetTimerEx` / `KillTimer` | `util.timer` — create, start, stop, reset |
| HTTP | Via plugin | `util.http.get` / `util.http.post` — headers, timeout, no plugin |
| Database | MySQL/SQLite via plugin | `core.database` + `core.database_query` — MySQL, schema definition, async execution |
| 3D Models | `CreateObject` / `MoveObject` + `.DFF` / `.TXD` / `.COL` | `core.model.create` — GLB, collision embedded, animation, bones, blendshapes, material overrides |
| Vehicles | `CreateVehicle` + callbacks | `physics.vehicle_body` + `physics.vehicle_wheel` — engine force, brake, steering, velocity, impulse, CCD |
| UI | TextDraw only | `core.webview` (HTML/CSS/JS), `core.canvas` (2D draw), `core.rendertarget` (texture render) |
| Audio | None built-in | `core.audio_2d` / `core.audio_3d` — volume, pitch, FX chain, spatial attenuation — OGG, WAV, MP3 |
| Images | None built-in | `core.image` / `core.svg` — JPG, PNG, WEBP, BMP, DDS, KTX, EXR |
| File I/O | None built-in | `util.file` — read, write, hash, delete |
| Networking | SA-MP sync layer | `ISyncable` net IDs, `core.engine.get_entity_by_net_id`, server-authoritative replication |
| Async scripting | Callback-based only | `util.thread` + `util.promise` — yield on await, resume on resolution |

## What does not carry over

- **GTA San Andreas assets** — map, vehicles, weapons, peds, interiors. You need your own assets in supported formats.
- **Pawn code** — must be fully rewritten in Lua. There is no automated migration path.
- **SA-MP filterscripts and gamemodes** — Vital.sandbox uses `manifest.yaml` per resource with a different structure.
- **GTA-SA specific APIs** — ped animation sets, weapon pickups, wanted level, and anything that addresses the GTA binary directly. These have no equivalent.
- **Built-in game world** — there is no world loaded by default. Map, terrain, and environment are your own assets.
