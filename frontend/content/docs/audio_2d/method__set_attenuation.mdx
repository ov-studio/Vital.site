---
title: self:set_attenuation
description: Sets the attenuation curve factor of the audio-2d instance
badge: client
---

### Syntax

```lua
local status = self:set_attenuation(
    value
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | value | Attenuation curve factor to apply<br/>Higher values cause volume to drop off more sharply with distance |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set a sharper attenuation curve"
local entity = core.audio_2d.create("sounds/ambient.ogg")

entity:set_attenuation(2.0)
```
