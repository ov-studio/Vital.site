---
title: self:get_type
description: Retrieves the type of the instance
badge: client
---

### Syntax

```lua
local type = self:get_type()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `string` | type | Type name of the instance |

---

### Examples

```lua lineNumbers title="Get the type of a display instance"
local entity = core.display.get_texture()

core.engine.print("info", entity:get_type()) -- "display"
```
