---
title: self:set_debug_visible
description: Shows or hides a live wireframe outline of the collision shape's current geometry — the wireframe automatically moves with the shape and updates whenever its size is changed. Not supported for world boundary or separation ray shapes.
badge: client
---

### Syntax

```lua
local status = self:set_debug_visible(
    state
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to show the wireframe, `false` to hide it |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Show the debug wireframe on a collision shape"
local body = physics.rigid.create()
local entity = physics.collision_shape.create(body)
entity:set_shape_box({1, 1, 1})

entity:set_debug_visible(true)
```
