---
title: self:translate_local
description: Translates the collision shape by an offset in its own local coordinate space
badge: shared
---

### Syntax

```lua
local status = self:translate_local(
    offset
)
```

<Callout type="warn">
  **Replicated shapes can only be modified by the server or the owner of their body.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of.
  - **On any other client** — raises an error on server-owned or other clients' entities.
  - **Client-local entities** — entities that are not replicated are unrestricted.
  - **Attached entities** — a collision shape follows the authority of its body.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | offset | Offset to translate by as `{x, y, z}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Translate a collision shape locally"
local entity = physics.collision_shape.create()

entity:translate_local({0, 0, -1})
```
