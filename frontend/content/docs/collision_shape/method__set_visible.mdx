---
title: self:set_visible
description: Sets whether the collision shape is visible
badge: shared
---

### Syntax

```lua
local status = self:set_visible(
    visible
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | visible | Determines the visibility of the entity:<br/>• When `true` - the entity is shown<br/>• When `false` - the entity is hidden |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Toggle visibility of a collision shape"
local entity = physics.collision_shape.create()

entity:set_visible(false)
```
