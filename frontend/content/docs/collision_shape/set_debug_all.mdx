---
title: physics.collision_shape.set_debug_all
description: Shows or hides the debug wireframe on all collision shapes, including ones created afterward
badge: client
---

### Syntax

```lua
local status = physics.collision_shape.set_debug_all(
    state
)
```

<Callout type="info">
  **Wireframe color shows whether the shape is replicated.**

  - **Replicated** — orange wireframe, the shape sits on an entity that is synced from the server, so it exists for every player.
  - **Not replicated** — green wireframe, the shape sits on a local entity created by a client-side script and is only present on this client.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `bool` | state | `true` to show wireframes on all collision shapes, `false` to hide them |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Toggle debug wireframes globally"
physics.collision_shape.set_debug_all(true)
```
