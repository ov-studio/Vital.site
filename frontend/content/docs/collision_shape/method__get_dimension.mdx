---
title: self:get_dimension
description: Retrieves the dimension of the collision shape
badge: shared
---

### Syntax

```lua
local dimension = self:get_dimension()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `int` | dimension | Current dimension id |

---

### Examples

```lua lineNumbers title="Get the dimension of a collision shape"
local entity = physics.collision_shape.create()

core.engine.print("info", "Collision shape dimension:", entity:get_dimension())
```
