---
title: self:destroy
description: Destroys the collision shape instance and removes it from the scene
badge: client
---

### Syntax

```lua
local status = self:destroy()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Destroy a collision shape instance"
local entity = local body = physics.rigid.create()
local entity = physics.collision_shape.create(body)

entity:destroy()
```
