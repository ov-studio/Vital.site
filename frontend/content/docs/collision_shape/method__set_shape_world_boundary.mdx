---
title: self:set_shape_world_boundary
description: Assigns an infinite boundary plane shape to the collision shape — useful for kill-floors or world edges
badge: shared
---

### Syntax

```lua
local status = self:set_shape_world_boundary(
    plane_normal,
    plane_distance = 0
)
```

<Callout type="warn">
  **Modifying a replicated collision shape is only allowed for the server or the client that owns its body.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of.
  - **On any other client** — raises an error when the entity is owned by the server or by another client.
  - **Client-local entities** — entities that are not replicated are unrestricted.
  - **Attached entities** — a collision shape follows the authority of the body it is attached to.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `vector3` | plane_normal | Normal of the infinite boundary plane as `{x, y, z}` |
| `float` | plane_distance | Distance of the plane from the origin along its normal |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set a world boundary shape on a collision shape"
local body = physics.rigid.create()
local entity = physics.collision_shape.create(body)

entity:set_shape_world_boundary({0, 1, 0}, 0)
```
