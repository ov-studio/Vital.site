---
title: self:is_type
description: Checks whether this instance is of the given type name
badge: client
---

### Syntax

```lua
local result = self:is_type(
    name
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `string` | name | Type name to compare against, e.g. "physics.collision_shape" |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the instance matches the given type name, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check the type of a collision shape"
local body = physics.rigid.create()
local entity = physics.collision_shape.create(body)

core.engine.print("info", entity:is_type("physics.collision_shape"))
```
