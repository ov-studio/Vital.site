---
title: self:get_global_scale
description: Retrieves the global scale of the collision shape
badge: client
---

### Syntax

```lua
local scale = self:get_global_scale()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | scale | Current global scale as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the global scale of a collision shape"
local entity = physics.collision_shape.create()

core.engine.print("info", entity:get_global_scale())
```
