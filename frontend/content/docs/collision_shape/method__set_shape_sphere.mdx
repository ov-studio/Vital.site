---
title: self:set_shape_sphere
description: Assigns a sphere shape to the collision shape
badge: client
---

### Syntax

```lua
local status = self:set_shape_sphere(
    radius
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `float` | radius | Sphere radius to apply |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set a sphere shape on a collision shape"
local body = physics.rigid.create()
local entity = physics.collision_shape.create(body)

entity:set_shape_sphere(0.5)
```
