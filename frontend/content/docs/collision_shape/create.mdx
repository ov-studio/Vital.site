---
title: physics.collision_shape.create
description: Creates a new collision shape instance and attaches it to a physics body or area
badge: shared
---

### Syntax

```lua
local instance = physics.collision_shape.create(
    body
)
```

<Callout type="warn">
  **Attaching requires authority over the target body.**

  - **On the server** — always allowed.
  - **On the owning client** — allowed when the client is the syncer of the body.
  - **On any other client** — raises an error when the body is owned by the server or by another client.
  - **Areas** — areas are not replicated, so attaching a shape to an area is unrestricted.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `object` | body | Physics body or area instance to attach the shape to |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `object` | instance | Created collision shape instance |

---

### Examples

```lua lineNumbers title="Create a collision shape instance"
local body = physics.rigid.create()
local entity = physics.collision_shape.create(body)

entity:set_shape_box({1, 1, 1})
```
