---
title: self:set_shape_mesh
description: Builds the collision shape from the meshes of a model
badge: shared
---

### Syntax

```lua
local status = self:set_shape_mesh(
    model,
    config = {}
)
```

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `model` | model | Model instance whose meshes are used to generate the shape |
| `table` | config | Optional generation settings<br/>Refer [**Config**](#config) section |

---

### Config

| Type | Name | Description |
|------|------|-------------|
| `string` | shape_type | Shape generated by default:<br/>• When `"convex"` - builds a convex hull<br/>• When `"concave"` - builds an exact triangle mesh<br/>Defaults to `"convex"` |
| `bool` | include_children | Whether every matching mesh becomes its own child shape instead of one shape for the whole model<br/>Defaults to `false` |
| `table` | filters | List of `{match, shape_type}` rules, the first rule matching a component name overrides `shape_type` for it |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful generation, `false` if the model has no usable mesh |

---

### Examples

```lua lineNumbers title="Generate a convex shape from a model"
core.model.load("crate", "models/crate.glb")
local model = core.model.create("crate")
local body = physics.static.create()
local entity = physics.collision_shape.create(body)

entity:set_shape_mesh(model)
```

```lua lineNumbers title="Generate a concave shape for a specific component"
core.model.load("crate", "models/crate.glb")
local model = core.model.create("crate")
local body = physics.static.create()
local entity = physics.collision_shape.create(body)

entity:set_shape_mesh(model, {
    shape_type = "convex",
    include_children = true,
    filters = {
        {match = "Floor*", shape_type = "concave"}
    }
})
```
