---
title: self:is_remote
description: Checks whether the instance is remotely owned
badge: client
---

### Syntax

```lua
local result = self:is_remote()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the instance is remotely owned, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check whether a collision shape is remote"
local entity_owner = physics.rigid.create()
local entity = physics.collision_shape.create(entity_owner)

core.engine.print("info", "Remote:", entity:is_remote())
```
