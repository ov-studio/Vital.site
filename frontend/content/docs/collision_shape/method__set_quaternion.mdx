---
title: self:set_quaternion
description: Sets the local rotation of the collision shape using a quaternion
badge: shared
---

### Syntax

```lua
local status = self:set_quaternion(
    quaternion
)
```

<Callout type="warn">
  **Modifying a replicated collision shape is only allowed for the server or the client that owns its body.**

  - **On the server** — always allowed, and the change is replicated to every peer.
  - **On the owning client** — allowed on entities it is the syncer of.
  - **On any other client** — raises an error when the entity is owned by the server or by another client.
  - **Client-local entities** — entities that are not replicated are unrestricted.
  - **Attached entities** — a collision shape follows the authority of the body it is attached to.
</Callout>

### Parameters

| Type | Name | Description |
|------|------|-------------|
| `quaternion` | quaternion | Rotation to apply as `{x, y, z, w}` |

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | status | `true` on successful execution, `false` otherwise |

---

### Examples

```lua lineNumbers title="Set the quaternion of a collision shape"
local entity = physics.collision_shape.create()

entity:set_quaternion({0, 0, 0, 1})
```
