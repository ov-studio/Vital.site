---
title: self:get_position
description: Retrieves the local position of the collision shape
badge: client
---

### Syntax

```lua
local position = self:get_position()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `vector3` | position | Current local position as `{x, y, z}` |

---

### Examples

```lua lineNumbers title="Get the local position of a collision shape"
local entity = physics.collision_shape.create()

core.engine.print("info", entity:get_position())
```
