---
title: self:is_streamed
description: Checks whether the instance is currently within the streaming range of the active camera
badge: client
---

### Syntax

```lua
local result = self:is_streamed()
```

### Parameters

| No parameters are accepted by this function |
|---------------------------------------------|

### Returns

| Type | Name | Description |
|------|------|-------------|
| `bool` | result | `true` if the instance is within streaming range, `false` otherwise |

---

### Examples

```lua lineNumbers title="Check whether a collision shape is streamed in"
local entity_owner = physics.rigid.create()
local entity = physics.collision_shape.create(entity_owner)

core.engine.print("info", "Streamed:", entity:is_streamed())
```
